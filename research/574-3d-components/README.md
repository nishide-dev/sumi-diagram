## 決定事項

### 投影
- 既定は **45° / 縮率 0.5**。`layers` と同じ右上で、`dx = s·d·cosθ`、`dy = s·d·sinθ`（d は奥行きの mm、y は上向き）。30° は横に広い列（VGG 型）で図ごとに選べる値として残す。理由: 45° は `layers` と揃い、縦横の食い込みが対称。30° は縦が低くなるが側面が広がり、隣との重なりが増える。
- 外接形は前面 + (dx, dy) の箱 `[x, y−dy, x+w+dx, y+h]`。レイアウト・配線・geometry lint はこれで判定する。

### 面の陰影（tone の fill から導く。色を足さない）
- 前面は tone の fill そのまま。top / side は fill から目標色へ混ぜる比率で決める。
  - 明るいテーマ（sumi, paper）: top は白へ **0.55**、side は tone の line 色へ **0.20**。
  - 暗いテーマ（sumi-dark）: top は tone の line 色へ **0.22**（明るくなる）、side は `#1c2033` へ **0.35**（暗くなる）。
- weak（0.35/0.10, 0.12/0.20）は面の差が出ず、strong（0.80/0.32, 0.34/0.50）は重く、暗色では側面が背景に沈む。medium を採る。
- 値はテーマの `cuboidShade` 相当として持ち、`themeOverrides` で上書き可能にする。

### 線
- **輪郭（シルエット）は frame 幅、tone の line 色。内側の 3 辺（前面の上辺・右辺と手前の角）は 0.5 倍の太さで line 色を fill 側へ 55% 混ぜる**。全辺を同じ太さにすると薄い板（幅 1.5mm）が線の塊になる。
- 角は丸めない（`rx` は cuboid に使わない。paper でも直角）。
- 格子線（`cells`）は edge 幅の 0.5 倍、line 色を canvas 側へ 45% 混ぜる。ハイライトの部分ブロックは別の cuboid として tone を変え、frame 幅の輪郭で描く。

### 文字と寸法
- 文字は常に水平。cuboid の中に入れない（薄い板では入らない）。
- `dims`: 幅（x）の値は輪郭の**上**、中央を最上辺の中点に置き、シルエットの上端から 2.6mm。高さ（y）の値は前面の**下**（同 3.4mm）、または左辺の左（conv3d）。奥行きの値は手前下の奥行き辺の中点の右下。値の整列は同じ列で揃える。
- 軸の割り当ては図の作者が決める（CNN: 幅 = チャネル数、前面の高さ・奥行き = 空間サイズ。conv3d: x, y, 奥行き = W, H, D）。大きさの mm は明示値。空間サイズの縮尺は対数的に圧縮してよい（U-Net は 1/√2 ずつ）。
- 同じ列の連続する cuboid（conv ブロック）には寸法を 1 回だけ、列の中央に置く。

### ポート
- 左 = 前面の左辺中点。右 = 前面中央の高さの水平線がシルエットと交わる点（`h/2 ≥ dy` なら奥の右辺、そうでなければ側面の下辺）。下 = 前面の下辺中点。上 = 上面の奥の辺の中点（x は前面中央 + dx）。
- スキップ接続は上ポートから出て、図ごとに決めた高さ（シルエットの上端 − 8mm）で水平に渡り、相手の上ポートへ降りる直交線（破線）。プール = 下ポートから下→右。アップコンブ = 右ポートから右→上。

### 重なり順（z-order）
- **左から右、下から上**（キー = `x − y`、昇順に描く）。奥行きが右上へ伸びるので、右隣の前面が左の側面を隠すのが正しい。逆順は誤り。
- 同じブロック内の cuboid は隙間 **1mm**（板を重ねた見え方）。ブロック間は **0.5·dx + 1.2mm**。dx 以上空ける必要はない。
- 矢印・スキップ・凡例の線は cuboid より後に描く。受容野の線は出力側の体積より前に描き、出力側に隠させる（セルの背面へ届く表現）。

### 受容野（stage B）
- 部分ブロックは体積の前・上・右の角に置くと 3 面が見え、読みやすい。核のブロックは別 tone（orange）、輪郭を frame 幅。
- 線は **核の出力側の面の 4 隅 → 出力セルの入力側の面の 4 隅**（案 A）。破線（`2 1.8`）、edge 幅、tone の line 色。案 B は入力の体積を横切り、案 C は 2 本だけで「四角錐」に見えない。
- 注意: 核の位置と出力セルの添字の対応は描かない（見えやすさを優先して最寄りのセルに結ぶ）。実装では `zoom` の始点を「cuboid の部分ブロックの面」に一般化する。

### plane（stage C）
- 平面は平らな 2D のシート。座標 (u, v) を `x = x0 + u + v·s·cosθ`、`y = y0 − v·s·sinθ` に写す（u は横幅、v は手前の辺からの奥行き。縮率 s と角度 θ は図の投影設定と同じ）。45° / 0.5 では 100 × 56mm のシートが約 120mm 幅 × 20mm 高に見える。
- 中身は 2D で配置して同じ変換で写す。**ノードは写さず中心だけ写す**: 円は直立した円（半径 4.3mm、中に水平の文字）。平たい楕円（ラベルを上に出す）は文字が対応線とぶつかり、読みにくいので採らない。
- 平面内の辺は plane 座標で配線し（直線は直線、曲線は同じ変換）、円の縁で止める。edge 幅の 1.5 倍の実線。背面の行（v が大きい）から順にノードを描く。
- 平面の枠は `container` と同じ fill / 枠（sumi は fill あり、paper は白＋薄灰の枠）。厚みの縁は付けない（平らで足りる）。タイトルは手前の辺の下、左寄せ、group の文字サイズの太字。
- 対応線: edge 幅の点線（`0.1 1.3`、丸キャップ）、ノード円の縁から縁へ縦に引く。**上の平面の背後を通し、平面内では薄く（ink を canvas 側へ 60% 混ぜる）重ねて描く**（案 V3）。V1（常に前）は上の平面の辺とぶつかり、V2（完全に隠す）は対応が途切れる。対応ノードは画面上の x が重ならないよう段違いに置く（行ごとに v の分だけずれるため自然に離れる）。
- 角度は 45°/0.5 でよい。30°/0.5 は平面が低くなり縦の余白が詰まる代わりに、側面が広がる。
