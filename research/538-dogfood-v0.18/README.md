## 採点の基準（図を見る前に決めた）

採点は、手順と描き手を伏せた PNG（final と draft1）で行う。各項目 1〜5。

1. **内容の正しさと網羅**: 依頼の要素がすべてあり、関係（向き・入れ子・共有）が正しい。
2. **読みやすさ**: 置き場所での文字の大きさ、ラベルの長さと折り返し、線と文字の重なりのなさ。
3. **構成**: 主な流れが一目でわかる、視線の向きが一貫している、要素の重要度に応じた大きさと強調、余白の配分。
4. **整列と一貫性**: 同じ役割の要素の大きさ・間隔・形がそろっている、格子に乗っている。
5. **色**: 色数を抑え、強調に意味がある、テーマと調和している。
6. **置き場所への収まり**: 縦横比と大きさが置き場所に合っている、無駄な空白や縮小がない。

総合: 「そのまま使える」「少し直せば使える」「使えない」の 3 段階。

あわせて、時間、描画の回数、lint の warning の数を比べる。
