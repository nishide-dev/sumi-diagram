# Sumi v0.18.0

エージェントが描く図の質を上げる版です。Sumi Skill に、構成が自明でない図で先に HTML の下絵を作る段階と、近い構成をコピーして直すための 26 個のベースレイアウトを加えました。テーマの文字の倍率と画面向けのプロファイル、テーマの色の使い方の目安と lint、状態遷移の記号やラベルの文字スタイル、集合の最小サイズなども加えています。v0.17 で描いた 8 つの依頼を v0.18.0 の Skill で描き直した再計測（[#538](https://github.com/nishide-dev/sumi-diagram/issues/538)）では、盲検の採点の平均が 30 点満点で 17.6 から 25.2 に上がりました。実装は milestone「[v0.18.0](https://github.com/nishide-dev/sumi-diagram/milestone/35)」です。

## Sumi Skill

- **HTML の下絵**（[#510](https://github.com/nishide-dev/sumi-diagram/issues/510)）: 複数パネル・ループ・状態遷移・分類など構成が自明でない図では、Sumi で描けるものだけを使った HTML/CSS の下絵を実寸で作り、Chrome で画像にして確かめてから YAML で再現します。手順は `references/mockup.md`、ひな形は `references/mockup-template.html` です。テーマの色・文字・線の太さは `sumi catalog --json` から取ります。
- **ベースレイアウト集**（[#511](https://github.com/nishide-dev/sumi-diagram/issues/511)）: `skills/sumi/layouts/` に 26 個の構成（パイプライン、エンコーダー・デコーダー、残差の積み重ね、MoE、2・3 パネルの比較、表、アブレーション、ループ、状態遷移、エージェントのループ、判定の木、タイムライン、階層の木、Venn、入れ子、3 層構成、メッセージバスなど）を置きました。エージェントは最も近いものをコピーして直し、どれを元にしたかを報告します。どれも `sumi` テーマで、lint の error・warning は 0 です。索引は `layouts/README.md` で、サムネイル付きです。
- **プレビュー**（[#521](https://github.com/nishide-dev/sumi-diagram/issues/521)、[#535](https://github.com/nishide-dev/sumi-diagram/issues/535)）: `scripts/preview` は macOS 以外でも headless Chrome / Chromium / Edge（`$SUMI_CHROME`）を優先し、埋め込みフォントで描きます。`rsvg-convert` しかない環境では、太字などが反映されないことを警告します。Linux で Chrome の終了時のシグナルにスクリプトが巻き込まれないよう、Chrome を別のセッションで起動します。`scripts/compare` のオプションは入力の前後どちらにも置けます。
- 案内の追加: `operator` と `junction` が記号の部品であること、状態遷移図は小さく直線的なときだけ自動配置にすること、置き場所に合わせて文字の倍率を選ぶ手順。

## テーマと文字

- **文字の倍率と `screen-doc`**（[#514](https://github.com/nishide-dev/sumi-diagram/issues/514)）: `figure.themeOverrides.textScale`（0.5〜4、0.25 刻み）で、テーマの文字サイズ・線の太さ・角の丸みに同じ倍率を掛けます。`sumi` のような 7〜9pt のテーマをスライドに使うときは `textScale: 2` です。README やブログ向けのプロファイル `screen-doc`（最大 200 × 150mm、最小 10pt）を加え、`sumi` は倍率 1.5 で満たします。`sumi catalog` はテーマとプロファイルの組ごとに必要な倍率（`textScaleFor`）を示し、`profile/font-too-small` のヒントも倍率を名指しします。
- **色の使い方の目安**（[#513](https://github.com/nishide-dev/sumi-diagram/issues/513)）: テーマが `colorUse`（有彩色の tone の数、勧める variant、重い variant の面積の割合）を持てるようにし、`sumi` / `sumi-dark` に設定しました。外れた図には `geometry/theme-color-use`（info）が、直す tone と variant を名指しします。`sumi catalog --json` の `themes[].colorUse` で読めます。
- **ラベルの文字スタイル**（[#519](https://github.com/nishide-dev/sumi-diagram/issues/519)、structured のみ）: `text: small | body | heading | large` でテーマの文字の役割から大きさを選び、`weight: regular | bold` で太さを、`sublabelInk: muted` で副題を補助の文字色にします。自由なサイズや色は指定できません。

## コンポーネント

- **開始・終了の記号**（#519）: `sumi/initial`（塗りの点）と `sumi/final`（輪のある点）。structured のみで、辺の端点にできます。
- **破線の箱と塗りのある破線のグループ**（#519）: 塗りのある形に `dashed` variant、グループに `filled-dashed` variant。
- **自己ループの曲線**（#519）: 自分自身への辺に `route: curve` を使えます。`fromAnchor` / `toAnchor` で辺と両端を選べます。
- **`textAlign: left | right`**（#519）: 文字より広い箱で、文字のまとまりごと左右の余白に寄せるようにしました（これまでは行揃えだけでした）。
- **低い円柱**（[#516](https://github.com/nishide-dev/sumi-diagram/issues/516)）: 高さ 50pt 未満の円柱は蓋を浅くし、1 行のラベルが入るようにしました。それでも入らないときは、ヒントが必要な `props.height` を示します。
- **mm の大きさ**（[#515](https://github.com/nishide-dev/sumi-diagram/issues/515)）: `width` / `height` などの大きさが 0.5pt の倍数でないとき、拒否せずに最も近い 0.5pt に丸めます。線の太さ・角の丸み・文字サイズは従来どおり厳密です。

## 集合

- **最小の大きさ**（[#518](https://github.com/nishide-dev/sumi-diagram/issues/518)）: `circle` / `ellipse` / `rect` の集合に `minWidth` / `minHeight`。メンバーに合わせた輪郭が小さいときだけ、中心を保って大きくします。複数の集合の大きさをそろえるのに、見えない `junction` は不要になりました。
- **lint**（#518）: メンバーでないノードを輪郭が横切ると `geometry/set-outline-crosses-node`（warning）。凡例の `node` の見本に `cornerRadius` を指定できます。

## 構造化レイアウト

- **予測できる配置**（[#517](https://github.com/nishide-dev/sumi-diagram/issues/517)）:
  - グループの見出しを枠の外に置く `labelAt: above-left / above / above-right` と、グループの `props.padding`。
  - grid のセルごとの `align`（`{item, span, align}`）。
  - tokens の空のセル `{blank: true}`。
  - `place` の `origin: body`（付属のラベルを除いた本体を基準にする）。
  - 診断: 1 行の tokens が `align` で割れると `layout/align-splits-tokens`（warning）、`centerOn` の大きな空白に `layout/center-on-void`（info）。`layout/straight-off-side` のヒントに、合わせるアンカーを示します。
- **広い箱から狭い箱への線**（[#512](https://github.com/nishide-dev/sumi-diagram/issues/512) の一部）: アンカーのない端点で、一方が他方より広く、相手の中心がその辺の内側にあるときは、既定でまっすぐ降ろします。これまでは中央どうしを結ぶ段差や、同じ辺の線を束ねた幹になっていました。従来の束ね方は `figure.layout.fanIn: merge` で戻せます。

## フォーマッタ

- **grid の行**（[#520](https://github.com/nishide-dev/sumi-diagram/issues/520)）: `sumi fmt` が grid の `items` を行ごとに 1 行で保つようにしました。flow の括弧の内側には空白を入れません（`[a, b]`、`{a: 1}`）。

## 互換性

- Figure Schema への追加はすべて任意です（`themeOverrides.textScale`、`text` / `weight` / `sublabelInk`、`labelAt: above-*`、グループの `props.padding`、セルの `align`、`blank` セル、`origin`、集合の `minWidth` / `minHeight`、凡例の `cornerRadius`）。プロファイルに `screen-doc`、部品に `sumi/initial` / `sumi/final`、variant に `dashed` / `filled-dashed` が加わりました。
- **出力が変わる図**:
  - 幅の違う箱をアンカーなしでつなぐ structured の図。線がまっすぐになります（`fanIn: merge` で従来に戻せます）。
  - 高さ 50pt 未満の円柱。蓋が浅くなり、ラベルが胴の中央に寄ります。
  - 固定幅などで文字より広い箱の `textAlign: left | right`。
  - 0.5pt の倍数でない大きさを書いた図。これまでのエラーではなく、丸めて描きます。
- `sumi fmt` の出力が変わります（grid の行、flow の括弧の空白）。描画は変わりません。
- 新しい lint の info / warning が出る図があります（`geometry/theme-color-use` は `sumi` / `sumi-dark` のみ）。
- コミット済みの作例と論文の再現図は変わりません（版の表記と、fmt の変更による入力の hash を除く）。
- 固定版 D2 は v0.9.0、同梱フォント・Tabler Icons・Fluent Emoji Flat・Takumi は v0.17.1 と同じです。
- 設計の判断は、[docs/design/decisions](https://github.com/nishide-dev/sumi-diagram/tree/v0.18.0/docs/design/decisions) の各ファイル（#511〜#520）を参照してください。
- 矢印の経路の残りの課題（不要な迂回、枠に沿う線）と、再計測で見つかった課題は milestone「[v0.18.1](https://github.com/nishide-dev/sumi-diagram/milestone/36)」で扱います。

## インストールと更新

```sh
curl -fsSL https://raw.githubusercontent.com/nishide-dev/sumi-diagram/main/install.sh | sh
```

版を固定するときは `SUMI_VERSION=0.18.0` を付けます（README の[はじめる](https://github.com/nishide-dev/sumi-diagram/blob/v0.18.0/README.md#get-started)）。Skill は `npx skills add nishide-dev/sumi-diagram --skill sumi` で更新します。
