# Sumi v0.5.2

v0.5.1 を典型的な論文図 4 枚で実際に使った結果（[#151](https://github.com/nishide-dev/sumi-diagram/issues/151)、[記録](https://github.com/nishide-dev/sumi-diagram/blob/v0.5.2/research/151-dogfood-v0.5/README.md)）をもとに、不具合・診断・lint・Skill を直したパッチリリースです。Figure Schema の書き方は追加していません。実装は milestone「[v0.5.2 — Dogfooding fixes](https://github.com/nishide-dev/sumi-diagram/milestone/14)」です。

## 不具合の修正

- **structured の図で、hidden junction へのまっすぐな線が S 字に寄り道する問題を直しました**（[#153](https://github.com/nishide-dev/sumi-diagram/issues/153)）。
  - ⊕ からすぐ上の hidden junction へ引く線が、junction の手前で横へずれてから入ることがありました。凡例など、近くの箱の位置によって起きたり起きなかったりしました。
  - 原因は、junction から出る辺の矢じりの手前に取る直線の余白（v0.4.1 の [#116](https://github.com/nishide-dev/sumi-diagram/issues/116)）が、junction を越えて入ってくる線の側まで伸びていたことでした。余白を、真正面にある junction で止めるようにしました。
- **hidden junction の角の丸めが、矢じりに重ならないようにしました**（[#160](https://github.com/nishide-dev/sumi-diagram/issues/160)）。
  - junction から矢じりまでが短いと、junction の丸めの弧が矢じりにかかることがありました。junction の丸めも、矢じりの側に残す長さを守ります。
  - 組み込みの辺（`arrow`、`double-arrow` など三角の矢じり）では起きず、出力も変わりません。矢じりが `arrow` や `cross` の自作の辺の部品で起きていました。

## 診断の追加と改善

- **`lint/literal-newline`（warning）**: ラベルの平文の部分（`$...$` の外）に、文字どおりの `\n`（バックスラッシュ + n）があると報告します（[#154](https://github.com/nishide-dev/sumi-diagram/issues/154)）。単一引用符で書いた `'...\n$\gamma$'` のように、改行のつもりの `\n` がそのまま描かれる誤りを見つけます。`$...$` の中の `\nu` `\neq` `\nabla` などは対象外です。hint は二重引用符での書き方を示します（そのラベルを書き直した形。長いラベルでは短い例）。本当に `\n` を描きたい場合は `--rule lint/literal-newline=off` で止められます。
- **`component/anchor-on-junction`（warning）**: structured の図で、junction の端に書いた `fromAnchor` / `toAnchor` は効かない（junction の中心につなぐ）ことを報告します（#154）。図の描き方は変わりません。
- **`layout/edge-crossing`（info）**: 同じ長い hint を交差ごとに繰り返していたのを、最初の 1 件だけにしました（#154）。コード・severity・件数は変わりません。
- **`layout/align-grew-figure`（info）**: `figure.layout.align` で図が大きくなったとき（同じ向きで 5mm を超え、かつ 10% を超える）、伸びた量と前後の大きさを報告します（[#155](https://github.com/nishide-dev/sumi-diagram/issues/155)）。
- **辺の近接を見る幾何 lint を 4 つ追加しました**（[#156](https://github.com/nishide-dev/sumi-diagram/issues/156)）。auto と structured の両方に掛かり、描かれた線（structured では角を丸め、矢じりの手前で止めた線）で測ります。
  - `geometry/edge-on-border`（warning）: 辺が、グループの枠線に接する・重なる（線の間 0.5pt 以下）状態で 3mm 以上並ぶ。
  - `geometry/edge-near-border`（info）: 同じで、線の間が 0.5pt を超え 1.5pt 未満。
  - `geometry/edge-near-edge`（warning）: 2 本の辺が、同じ線には重ならずに 1.5pt 未満の間隔で 3mm 以上並ぶ。同じ線に重なる共有の幹線は対象外です。
  - `geometry/edge-touches-label`（info）: 辺が、端でないグループの見出し・キャプション・`label` 部品の文字から 1.5pt 未満を通る（横切る場合は従来どおり `edge-crosses-label`）。
  - 破線は、破線の間も線として測ります。そのため、文字の脇が破線の間に当たる場合も報告することがあります。

## 配置の改善

- **`figure.layout.align` が図を必要以上に大きくしないようにしました**（#155）。揃え方の候補が同じだけ揃う場合に、図の小さくなる候補を選びます。#151 の例では、高さが 90mm から 127mm に伸びていた図が 90mm のまま揃います。揃い方が良い候補がある場合の選び方は、従来どおりです。

## Skill

- Skill を直しました（[#157](https://github.com/nishide-dev/sumi-diagram/issues/157)）。
  - グループの `caption` は下に固定で、経路を塞ぐと下の要素への辺が回り込むこと。外側のグループに `caption` を付ける、相手を横に並べる、という直し方。
  - `container` の `muted` の見え方（`academic` は破線の枠と透明の背景、`minimal` / `color` / `slides` は同じ枠と白の背景）。catalog の説明も直しました。
  - 数式と改行を 1 つのラベルで使う書き方（二重引用符でバックスラッシュを重ねる、または `|-` のブロック）。
  - `layout/align-grew-figure` が出たときの直し方、junction の anchor が効かないこと。

## 互換性

- Figure Schema と CLI は変わりません。上の新しい診断コードを追加しました。既存のコードと severity は変わりません。
- **新しい warning が、既存の図に出ることがあります**。`--max-warnings 0` で検査している場合は、更新後に確かめてください。
  - `geometry/edge-on-border` と `geometry/edge-near-edge` は、リポジトリの図では、structured の研究用の図（#135 の図 4、#151 の図 4 と再現）に出ました。同梱の作例とギャラリーの見本には出ません。
  - `lint/literal-newline` は、ラベルに文字どおりの `\n` を書いた図に出ます（リポジトリでは、#151 の再現と、わざと `\n` を描くテスト用の図）。
  - ギャラリーの比較表（auto の pipeline、minimal・color テーマ）で、`geometry/edge-touches-label` の info が 4 件増えました。
- auto（D2/ELK）の図の SVG / PDF / PPTX は、版に関する metadata（`sumi-version` など）を除いて変わりません。
- structured の図は、次の場合だけ経路や配置が変わります。同梱の作例・ギャラリー・fixture では、版の表記を除いてバイト単位で同じです。
  - 矢じりのある辺の手前、余白の長さより近くに、真正面の hidden junction がある（#153）。リポジトリの図では #151 の再現だけが変わりました。
  - `figure.layout.align` の候補が同じだけ揃う（#155）。`align` を使うリポジトリの 7 図では、#151 の再現だけが変わりました。
- 固定版 D2 は v0.9.0、同梱フォントは BIZ UD Gothic 1.051 と STIX Two 2.13、Tabler Icons は 3.49.0 のままです。
- 設計の詳細は、[設計 §6.36〜§6.39](https://github.com/nishide-dev/sumi-diagram/blob/v0.5.2/docs/design/phase1.md#636-155-の-align-による図の拡大の報告と同点の案の選び方) と §6.26（#160）を参照してください。
