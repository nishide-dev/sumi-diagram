# Sumi v0.18.2

v0.18.1 で一部だけ直した課題の残りを片付ける版です。線のラベルと線の間を広げ、グループに入る線の幹を枠から離し、編集可能 PPTX の矢じりを SVG に合わせました。実装は milestone「[v0.18.2](https://github.com/nishide-dev/sumi-diagram/milestone/37)」です。

## 線のラベル

- **ラベルと線の間隔**（[#546](https://github.com/nishide-dev/sumi-diagram/issues/546)）: テーマに `edgeLabelGap`（unit）を持てるようにし、`sumi` / `sumi-dark` は 6（約 1mm）にしました。これまでは線から 0.4〜0.5mm で、線に貼り付いて見えました。間隔は `textScale` に比例します。構造化レイアウトのみで、auto（D2）は変わりません。ほかのテーマは従来の間隔のままです。
- `sumi catalog --json` の `themes[].edgeLabelGap` で読めます。
- `geometry/edge-label-hugging` は、`edgeLabelGap` を持つテーマでは、その 75%（`textScale` を掛けた値）より線に近いラベルを報告します。ほかのテーマは従来どおり印刷時 1pt です。

## 矢印の経路

- **グループに入る線の幹**（[#512](https://github.com/nishide-dev/sumi-diagram/issues/512)）: 別々の場所から同じポートに入るファンインの幹と、相手と反対を向いたポートに入る U 字の線が、グループの枠から 3pt 離れるよう余白を広げます。幹がすでに 3pt 以上離れているときは変えません。v0.18.1 のファンアウトの規則と合わせて、記録された枠沿いの線はなくなりました。

## 編集可能 PPTX

- **`arrow`・`box`・`cross` の矢じり**（[#485](https://github.com/nishide-dev/sumi-diagram/issues/485)）: SVG と同じ形の図形で描きます。auto は SVG の marker から、構造化レイアウトは SVG と同じ関数から形を取ります。D2 と同じく `arrow` は常に塗ります。marker の線の太さも、形と同じ倍率で太くします。
- **点線の位相**（#485）: ラベルの下で分けた点線の各部分を、SVG の次の点の位置から始めます。点を持たない短い部分は捨て、その終点の矢じりは別の図形で描きます。
- この矢じりを持つ線は、glued でも freeform になります（v0.18.1 の中抜きの矢じりと同じ）。

## 互換性

- Figure Schema は変わりません。テーマに任意の `edgeLabelGap` が加わりました。
- **出力が変わる図**:
  - `sumi` / `sumi-dark` の構造化レイアウトで、線のラベルがある図（ラベルが線から離れます）。Skill のレイアウト 15 個、README の図、ギャラリーの `dim` を再生成しました。
  - グループの外から同じポートに入るファンインや、U 字に入る線が、枠の 3pt 以内を通っていた図（グループの余白が広がります）。
  - 編集可能 PPTX の `arrow`・`box`・`cross` の矢じりと、ラベルの下で分けた点線。
- コミット済みの作例と論文の再現図の出力は変わりません（版の表記を除く）。
- 固定版 D2 は v0.9.0、同梱フォント・Tabler Icons・Fluent Emoji Flat・Takumi は v0.17.1 と同じです。
- 設計の判断は、[docs/design/decisions](https://github.com/nishide-dev/sumi-diagram/tree/v0.18.2/docs/design/decisions) の `485-pptx-arrow-box-cross-heads.md`、`512-adjacent-trunks.md`、`546-edge-label-gap.md` を参照してください。
- `labelAt: above-*` の見出しの隙間（[#544](https://github.com/nishide-dev/sumi-diagram/issues/544)）は再現しなかったので閉じました。
