# Sumi v0.9.0

論文図のレイアウトの仕上げです。離れた bowtie（LoRA）のラベルと辺を直し、グループの中で横から入る矢じりの前に見える直線と丸い角を取り、パネルの空きを詰める配置の指定を加えました。あわせて、テーマの役割・作例・ギャラリーを整理しました。計画は [#236](https://github.com/nishide-dev/sumi-diagram/issues/236)、実装は milestone「[v0.9.0 — Layout polish](https://github.com/nishide-dev/sumi-diagram/milestone/20)」です。

## 新しい書き方

- **パネルの空きを詰める `justify`**（[#248](https://github.com/nishide-dev/sumi-diagram/issues/248)）: structured の `row` / `stack` に任意の `justify: center | stretch | space-between`。主軸（stack は高さ、row は幅）の余りの使い方を決めます。
  - `stretch`: 余りを伸ばせる子に等分して足します（入れ子の配置・group・大きさを明示していない箱）。円・正方形・文字・独自の輪郭（bowtie など）と、主軸の大きさを明示した要素は伸ばしません（交差軸は `align` に従います）。
  - `space-between`: 子の大きさを保ち、余りを間隔に等分します。
  - 省略と `center` は従来どおり中央寄せです。交差軸の伸縮は従来の `align: stretch` を使います。grid では使えません。
  - 例: 高い要素（行列や図）と並べた列の箱を、その高さまで伸ばせます（列に `justify: stretch`、行に `align: stretch`）。

## 改善と修正

- **グループの中で横から入る矢じりの前に、見える直線と丸い角を取ります**（[#247](https://github.com/nishide-dev/sumi-diagram/issues/247)、[#260](https://github.com/nishide-dev/sumi-diagram/issues/260)）。
  - 例: Transformer の残差が Add & Norm に入る矢印。これまでは横の区間が矢じりの長さちょうどで、角の直後に矢じりが来ていました。
  - 今は「半径 2pt の丸い角 → 2pt の直線 → 矢じり」の順に描きます。そのために、その側のグループの余白を広げます。
  - 余白は左右（上下）の大きい方に揃えて両側を広げます。片側だけ広げると、グループの外の要素（Linear・⊕ など）とつながる線に小さな段差が出るためです。
- **離れた bowtie（`props.gap`）のラベルが輪郭に重ならないようにしました**（[#245](https://github.com/nishide-dev/sumi-diagram/issues/245)）。ラベルを左の台形の中に置き、その分の大きさを自動で取ります。大きさを明示して小さすぎる場合は `geometry/label-overflow`（error）で知らせます。
- **離れた bowtie に入る辺の段差をなくしました**（[#246](https://github.com/nishide-dev/sumi-diagram/issues/246)）。上下から揃った隣の要素とは、まっすぐつなぎます。動かせない場合は `layout/unaligned-ends`（warning）で知らせます。
- **離れた bowtie に `fromAnchor` / `toAnchor` を書いた辺が、誤って anchor のずれと判定されないようにしました**（[#251](https://github.com/nishide-dev/sumi-diagram/issues/251)）。

## 新しい診断

- **info**: `geometry/arrowhead-cramped`。structured の図で、矢じりの前の見える直線が印刷時 2pt 未満の端です。`fit: scale` で縮めた図にも出ます。曲がりのない辺・見えない辺・凡例の見本と、`arrowhead-on-bend`（warning）の対象は除きます。
- **info**: `geometry/group-empty-area`。group の外接矩形のうち、見出しと直接の子（ラベル・バッジを含む）の外接矩形で占められない部分が 75% 以上の場合です。辺は占有に数えず、空の group と展開でできる枠は除きます。詰めるには `justify` や `align: stretch` を使います。
- どちらも `render` と `lint --geometry` で実行します。
- info は `--max-warnings` に数えません。

## テーマ・作例・ギャラリー

- **テーマの役割をはっきりさせました**（[#262](https://github.com/nishide-dev/sumi-diagram/issues/262)）。`academic` は白黒（グレースケール）で印刷向けのジャーナル調、`paper` はカラーで ML 論文風（パステルの tone、角丸、1pt の枠と 0.5pt の辺、薄灰のパネル、Latin に Inter）です。テーマの出力は変わりません。5 テーマの比較は [テーマの説明](https://github.com/nishide-dev/sumi-diagram/blob/v0.9.0/docs/themes-ja.md) を参照してください。
- **作例の Transformer と DiT を paper テーマの完成版にしました**（[#263](https://github.com/nishide-dev/sumi-diagram/issues/263)）。DiT は原図と同じ 4 パネルで、`fit: scale` で 180mm に縮めます（数式の添字の大きさなどの info が出ます）。
- **ギャラリーを分けました**（[#264](https://github.com/nishide-dev/sumi-diagram/issues/264)）。短い目次、部品ごとのページ、テーマ・tone・dim・比較のページです。以前のリンク先のアンカーも残しています。

## 互換性

- Figure Schema は任意の追加（`justify`）だけです。CLI のコマンドは変わりません。
- **グループの中に、横から箱に入る矢じりを持つ structured の図は、幅（または高さ）が増えます**（#247・#260）。v0.8.0 の Transformer（paper テーマ）は 75.32 → 78.49mm です。
  - 単段の幅上限（paper-single の 88mm）に近かった図は、`geometry/exceeds-page-width`（error）になることがあります。#247 の時点でリポジトリの全図を全テーマで比べたところ、9 通り（`examples/transformer` の旧版 2 通りと研究用の図 7 通り）が新たに上限を超えました。
  - 回避するには、`fit: scale` で縮めるか、間隔（`gap`）や要素の幅を調整してください。
  - 新しい info（`arrowhead-cramped`・`group-empty-area`）が加わる図があります。出力は変わりません。
- **離れた bowtie（`props.gap`）を使う図は、大きさとラベルの位置が変わります**（#245）。
- 上の 2 種類以外の図の SVG / PDF / PPTX / D2 は、v0.8.0 と同じです（版に関する metadata を除く）。
- 固定版 D2 は v0.9.0、同梱フォント（BIZ UD Gothic 1.051、STIX Two 2.13、Inter 4.1）、Tabler Icons 3.49.0、Fluent Emoji Flat は v0.8.0 と同じです。
- 設計の詳細は、[設計 §6.68〜§6.73](https://github.com/nishide-dev/sumi-diagram/blob/v0.9.0/docs/design/phase1.md#668-245-の-split-bowtie-のラベル安全領域と輪郭重なり検出) を参照してください。
