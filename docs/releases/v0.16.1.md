# Sumi v0.16.1

v0.16.0 で加えた部品のギャラリーの図を、何を説明する図かが一目で分かる作例に作り直しました。あわせて、グリフ付きのノードで矢印が曲がる不具合と、黄・橙の色が黄土色やカーキに濁る問題を直しました。論文の再現図が lint やテストのために書き換えられたことを検出するテストも加えています。計画は [#236](https://github.com/nishide-dev/sumi-diagram/issues/236)、実装は milestone「[v0.16.1 — Gallery figures that explain](https://github.com/nishide-dev/sumi-diagram/milestone/30)」です。

## ギャラリーの図

- **作り直した図**（[#456](https://github.com/nishide-dev/sumi-diagram/issues/456)）: 機能を並べただけだった 3 つの図を、それぞれ一つの場面を説明する図にしました。
  - [Legend samples](https://github.com/nishide-dev/sumi-diagram/blob/v0.16.1/docs/gallery/legend-samples.md): 文書のハイパーグラフをエンコーダで埋め込み、正例・負例の対を作る対照学習の図です。凡例は図で使う記号だけを、Nodes・Features・Pairs の見出しで並べます。
  - [Node glyphs](https://github.com/nishide-dev/sumi-diagram/blob/v0.16.1/docs/gallery/glyphs.md): キャプションと画像を別々のエンコーダで埋め込み、結合して分類する図です。特徴ベクトルが段階ごとに色を変え、点（学習する）とピル（凍結）が状態を示します。
  - [Stroke options](https://github.com/nishide-dev/sumi-diagram/blob/v0.16.1/docs/gallery/strokes.md): 知識蒸留の図です。太い線（主な経路）、細い線（補助の入力）、破線（教師のソフトターゲット）、点線の枠（推論だけで使う部分）に、それぞれ役割を持たせました。
  - `slides` テーマでは、文字と線が 2 倍になるため、これらの図を `presentation-16x9` プロファイルで描きます。
- **集合がグリフも囲む指定**（#456）: `sets` の `enclose: footprint` で、メンバーの特徴ベクトルなどのグリフも囲みます。既定は `enclose: body`（ノードの本体だけを囲む、これまでどおり）です。
- **短すぎる破線の警告**（#456）: 新しい lint `geometry/dash-hidden` は、矢じりに挟まれて破線や点線の模様が見えなくなっている線を知らせます。凡例の破線・点線の見本は、模様が見える長さで描くようにしました。

## 不具合の修正

- **グリフ付きノードの揃え**（[#454](https://github.com/nishide-dev/sumi-diagram/issues/454)）: 行・列・グリッドで、特徴ベクトルなどのグリフを付けたノードが、グリフの分まで含めた外枠ではなく本体の位置で揃うようになりました。アイコンと箱を結ぶ矢印に出ていた小さな段差がなくなります。グリフの場所はこれまでどおり確保します。既定の位置のグリフが直線の矢印に重なるときは、`geometry/glyph-collision` がグリフの動かし方を案内します。
- **パレットの黄・橙**（[#455](https://github.com/nishide-dev/sumi-diagram/issues/455)）: `themeOverrides.palette` から作る yellow と orange が、カーキやタンに濁らないようにしました。
- **solid の黄・橙と黄色の線**（[#459](https://github.com/nishide-dev/sumi-diagram/issues/459)）:
  - solid の yellow は、明るい黄色の塗りに濃い文字にしました。orange は茶色に見えないよう、少し赤に寄せました。
  - yellow の線（矢印・枠）は、黄土色ではなく金色にしました。白とテーマの通常のパネルに対して 3:1 以上を保ちます。パレットの濃いパネルや明示的な色の上書きは、この保証の外です。
  - 白黒のテーマ（academic・minimal・slides）は変わりません。
- **yellow の文字**（[#465](https://github.com/nishide-dev/sumi-diagram/issues/465)）: yellow の文字を、他の tone と同じく線と同じ色相の濃い色（濃い金色）にしました。パレットの墨色（紺や赤茶）が黄色の上に載ってちぐはぐに見えていたのを直しています。ノードの中で別の tone の塗りに載る `\textcolor{…}` の文字は、4.5:1 で読める濃さまで暗くします。
- **濁りの lint**（#455、#459、#465）: `geometry/muddy-color` は、不透明な塗りと線が黄土色・カーキ・オリーブ・タンになっていないかも調べます。小さな文字は、同じ色相の濃い色でもその色の系統として読めるため対象外です。

## テスト

- **再現図の書き換えの検出**（[#462](https://github.com/nishide-dev/sumi-diagram/issues/462)）: 論文の再現図と Skill の例について、YAML・参照する素材・素材を作るスクリプトの内容のハッシュを記録し、テストで照合します。再現図は元の図に忠実であるべきで、lint の指摘は図を変えずに期待値として記録します（例: LLaDA の `geometry/dash-hidden` 4 件は元の図の短い破線の矢印によるもの）。意図した変更のときだけ `SUMI_UPDATE_REPRODUCTIONS=1 bun test src/compiler/reproduction-hashes.test.ts` で更新します。

## 互換性

- Figure Schema への追加は任意のもの（`sets` の `enclose`）だけです。CLI のコマンドは変わりません。
- **出力が変わる図**:
  - 行・列・グリッドに、グリフを付けたノードを並べた図。本体の位置で揃います。
  - `color`・`paper`・`llama` テーマとパレットで、yellow や orange の tone を使う図。solid の塗り、yellow の線と文字の色、`llama` の orange の線が変わります。
  - ギャラリーの見本の多く。
- 論文の再現図（transformer・dit-block・clip・embedding-gemma・gcn・llama4-moe・tricl・llada）の出力は変わりません。LLaDA には `geometry/dash-hidden` の警告が 4 件出ます（元の図どおり）。
- それ以外の既存の図の SVG / PDF / PPTX / D2 は、v0.16.0 と同じです（版に関する metadata を除く）。
- 固定版 D2 は v0.9.0、同梱フォント・Tabler Icons・Fluent Emoji Flat・Takumi は v0.16.0 と同じです。
- 設計の判断は、[docs/design/decisions](https://github.com/nishide-dev/sumi-diagram/tree/v0.16.1/docs/design/decisions) の各ファイル（#454〜#465）を参照してください。
- 濃い塗りの上の淡い線を検出する lint は、論文の再現図の淡い線との兼ね合いを含めて [#463](https://github.com/nishide-dev/sumi-diagram/issues/463) で設計します。

## インストールと更新

```sh
curl -fsSL https://raw.githubusercontent.com/nishide-dev/sumi-diagram/main/install.sh | sh
```

版を固定するときは `SUMI_VERSION=0.16.1` を付けます（README の[インストール](https://github.com/nishide-dev/sumi-diagram/blob/v0.16.1/README.md#install)）。Skill は `npx skills add nishide-dev/sumi-diagram --skill sumi` で更新します。

公開準備は [#467](https://github.com/nishide-dev/sumi-diagram/issues/467) です。今後の計画は [#236](https://github.com/nishide-dev/sumi-diagram/issues/236) で管理します。
