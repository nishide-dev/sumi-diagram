# Sumi v0.8.0

論文図の改善の続きです。H3-World の LoRA を原図どおり離れた 2 枚の台形で描けるようにし、同梱の絵文字を大きく増やし、ワンライナーのインストーラーと README を作り直しました。計画は [#236](https://github.com/nishide-dev/sumi-diagram/issues/236)、実装は milestone「[v0.8.0 — Paper figure follow-ups](https://github.com/nishide-dev/sumi-diagram/milestone/19)」です。

## 新しい書き方

すべて Figure v1 への任意の props の追加と、使える絵文字の名前の追加です。structured と auto の両方の図で使えます。

- **離れた 2 枚の台形の bowtie**（[#233](https://github.com/nishide-dev/sumi-diagram/issues/233)）: `component: bowtie` の `props.gap`（0〜64、D2 単位＝0.5pt。例: `gap: 8` で 4pt）。向かい合う 2 枚の台形を、間を空けて描きます。未指定・0 は従来の中央でつながった形です。小さい幅を明示しても台形が潰れないよう、間隔は幅の半分までに抑えます。
  - ラベルは 1 個で、2 枚の台形と間隔をまたいで置きます。バッジは全体の角に付きます。
  - 間隔は経路の通り道になりません（ほかの辺は全体を避けます）。上下から入る辺は、間隔ではなく近いほうの台形の口に接します（ちょうど中央なら左）。
  - 編集可能 PPTX では 1 個の図形（2 本の path）として書き出し、接続点は描かれた台形の輪郭の上に置きます。
- **台形の向き**（#233）: `component: trapezoid` の `props.narrow: south | north | east | west` で、狭い辺の側を選びます。未指定・`south` は従来どおり上が広い台形です。
- **絵文字の拡大**（[#234](https://github.com/nishide-dev/sumi-diagram/issues/234)）: `icon: emoji/<name>` と `badge.icon` で、Fluent Emoji Flat（MIT）のうち Sumi が安全に取り込める **3,124 個**すべてを使えます（v0.7.0 は 47 個）。v0.7.0 の 47 個の名前と絵は変わりません。
  - 名前は `sumi catalog --icons "<words>"` で探せます（Tabler のアイコンと同じ検索）。`sumi catalog --icons "" --json` は全件を返します。
  - 上流の 3,174 個のうち、`<use>`・クリッピング・グラデーション・フィルタが必要な **50 個**は同梱していません。その名前を書くと `asset/unsupported-icon`（error）と理由を返します。名前の誤りは従来どおり `asset/unknown-icon` と近い名前の候補です。
  - 絵文字のデータは、名前の検索や描画で初めて使うときに読み込みます。起動時間と、絵文字を使わない図の描画には影響しません。

## インストール

- **ワンライナーのインストーラー**（[#238](https://github.com/nishide-dev/sumi-diagram/issues/238)）:
  ```sh
  curl -fsSL https://raw.githubusercontent.com/nishide-dev/sumi-diagram/main/install.sh | sh
  ```
  macOS / Linux の x64 / arm64 を判別し、最新のリリース（または `SUMI_VERSION`）を取得します。`SHA256SUMS` で検証してから、`~/.local/share/sumi`（`SUMI_HOME`）に展開し、`~/.local/bin/sumi`（`SUMI_BIN_DIR`）にリンクを作って `sumi doctor` を実行します。sudo は使いません。再実行で更新でき、同じ版の入れ直しでも実行中の `sumi` を上書きしません（別の場所に展開してから入れ替えます）。
- **README を作り直しました**（#238）。英語の [README](https://github.com/nishide-dev/sumi-diagram/blob/v0.8.0/README.md) と日本語の [docs/README-ja.md](https://github.com/nishide-dev/sumi-diagram/blob/v0.8.0/docs/README-ja.md) を互いにリンクし、詳しい使い方は `docs/usage.md` / `docs/usage-ja.md`、開発の手順は `CONTRIBUTING.md` に移しました。

## 診断

- 新しい診断コードはありません。
- `svg/outline-edge-miss`（warning）は、auto の図で、離れた bowtie に入る辺の端を安全に台形の口へ移せない場合にも出ます（補正した経路が折り返す・自分と重なる・ほかの図形を横切る、など）。このとき Sumi はその辺を D2 の元の経路のまま描くので、配置を調整してください。structured の図では出ません。

## 互換性

- Figure Schema は任意の追加だけです。CLI のコマンドは変わりません（`catalog --icons` の検索対象に絵文字が加わります）。
- **`gap` / `narrow` と新しい絵文字を使わない図の SVG / PDF / PPTX / D2 は、v0.7.0 と同じです**（版に関する metadata を除く）。リポジトリの 149 個の図を、書かれた Theme と全組み込み Theme の 894 通りで比較して確認しました。
- 同梱の作例の出力は、版の表記を除いて変わりません。ギャラリーの bowtie と trapezoid の見本に、`gap` と 4 方向の `narrow` が加わりました。
- **配布物**: 絵文字のデータが約 1.06 MiB 増えました（darwin-arm64 の tarball で 53.2MB → 54.3MB）。Fluent Emoji Flat のライセンス（`licenses/` と NOTICE）は v0.7.0 と同じです。
- 固定版 D2 は v0.9.0、同梱フォント（BIZ UD Gothic 1.051、STIX Two 2.13、Inter 4.1）と Tabler Icons 3.49.0 は v0.7.0 と同じです。
- 設計の詳細は、[設計 §6.66〜§6.67](https://github.com/nishide-dev/sumi-diagram/blob/v0.8.0/docs/design/phase1.md#666-233-の離れた-2-台形の-bowtie-と台形の向き) を参照してください。
