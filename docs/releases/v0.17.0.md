# Sumi v0.17.0

プロジェクトの Web サイトと同じデザインの `sumi` / `sumi-dark` テーマを加え、テーマが描画の地の色を持てるようにしました。図の背景を透明にして出力でき、エッジのラベルの下に地の色の四角を敷かなくなったので、スライドや Web ページ、GitHub の README にそのまま重ねられます。濃い塗りの上で見えにくい線を知らせる lint も加えました。あわせて、README をエージェントから使う前提で書き直し、作例・コンポーネント・プロンプト作成をまとめた [Web サイト](https://nishide-dev.github.io/sumi-diagram/)を公開しました。計画は [#236](https://github.com/nishide-dev/sumi-diagram/issues/236)、実装は milestone「[v0.17.0](https://github.com/nishide-dev/sumi-diagram/milestone/33)」「[README refresh](https://github.com/nishide-dev/sumi-diagram/milestone/32)」「[GitHub Pages site](https://github.com/nishide-dev/sumi-diagram/milestone/31)」です。

## テーマ

- **`sumi` と `sumi-dark`**（[#473](https://github.com/nishide-dev/sumi-diagram/issues/473)）: サイトのデザインシステムに合わせたテーマです。
  - `sumi`: クリーム色の地（`#f8f8ee`）に紺の線と文字、砂色のアクセント。
  - `sumi-dark`: 紺の地（`#30364f`）にクリーム色の線と文字。tone・set・`dim` は暗い地で読めるように作り直しています。
  - 欧文は Inter です（`paper`・`llama` と同じフォントセット）。文字は 4.5:1、線は 3:1 を地とパネルの上で保ちます。
- **テーマの地の色**（#473）: テーマが描画の地の色を持つようになりました（既定は白）。SVG（structured・auto の両方）、PDF、PPTX（画像・編集可能）、HTML 埋め込み（`--sumi-bg`）、ラベルや色の合成、幾何 lint のコントラストが、白ではなくこの色を使います。
- **暗い地のパレット**（#473）: `themeOverrides.palette` を `sumi-dark` に当てると、パレットの暗い版になります。地はテーマの紺のまま、パネルはパレットの色相で一段明るく、文字と線はパレットの最も淡い色、アクセントは地の上で読める明るさにします。明るい地（`sumi` の cream など）では、これまでどおりの導出を地の色に対して測ります。

## 出力

- **透明な背景**（[#479](https://github.com/nishide-dev/sumi-diagram/issues/479)）: `figure.background: transparent`、または `sumi render --background transparent` で、一番外側の地を描かずに出力します（SVG・PDF・PPTX）。ノードの塗りはテーマの地の色のままで、コントラストと lint もテーマの地を想定します。`sumi lint --geometry` も同じフラグを受け付けます（結果は変わりません）。
- **ラベルの下地をなくした**（[#483](https://github.com/nishide-dev/sumi-diagram/issues/483)）: エッジのラベルの下に地の色の矩形を敷かなくなりました。
  - structured: ラベルは線から離して置かれるので、下地は不要です。
  - auto（D2）: D2 がラベルの下の線をマスクで切るので、重ねていた矩形を除きました。編集可能 PPTX は、ラベルの下で線を分割します（`glued` は通常の地では下地を残して接続を保ち、透明な背景ではラベルを横切る線だけを分割します）。
  - 中抜きの矢じりは中を塗らず、線を矢じりの根元で止めます。
  - 透明な背景の図を別の色の上に置いても、ラベルや矢じりの周りに四角が出ません。地の上での見た目は変わりません。

## lint

- **`geometry/low-stroke-contrast`**（[#463](https://github.com/nishide-dev/sumi-diagram/issues/463)）: エッジの線と、塗りが背後とほぼ同じで輪郭だけで形を示すノードの枠が、実際に描かれた背景（地・グループ・set）から区別しにくいときに知らせます。
  - エッジ: 3:1 未満で info、1.5:1 未満で warning。
  - ノードの枠: 2:1 未満で info。
  - グループの枠、operator・junction・zoom の線、`dim` の中の要素は対象外です。

## README と Web サイト

- **Web サイト**（[#469](https://github.com/nishide-dev/sumi-diagram/issues/469)、[#470](https://github.com/nishide-dev/sumi-diagram/issues/470)、[#475](https://github.com/nishide-dev/sumi-diagram/issues/475)、[#486](https://github.com/nishide-dev/sumi-diagram/issues/486)）: https://nishide-dev.github.io/sumi-diagram/
  - Home は README から生成します。
  - Examples は作例の図と YAML、原図へのリンクです。
  - Components では、全コンポーネントと描画オプションを、全テーマ・パレットで見比べられます（Preview / Code）。
  - Prompt では、図の目的・資料・種類・配置先・レイアウト・色からエージェント向けの依頼文を作れます。日英に対応します。
- **README**（[#474](https://github.com/nishide-dev/sumi-diagram/issues/474)）: エージェントから使う前提で書き直しました。
  - Sumi 自身で描いた仕組みの図（`sumi` / `sumi-dark`、透明な背景）を載せています。
  - Skill の導入コマンドは、特定のハーネスに限りません: `npx skills add nishide-dev/sumi-diagram --skill sumi`。

## 互換性

- Figure Schema への追加は任意のもの（`figure.background`）だけです。CLI には `--background` を追加しました。テーマ名に `sumi`・`sumi-dark` が加わりました。
- **出力が変わる図**:
  - エッジのラベルを持つ図。ラベルの下の矩形がなくなります（地の上の見た目は同じ）。
  - 中抜きの矢じりの図（独自の部品で使う場合）。
  - ギャラリーには、`sumi` と `sumi-dark` の列が加わりました。
- 既存のテーマ（minimal・academic・slides・color・paper・llama）とパレットの色は変わりません。
- 新しい lint の info が出る図があります。作例では `gcn` の原図どおりの淡いエッジ 2 本です（図は変えずに期待値として記録）。
- 固定版 D2 は v0.9.0、同梱フォント・Tabler Icons・Fluent Emoji Flat・Takumi は v0.16.1 と同じです。
- 設計の判断は、[docs/design/decisions](https://github.com/nishide-dev/sumi-diagram/tree/v0.17.0/docs/design/decisions) の各ファイル（#463、#469、#473〜#475、#479、#483）を参照してください。
- 編集可能 PPTX の中抜きの矢じりの形と、分割した破線の模様のつながりは [#485](https://github.com/nishide-dev/sumi-diagram/issues/485) で扱います。

## インストールと更新

```sh
curl -fsSL https://raw.githubusercontent.com/nishide-dev/sumi-diagram/main/install.sh | sh
```

版を固定するときは `SUMI_VERSION=0.17.0` を付けます（README の[はじめる](https://github.com/nishide-dev/sumi-diagram/blob/v0.17.0/README.md#get-started)）。Skill は `npx skills add nishide-dev/sumi-diagram --skill sumi` で更新します。
