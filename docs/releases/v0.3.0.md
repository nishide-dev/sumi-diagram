# Sumi v0.3.0

台形・stack の汎用部品、カスタム輪郭の描画と幾何 lint、2種類の PPTX 出力を追加したリリースです。PDF エンジンは、保守終了した svg2pdf から krilla / krilla-svg へ移行しました。機能追加を含むため v0.2.1 ではなく v0.3.0 として公開します。

## 台形・stack とカスタム輪郭

- `trapezoid` は上辺が広く下辺が狭い台形、`stack` は3枚の矩形を重ねた汎用部品です。全3テーマ・default / emphasis / muted に対応し、カタログとギャラリーから探せます。
- props は既存部品と同じ width / height。省略時は文字と輪郭の安全領域に合わせて自動サイズを決めます。傾き・枚数・ずれ幅は固定です。
- 自動サイズは測定と最終描画の2パスです。カスタム輪郭にエッジ端点を合わせ、ラベルの安全領域・衝突領域を幾何 lint へ接続しました。
- 任意のSVGをYAMLに埋め込む機能ではありません。カタログの `render` は部品のメタデータで、利用者がYAMLへ書くフィールドではありません。固定ポートの公開や1パス化は行いません。

## PPTX：画像方式（既定）

```sh
sumi render figure.sumi.yaml -o figure.pptx
# または
sumi render figure.sumi.yaml --format pptx
```

図全体を1スライド・1枚の画像にします。文字をpath化したSVGと、resvg 0.47.0によるPNGフォールバックを格納し、閲覧側のフォントに依存しません。**図形・文字・矢印は個別編集できません**。画像は元SVGの物理サイズを保ち、PPTXの最小1inchより小さい辺は余白を足して中央配置します。56inch超の辺は診断で拒否します。PNGは192dpiを目標に、8192px/辺・約1600万画素へ制限します。

## PPTX：編集可能方式（実験的）

```sh
sumi render figure.sumi.yaml -o editable.pptx --pptx-mode editable
sumi render figure.sumi.yaml -o glued.pptx --pptx-mode editable --pptx-connectors glued
```

保証するのは **図形と文字を個別に選択・編集できること**のみです。

- `freeform`（既定）は元の経路を自由形状として保ちますが、ノード移動へ追従しません。
- `glued` は上下左右の接着点を持つ標準直線コネクタへ置換します。折れ線・曲線は失われ、ラベルも追従しません。コンテナは子を一緒に動かす階層グループではありません。
- 文字はフォントを参照し、PPTXへ埋め込みません。閲覧側に BIZ UDPGothic / BIZ UDGothic がなければ置換されます。Macでの実確認では MS-Gothic への置換を観測しました。
- 見た目の完全一致、編集後レイアウトの維持、YAMLへの逆変換は保証しません。画像方式へ暗黙に置き換えることもしません。非対応形状・glued自己ループ等は診断で拒否します。

生成環境は両方式とも macOS / Linux × x64 / arm64。実アプリは PowerPoint for Mac 16.114.1 で日本語fixtureを確認し、画像方式のSVG表示、編集可能方式の文字変更・20pt移動の保存と接着挙動を記録しました。Windows PowerPoint・Keynote・Google Slides は今回の保証対象外です。全入力を実アプリで確認したという意味ではありません。

## PDF エンジンの更新と LaTeX

変換を krilla 0.8.2 + krilla-svg 0.8.1 / usvg 0.47.0 に移行し、svg2pdf の依存と自前の決定性パッチを削除しました。同梱WASMは引き続きホスト関数なしで実行し、通常の利用にRust・Bun・Node.js・ブラウザは不要です。

PDF 1.7 の1ページ、SVGと同じpt寸法、同梱フォントの検索可能な文字サブセット、ベクターマスク、Sumi provenanceを維持します。実 pdfLaTeX / LuaLaTeX 取り込みを継続CIで検査しています。**v0.2.0 のPDFとは内部構造・subset tag・Producer・バイト列が変わります**。PDF/A・PDF/X・タグ付きPDF・複数ページは引き続き保証しません。

## 互換性と検証

- Figure Schema v1 と既存のYAML・CLIの既定SVG出力は維持します。SVGのmetadata `sumi-version` は `0.3.0` となるため、描画が同じ図でもファイルhashは変わります。
- `render` の形式に `pptx` と `.pptx` 推論を追加。既存 `--json` は `format: "pptx"` を返し、`size` は余白を加えたスライドではなく図自体の寸法です。バイナリ形式のstdout出力は行いません。
- 画像PPTXと編集可能PPTXのpackage provenanceも版を更新するため、v0.2.0表記の開発中生成物とはhashが変わります。
- 既存のgeometry診断に加え、PPTXの入力・寸法・フォント・未対応形状・変換の診断と、実験的編集方式のwarningを追加しました。warningだけならexit 0です。
- 固定版D2は **v0.9.0**、同梱フォントは **BIZ UD Gothic 1.051** のままです。Windows CLI・npm公開・macOS公証は対象外です。
- SVG/PDF/PPTX golden・package hash、独立Open XML SDKのスキーマ、4ターゲットの配布smokeで継続検証します。詳細: [画像PPTX](../verification/61-pptx.md)、[編集可能PPTX](../verification/62-editable-pptx.md)、[PDF移行](../verification/74-krilla.md)。

## インストールと更新

READMEの[インストール手順](../../README.md#インストールリリース版)で `version=0.3.0` を指定してください。macOS（arm64 / x64）とLinux（x64 / arm64）のtarballに、単一実行ファイル・D2・フォント・ライセンス・チェックサムを収録しています。旧版からは展開ディレクトリを丸ごと置き換え、`sumi --version` と `sumi doctor` を確認してください。

PDF/PPTX共通エンジンのライセンスは `licenses/pdf-wasm/` にあります（旧版の `licenses/svg2pdf-wasm/` から変更）。krillaのNOTICEが示すMPL部分を含め、原文と対応ソースの入手先を同梱します。PPTXのOffice/.NET検証ツールは配布物に含めません。
