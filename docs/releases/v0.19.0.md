# Sumi v0.19.0

立体で描いた方が伝わる図のための部品を加えた版です。U-Net や 3D-CNN の層を直方体で描く `cuboid`、その格子・部分ブロック・受容野の線、同じノードを持つグラフを傾けた平面に重ねて対応を見せる `plane` を、どれも斜投影（cabinet）の 2D の図形として描きます。設計は [#574](https://github.com/nishide-dev/sumi-diagram/issues/574)、実装は milestone「[v0.19.0](https://github.com/nishide-dev/sumi-diagram/milestone/38)」です。

## 投影の設定

- **`figure.projection: {angle, depthScale}`**（[#575](https://github.com/nishide-dev/sumi-diagram/issues/575)）: 奥行きを描く向きと縮尺を図ごとに決めます。`angle` は 10〜80 度（既定 45、右上）、`depthScale` は 0 より大きく 2 まで（既定 0.5）。立体と平面はすべてこの値で描きます。書かなければ、立体を使わない図の出力は変わりません。

## 直方体 `cuboid`

- **`sumi/cuboid`**（#575）: CNN の層・特徴マップ・体積を、前面・上面・側面の 3 面で描きます。上面は明るく、側面は暗く、テーマが面の陰影を決めます。`props: {width, height, depth}` で前面の大きさと奥行きを、`dims` で各辺の寸法ラベル（`64`、`28²` など）を付けます。構造化レイアウトのみです。
- **線は面の中心から面の中心へ**（[#587](https://github.com/nishide-dev/sumi-diagram/issues/587)）: アンカーのない線は、出る面の中心から入る面の中心へ向けた 1 本の直線になります。見える面（側面・上面）では面の中心から出て面の中心に着き、隠れた面（左面・底面）では面の中心を狙ってシルエットで止まります。途中に別のノードがあるとき（U-Net の skip connection など）は、横に並んだ立体なら上面（または底面）から、縦に並んだ立体なら側面から回り込み、ほかの線と交わらない経路を選びます。どれも引けなければ従来の経路にします。立体の中心へ向けてシルエットで止める描き方は `ports: center` で選べます。
- **格子と部分ブロック**（[#576](https://github.com/nishide-dev/sumi-diagram/issues/576)）: `props.cells: [nx, ny, nz]` で見える 3 面にセルの格子を描き、`props.highlight` でカーネルや出力セルのような部分ブロックを色を付けて描きます。部分ブロックは `<node>.<name>` で参照できます。
- **受容野の線**（#576、[#584](https://github.com/nishide-dev/sumi-diagram/issues/584)）: 部分ブロックどうしを `zoom` で結ぶと、対応する角どうしを 4 本の線で結びます。横に並んだ体積でも、上下に並んだ体積でも描け、体積に隠れる部分は SVG・PDF・PPTX で同じように切ります。
- **部分ブロックへの普通の線**（#584）: `arrow` / `line` の端にも `<node>.<name>` を使えます。線はブロックの中心へ向かい、ブロックの輪郭で止まります。

## 傾けた平面 `plane`

- **`container` の `props.plane: floor | wall`**（[#577](https://github.com/nishide-dev/sumi-diagram/issues/577)）: グループを床（`floor`）または奥へ退く壁（`wall`）として平行四辺形に描きます。中身は普段どおり `place`・`row`・`grid` などで並べ、平面の写像で位置を写します。平面内の線は平面の上で配線してから写します。
- **平面をまたぐ対応線**（#577）: 重ねた平面のノードどうしを `route: straight` で結ぶと、上の平面に隠れる部分は平面の下を通り、上に薄く重ねて見せます。多層ネットワークやグラフの対応づけを描けます。
- **中身を平面に倒す `contents: projected`**（#577）: 既定（`upright`）ではノードは立ったまま中心だけを写します。`projected` では箱は平行四辺形、円は楕円になり、矢じりも平面に沿って倒れます。文字は読めるよう水平のままです。
- **平面上の `matrix`**（#577）: attention map のような行列を平面に置けます。`contents: projected` ではセルも平面に倒れます。

## Skill と作例

- **ベースレイアウト**: `cnn-volumes`（VGG 風の層の並び）、`conv3d`（3D 畳み込みの受容野）、`stacked-planes`（重ねた平面と対応線）、`projected-planes`（平面に倒した中身と attention map）を加えました。
- **作例**（[#588](https://github.com/nishide-dev/sumi-diagram/issues/588)、[#591](https://github.com/nishide-dev/sumi-diagram/issues/591)）: [`multilayer-network`](https://github.com/nishide-dev/sumi-diagram/blob/v0.19.0/examples/multilayer-network/multilayer-network.sumi.yaml)（3 層の多層ネットワーク）と [`attention-sheet`](https://github.com/nishide-dev/sumi-diagram/blob/v0.19.0/examples/attention-sheet/attention-sheet.sumi.yaml)（傾けた平面の上の causal attention）を `llama` テーマで加え、サイトの Examples に載せました。
- **サイトのプロンプトビルダー**（[#571](https://github.com/nishide-dev/sumi-diagram/issues/571)）: README 向けの図を `screen-doc` で作るようにし、置き場所ごとの高さの目安、テーマを変えないこと、資料にない矢印を仮定として報告することを、Skill に合わせて指示するようにしました。

## 互換性

- Figure Schema に `figure.projection`、部品 `cuboid`、`container` の `props.plane` / `props.contents` が加わりました。既存のプロパティは変わりません。
- **出力が変わる図**: ありません。立体と平面を使わない図、コミット済みの作例、論文の再現図の出力は変わりません（版の表記を除く）。
- 固定版 D2 は v0.9.0、同梱フォント・Tabler Icons・Fluent Emoji Flat・Takumi は v0.18.2 と同じです。
- 設計の判断は、[docs/design/decisions](https://github.com/nishide-dev/sumi-diagram/tree/v0.19.0/docs/design/decisions) の `575-cuboid.md`、`576-cuboid-grids.md`、`577-planes.md`、`577-projected-planes.md`、`584-cuboid-block-edges.md`、`587-cuboid-face-ports.md`、および `571-prompt-builder.md` を参照してください。
- **既知の制限**: 立体と平面は構造化レイアウトのみです。連鎖して重なる 3 本以上の skip connection は交わることがあります（`ports: center` と同じ）。平面の上の画像や円柱などは立ったまま、文字は傾けません。編集可能 PPTX では、平面をまたぐ対応線は平面の上に描かれ、薄い重ねはありません。
