# Sumi v0.15.2

チャットの吹き出しや注釈を描く部品 `bubble` と、会話をチャットアプリのように並べる `chat` 配置を加え、会話の図の例を 2 つ追加しました。あわせて、Skill に主要な例を同梱し、図を作るときに近い例の画像と YAML を見てから書くようにしました。計画は [#236](https://github.com/nishide-dev/sumi-diagram/issues/236)、実装は milestone「[v0.15.2 — Chat figures](https://github.com/nishide-dev/sumi-diagram/milestone/28)」です。

## 吹き出し `bubble`

- **組み込み部品 `bubble`**（[#395](https://github.com/nishide-dev/sumi-diagram/issues/395)）: 角の丸い吹き出しです。auto と structured の両方で使えます。
  - `tail: left | right | top | bottom | none`（既定は `none`）でしっぽの向き、`tailAt: start | center | end | <長さ>` で辺の上の位置、`tailSize` で張り出しの深さを決めます。
  - 左右の `start` は、チャットアプリの吹き出しと同じく、上の角の丸みに付く小さな角になります。そのほかの位置と上下は、付け根がなめらかな短いくさび形です。本体としっぽは継ぎ目のない 1 本の輪郭で、SVG・PDF・PPTX で同じ形に描きます。
  - しっぽの分の場所を確保し、重なりやページ幅の lint はしっぽを含めて判断します。線は本体だけにつながり、しっぽの先にはつながりません。
  - 本文は既定で左揃えで、`props.maxWidth` で折り返します。和文は行頭・行末の禁則を守って折り返し、`$...$` の数式は途中で分けません。
  - variant は他の塗れる形と同じ 7 種類です。既定は白地に枠、`filled` と `solid` は枠なしです。

## チャット配置 `chat`

- **arrange の箱 `chat`**（[#396](https://github.com/nishide-dev/sumi-diagram/issues/396)）: `bubble` のノードを、メッセージの列として並べます。
  - `speakers` に話者ごとの左右（`side`）、アイコン（`avatar`、既存のノードの id）、tone と variant を書き、`items` に `{ node, from, meta }` と区切り（`divider`）を並べます。
  - しっぽの向き、続けて送ったメッセージのしっぽとアイコンの省略、最大幅（既定は列幅の 0.7）での折り返し、左揃えは配置が決めます。
  - `meta`（時刻・既読など）は吹き出しの内側の下端に小さな文字で添え、区切りは中央の小さな pill になります。
  - 話者やノードの指定の誤り、`bubble` 以外のノード、列幅からのはみ出しは診断（`layout/chat-unknown-speaker`、`layout/chat-unknown-avatar`、`layout/chat-non-bubble`、`layout/chat-overflow`）で知らせます。
  - アイコンは 2 回目以降の出番に別のノードとして描きます。アイコンへの線は最初の出番につながります。

## 例

- **チャット**（[#397](https://github.com/nishide-dev/sumi-diagram/issues/397)、[`examples/chat/`](https://github.com/nishide-dev/sumi-diagram/tree/v0.15.2/examples/chat)）: 日付の区切り、時刻と既読、頭文字のアイコン、続けて送ったメッセージを含む和文の会話です。特定のサービスの色やアイコンは使っていません。
- **LLM との対話**（#397、[`examples/llm-dialogue/`](https://github.com/nishide-dev/sumi-diagram/tree/v0.15.2/examples/llm-dialogue)）: ユーザーとアシスタントのやりとりを、数式を含む複数行の答えとともに論文の図として描きます。

## Skill

- **主要な例の同梱**（[#402](https://github.com/nishide-dev/sumi-diagram/issues/402)）: Skill の例を 4 つから 12 に増やしました（GCN、Llama 4 MoE、チャット、LLM 対話、pipeline、decision-flow、system-architecture、grouped を追加）。索引には、例ごとに何の図か、使っている機能、テーマとプロファイルを載せています。
- **例を見てから書く手順**（#402）: SKILL.md の手順で、YAML を書く前に近い例を 1〜2 個選んで PNG を見て YAML を読み、描いたあとに例の PNG と見比べるようにしました。これまでの「頼まれたときだけ例を見る」という制限は外しました。

## 互換性

- Figure Schema への追加は任意のものだけです。CLI のコマンドは変わりません。
- 既存の図の SVG / PDF / PPTX / D2 は、v0.15.1 と同じです（版に関する metadata を除く）。
- 部品ギャラリーの `bubble` の見本は、塗りの吹き出しが各テーマの `filled` の色で描かれます（[#401](https://github.com/nishide-dev/sumi-diagram/issues/401)）。
- 例の YAML の正本は Skill（`skills/sumi/examples/`）にあり、リポジトリの `examples/` からリンクしています。
- 固定版 D2 は v0.9.0、同梱フォント・Tabler Icons・Fluent Emoji Flat・Takumi は v0.15.1 と同じです。
- 設計の判断は [docs/design/decisions](https://github.com/nishide-dev/sumi-diagram/tree/v0.15.2/docs/design/decisions) の各ファイル（#395、#396、#397）を参照してください。

## インストールと更新

```sh
curl -fsSL https://raw.githubusercontent.com/nishide-dev/sumi-diagram/main/install.sh | sh
```

版を固定するときは `SUMI_VERSION=0.15.2` を付けます（README の[インストール](https://github.com/nishide-dev/sumi-diagram/blob/v0.15.2/README.md#install)）。Skill は `npx skills add nishide-dev/sumi-diagram --skill sumi` で更新します。
