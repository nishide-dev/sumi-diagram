# Sumi v0.13.0

DETR の概要図を題材にした評価で見つかった、配置・線・診断の問題を直すリリースです。交差する線が同じ経路に重なる問題、`tokens` の不具合、短い区間の矢印ラベルの衝突を直し、図全体の大きな空白と大きな縮小を診断で知らせるようにしました。計画は [#236](https://github.com/nishide-dev/sumi-diagram/issues/236)、実装は milestone「[v0.13.0 — Layout quality](https://github.com/nishide-dev/sumi-diagram/milestone/24)」です。

## 線と配置の改善

- **交差する線の平行区間を分ける**（[#329](https://github.com/nishide-dev/sumi-diagram/issues/329)）: 2 つの行の間を、入れ替わる対応のように交差して結ぶ線が、同じ水平（垂直）の経路に重なっていました。structured の経路を決めたあと、こうした線の中央の区間を通路の中で別々のレーンに分けます。
  - レーンの順番は、線どうしの交差が最も少なくなるものを選びます（同時に分けるのは 7 本まで）。
  - 端点・共有の幹・障害物は動かしません。通路が狭くてレーンが入らないときは、元の経路のままにします。
  - そのときの `geometry/edge-near-edge` の hint に、必要な間隔を mm で示すようにしました。
- **短い区間の矢印ラベル**（[#332](https://github.com/nishide-dev/sumi-diagram/issues/332)）: ラベルが区間に入りきらずノードと重なるとき、線の脇（`labelSide` の側）へずらします。ずらす距離には上限があり、線を囲むグループの枠の外には出しません。収まらないときは従来の位置に置き、`layout/edge-label-overlap` を出します。
- **`tokens`**（[#331](https://github.com/nishide-dev/sumi-diagram/issues/331)）:
  - 省略セル（`{ label: '…', component: label }`）が、`tokens` の `variant`（例 `outlined`）を引き継いでエラーになっていました。セルの部品が持たない variant を引き継いだときは、既定の variant を使います。`tokens` 自体が持たない variant（綴りの誤りなど）は、従来どおり `component/unknown-variant` です。
  - 注記を `attach` した `tokens` 全体への矢印が、注記の分だけ広がった枠で止まり、セルの手前の空白で終わっていました。矢印はセルの範囲で終わるようになりました。
- **凡例の文字を左そろえに**（[#333](https://github.com/nishide-dev/sumi-diagram/issues/333)）: 折り返した凡例の項目が中央にそろっていました。既定を左そろえにしました。凡例の `textAlign` で中央・右にも変えられます。

## 新しい診断

- **info `geometry/dead-space`**（[#330](https://github.com/nishide-dev/sumi-diagram/issues/330)）: 図の中で、ノード・グループ・線・ラベルのどれにも重ならない最大の空き矩形が、図の面積の 27% 以上のとき、場所（例 左下）と大きさ（mm）を示します。グループの中だけを見る `geometry/group-empty-area` と違い、図全体を見ます。意図した余白なら `--rule geometry/dead-space=off`、または `--config` のファイルの `{"rules":{"geometry/dead-space":"off"}}` で止められます。
- **info `geometry/heavy-scaling`**（#330）: `figure.fit: scale` が自然な大きさの 90% 未満に縮めたとき、縮尺と、縮小前の大きさでの幅の内訳を示します。
- **info `layout/group-title-offset`**（#332）: 見出し付きのグループで中身の中心がずれ、出入りする矢印が折れ曲がるとき、原因と直し方の候補を示します。
- **`lint/missing-glyph` の位置**（[#298](https://github.com/nishide-dev/sumi-diagram/issues/298)）: `html` の中で、絶対配置の子の隣にある欠字が、1 つ外側の要素を指すことがありました。正しい要素の行・列を指すようになりました。

## 新しい書き方

- **`figure.layout.alignGrowth: report | allow`**（#333）: `allow` にすると、意図した整列で図が大きくなったときの info `layout/align-grew-figure` を出しません。配置は変わりません。

## 互換性

- Figure Schema は任意の追加だけです。CLI のコマンドは変わりません。
- **出力が変わる図**があります。
  - **凡例を含む図**（#333）: 文字の基準が中央から左端に変わるため、SVG / PDF / PPTX のバイト列が変わります。見た目が変わるのは、複数行の項目を持つ凡例だけです。
  - **短い区間のラベルがノードと重なっていた図**（#332）: ラベルの位置が変わります。
  - **2 つの行の間で交差する線が同じ経路を通っていた図**（#329）: 経路が変わります。
  - **文字と数式が空白をはさんで並ぶラベルを持つ図**（[#266](https://github.com/nishide-dev/sumi-diagram/issues/266)）: SVG の `<text>` に `xml:space="preserve"` が付きます。librsvg でもその空白が残るようになりました。PDF・PPTX・配置は変わりません。
- それ以外の図の SVG / PDF / PPTX / D2 は、v0.12.0 と同じです（版に関する metadata を除く）。
- 固定版 D2 は v0.9.0、同梱フォント・Tabler Icons・Fluent Emoji Flat・Takumi は v0.12.0 と同じです。
- 設計の詳細は、[設計 §6.95〜§6.101](https://github.com/nishide-dev/sumi-diagram/blob/v0.13.0/docs/design/phase1.md#695-329-の交差する対応線の平行区間の分離)を参照してください。

## インストールと更新

```sh
curl -fsSL https://raw.githubusercontent.com/nishide-dev/sumi-diagram/main/install.sh | sh
```

版を固定するときは `SUMI_VERSION=0.13.0` を付けます（README の[インストール](https://github.com/nishide-dev/sumi-diagram/blob/v0.13.0/README.md#install)）。Skill は `npx skills add nishide-dev/sumi-diagram --skill sumi` で更新します。

公開準備は [#341](https://github.com/nishide-dev/sumi-diagram/issues/341) です。今後の計画は [#236](https://github.com/nishide-dev/sumi-diagram/issues/236) で管理します。
