# Sumi v0.7.0

論文図の段階 C の後半です。v0.6.0 では描けなかった H3-World 系の概要図の要素（色つきの文字の範囲、画像の重ね、絵文字のバッジと bowtie、表のような配置、濃い塗り・淡い塗り、トークン列の区切り）を足し、3 図の描き直しで見つかった項目を直しました。計画は [#167](https://github.com/nishide-dev/sumi-diagram/issues/167)、実装は milestone「[v0.7.0 — Paper figures stage C, part 2](https://github.com/nishide-dev/sumi-diagram/milestone/17)」です。

## 新しい書き方

すべて Figure v1 への任意のフィールド・値・部品の追加です。特に書かない限り structured の図だけで使えます（auto の図では `layout/structured-only`）。

- **表のような配置 `grid`**（[#126](https://github.com/nishide-dev/sumi-diagram/issues/126)）: `grid: { columns, rowGap, columnGap, align, items }`。行ごとに左から並べ、列の x がそろいます。項目は `{ item, span }` で複数の列にまたがれます。空けたいセルは `null`（`~`）、複数列なら `{ item: null, span: N }` で書き、ノードも経路の障害物も作りません。行は必ず `columns` 列分で埋めます。セルは縦に中央そろえです。
- **画像の重ね**（[#187](https://github.com/nishide-dev/sumi-diagram/issues/187)）: 画像の `props.layers: { count, offset }`。同じ画像を右上へずらして重ねて描きます（Sumi は画像を加工しません）。配置と障害物は重ね全体の範囲、辺の端は描かれた画像に接します。SVG と PDF では画像を 1 回だけ埋め込みます。編集可能 PPTX には書き出せません（`pptx/unsupported-asset`）。
- **色つきの文字の範囲と左右そろえ**（[#186](https://github.com/nishide-dev/sumi-diagram/issues/186)）: 数式の中の `\textcolor{<tone>}{…}` で文字の一部に tone の色をつけます（平文は `\text{…}` で包む）。演算子や関係記号に色をつけても、数式の間隔は変わりません。`nodes[].textAlign: left | center | right` で、ラベルと 2 行目をそろえます。`\textcolor` はこれまで error だったので、今描ける図の意味は変わりません。
- **濃い塗りと淡い塗り**（[#214](https://github.com/nishide-dev/sumi-diagram/issues/214)）: node の `variant: solid`（tone の濃い塗りに白い文字）と `tinted`（淡い塗りに tone の枠と文字）。全組み込み Theme で、文字のコントラストは 4.5:1 以上です（`dim` の中では 3:1 以上）。auto の図でも使えます。
- **トークン列の区切り**（[#216](https://github.com/nishide-dev/sumi-diagram/issues/216)）: `tokens` のセルの間に点線の区切りを置けます。行では縦の線、縦の並びでは横の線になります。
- **絵文字・角のバッジ・bowtie**（[#188](https://github.com/nishide-dev/sumi-diagram/issues/188)）:
  - `icon: emoji/<name>`: 多色の絵文字。Fluent Emoji Flat（MIT）から、図でよく使う 47 個（チェック・警告・電球・歯車・鍵・書類・グラフ・時計・雲・ロボット・人・吹き出し・星・炎・雪の結晶など）を同梱しました。
  - `nodes[].badge: { icon, corner }`: 箱の角に小さなバッジを置きます。配置はバッジの分の場所も取ります。
  - `attach` の `side` に角（`north-east` など）を指定できます。
  - `component: bowtie`: 2 つの台形を向かい合わせた形（LoRA など）。上下から入る辺も形の輪郭に接します。

## 改善と修正

- **`figure.layout.align` が中央そろえの箱の中でも揃うようにしました**（[#213](https://github.com/nishide-dev/sumi-diagram/issues/213)）。1 つずつ動かしても揃わないとき、2 つの組み合わせを試し、ずれの合計が減る場合だけ採ります。試す回数は従来の上限（1,000 回の配置）に含めます。v0.6 で `layout/unsatisfied-align` が出ていた図は、出なくなることがあります。
- **`paper` の operator（⊕ など）を小さくしました**（[#215](https://github.com/nishide-dev/sumi-diagram/issues/215)）。14pt の円に 7pt の記号、枠は 0.5pt です。原図に合わせた変更で、DiT の図は原図と同じ幅で 1.2mm 低くなります。

## 新しい診断

- **error**: `layout/grid-span-overflow`、`layout/grid-item-count`、`component/badge-unsupported`、`asset/unknown-icon-set`・`asset/unknown-icon`（絵文字の名前）
- **warning**: `geometry/badge-collision`（バッジが他の要素や祖先の見出しに重なる）

## 互換性

- Figure Schema は任意の追加だけです。CLI のコマンドは変わりません。
- **新しい書き方を使わない図の SVG / PDF / PPTX / D2 は、v0.6.1 と同じです**（版に関する metadata を除く）。ただし次の 2 つは出力が変わります。
  - **`theme: paper` で operator を含む図**（#215）: operator が小さくなり、その周りの経路が少し変わります。リポジトリの研究用の図と fixture では、4 図で `geometry/edge-touches-label`（info）が新しく出ます。
  - **v0.6 で `layout/unsatisfied-align` が出ていた図**（#213）: 揃うようになり、配置が変わります。リポジトリでは #185 の再現の図だけです。
- 同梱の作例の出力は、版の表記を除いて変わりません。ギャラリーには新しい variant・部品の見本が加わり、既存の見本の一部（新しい variant を持つ部品の並び）が変わりました。
- **配布物**: Fluent Emoji Flat の 47 個（約 14KB）と、そのライセンス（`licenses/` と NOTICE）を同梱しました。
- 固定版 D2 は v0.9.0、同梱フォント（BIZ UD Gothic 1.051、STIX Two 2.13、Inter 4.1）と Tabler Icons 3.49.0 は v0.6.1 と同じです。
- 設計の詳細は、[設計 §6.58〜§6.65](https://github.com/nishide-dev/sumi-diagram/blob/v0.7.0/docs/design/phase1.md#658-213-の中央寄せの箱にある-align-の収束と-2-手先の補助探索) を参照してください。
