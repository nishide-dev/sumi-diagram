# Sumi v0.6.1

v0.6.0 の structured の図で、矢じりの直前に小さな段差ができたり、矢じりが曲がり角に乗ったりする問題を直したパッチリリースです（[#217](https://github.com/nishide-dev/sumi-diagram/issues/217)）。Figure Schema の書き方は追加していません。実装は milestone「[v0.6.1 — Arrowhead on bend fix](https://github.com/nishide-dev/sumi-diagram/milestone/18)」です。

## 不具合の修正

- **矢じりの直前の小さな段差をなくしました**（#217）。
  - 例: v0.6.0 の H3-World の受け入れ図（`research/185-acceptance/`）の (c) で、Out Proj. から ⊕ への線が、右へ進んだあと 2 unit 下がり、0.9 unit 横にずれてから ⊕ に入っていました。
  - 原因は経路探索の費用でした。矢じりの手前に取りたい直線（矢じりの長さを超える「余地」。v0.4.1 の #116）を取れないときの費用（100）が、曲がり 2 つの費用（80）より高かったため、余地を取るために小さな段差を足していました。また、この費用は格子の点ごとに掛かっていたので、格子の細かさで結果が変わっていました。
  - 余地の費用を 100 から 60 に下げました。また、同じネットのほかの矢じりの余地を通るときの費用は、格子の点ごとではなく、その余地に入るときに 1 回だけ掛けるようにしました（辺自身の余地の中で曲がるときは、従来どおり余地の費用が掛かります）。矢じりの長さ分の直線は、従来どおり必ず取ります。上の線は、曲がり 1 つで、矢じりの前に 14 unit の直線を持つ経路になります。
  - 余地は「取れれば取る」好みで、共有の幹線などでは段差が残ることがあります。
- **junction に入る矢じりの前にも、矢じりの長さ分の直線を取るようにしました**（#217）。矢じりのある辺が junction に入るとき、この直線が足りないことがありました。取れない場合は `layout/no-route` です。

## 診断の追加

- **`geometry/arrowhead-on-bend`（warning）**: 矢じりの直前の直線が矢じりより短い（矢じりが曲がり角に乗る）辺を報告します。描かれた線で測ります。リポジトリの図・ギャラリーでは出ません。
- **`geometry/edge-jog`（info）**: 2 つの直角の曲がりの間の線分が、印刷の大きさで 1pt より短い（小さな段差）辺を報告します。固定した口や共有の幹線から生じる段差もあるため info にしました。lint の設定で warning に上げられます。

## 互換性

- Figure Schema と CLI は変わりません。上の 2 つの診断コードを追加しました。既存のコードと severity は変わりません。
- auto（D2/ELK）の図の SVG / PDF / PPTX は、版に関する metadata（`sumi-version` など）を除いて変わりません。
- **structured の図は、矢じりの前の経路が変わることがあります**。段差や回り道が減る方向の変化です。同梱の作例・ギャラリー・golden は、版の表記を除いてバイト単位で同じです。リポジトリの研究用の図と fixture では、13 図・50 通りの出力が変わり、すべて段差の除去か経路の単純化であることを確かめました（[検証の記録](https://github.com/nishide-dev/sumi-diagram/blob/v0.6.1/docs/verification/217-arrowhead-jogs.md)）。
- `geometry/edge-jog` は info なので、`--max-warnings 0` の検査には影響しません。リポジトリでは、同梱の Transformer の作例を `minimal` / `color` で描いたときなど 55 件出ます。
- 固定版 D2 は v0.9.0、同梱フォント（BIZ UD Gothic 1.051、STIX Two 2.13、Inter 4.1）と Tabler Icons 3.49.0 は v0.6.0 と同じです。
- 設計の詳細は、[設計 §6.57](https://github.com/nishide-dev/sumi-diagram/blob/v0.6.1/docs/design/phase1.md#657-217-の矢じりの直前の段差の除去幾何-lint-と-junction-端の保証) を参照してください。
