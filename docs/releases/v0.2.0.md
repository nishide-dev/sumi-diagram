# Sumi v0.2.0

ベクター PDF の出力に対応したリリースです。SVG の出力は v0.1.1 と同じです（メタデータの `sumi-version` だけが変わります）。

## 新機能: PDF 出力

```sh
sumi render figure.sumi.yaml -o figure.pdf
# または
sumi render figure.sumi.yaml --format pdf    # 出力先は figure.pdf
```

- ページは SVG の `width` × `height`（pt）と同じ大きさの 1 ページです。論文の `\includegraphics` などで縮尺を変えずに使えます。
- 文字は同梱フォント（BIZ UDPGothic / BIZ UDGothic）のサブセットを埋め込んだ文字として残り、検索・コピーできます。閲覧側・変換側のフォントには依存しません。
- 図形・線はベクターのままで、ラスタ画像は含みません。同じ入力・同じ版の Sumi なら、OS・CPU によらずバイト単位で同じ PDF になります。
- 変換は svg2pdf 0.13（出力を決定的にするパッチを当て、WebAssembly にして `sumi` に同梱）が行います。Node.js・ブラウザ・追加のバイナリは不要です。
- 幾何 lint は従来どおり SVG の段階で実行します。幾何 lint の error があっても PDF は書き出します（SVG と同じ）。
- `sumi render --json` の結果に、出力形式を示す `format`（`svg` / `pdf`）を追加しました（既存のフィールドは変わりません）。

形式は `--format svg|pdf`、なければ `-o` の拡張子（`.svg` / `.pdf`）で決まり、どちらもなければ SVG です。`--format` と拡張子が矛盾する場合（`--format svg -o x.pdf`）は使い方の誤り（終了コード 2）になります。

新しい診断コード: `pdf/input-too-large`、`pdf/missing-font`、`pdf/unresolved-font`、`pdf/engine-unavailable`、`pdf/conversion-failed`。

## インストール

手順は v0.1.0 と同じです。`version=0.2.0` として、[v0.1.0 のリリースノート](v0.1.0.md) または README の「インストール（リリース版）」に従ってください。旧版から更新する場合は、展開したディレクトリを置き換えてください。

PDF エンジンを同梱したため、`bin/sumi` は約 2MB（darwin-arm64 で 64.8MB → 66.8MB）、tarball は約 0.8MB 大きくなりました。tarball の `licenses/svg2pdf-wasm/` に、PDF エンジンを構成する Rust クレートのライセンスを収録し、`NOTICE` に項目を追加しています（svg2pdf の一部は MPL-2.0 で、ソースの入手先を `NOTICE` に記載）。

## 互換性と既知の制約

- 図の形式（Figure Schema v1）・CLI の既存の動作・SVG の出力に互換性のない変更はありません。
- PDF は 1.7 で、PDF/A・PDF/X などの規格には適合しません（エッジのラベルの下の線を消すために透明（soft mask）を使います）。タグ付き PDF・複数ページには対応しません。
- PDF は `-o -`（標準出力）に書き出せません（使い方の誤りになります）。SVG は従来どおり書き出せます。
- 極端に大きい・深い入力（32 MiB、要素の入れ子 64 段、要素 200,000 個を超える SVG）は `pdf/input-too-large` になります。Sumi が生成する図はこれを大きく下回ります。
- pdfLaTeX / LuaLaTeX での取り込みは未検証です（#63）。
- その他は v0.1.0 から変更はありません（D2 v0.9.0 と同梱フォントに固定、Windows 版なし、macOS のバイナリは公証なし、npm 非公開）。
