# Sumi v0.1.0

Sumi の最初のリリースです。事前定義された部品とデザインシステムから、`*.sumi.yaml` を一次ソースとして SVG の図を生成する Diagram-as-Code CLI です。

## インストール

macOS（arm64 / x64）と Linux（x64 / arm64）向けの tarball を添付しています。Bun・Node.js は不要です。

```sh
version=0.1.0 target=darwin-arm64   # darwin-arm64 | darwin-x64 | linux-x64 | linux-arm64
base=https://github.com/nishide-dev/sumi-diagram/releases/download/v$version
curl -LO "$base/sumi-$version-$target.tar.gz" -LO "$base/SHA256SUMS"
shasum -a 256 --check --ignore-missing SHA256SUMS
tar -xzf "sumi-$version-$target.tar.gz"
export PATH="$PWD/sumi-$version-$target/bin:$PATH"   # 永続化する場合はシェルの設定ファイルに追記
sumi doctor
```

展開したディレクトリの構成（`bin/`・`libexec/`・`share/`）は崩さずに置いてください。`sumi` はこの構成から D2 とフォントを見つけます。Claude Code の Skill は PATH 上の `sumi` を使います。

各 tarball には、`sumi` の単一実行ファイル、レイアウトに使う D2 CLI v0.9.0（MPL-2.0。公式バイナリを無改変で同梱）、日本語対応の同梱フォント BIZ UD ゴシック（SIL OFL 1.1）、ライセンスと sha256 の一覧が入っています。詳しくは README の「インストール（リリース版）」を参照してください。

## 主な機能

- Figure Schema v1（`*.sumi.yaml`）と、エディタ補完用の JSON Schema
- 汎用の組み込み部品 14 種（box・circle・diamond・cylinder・label・container・arrow など）
- 組み込みのテーマ（`minimal` / `academic` / スライド向けの `slides`）と出力プロファイル（`paper-single` / `paper-double` / `presentation-16x9`）。スライドには `theme: slides` と `profile: presentation-16x9` を組み合わせます
- CLI: `render`・`lint`（構造 lint と、描画結果の幾何 lint）・`fmt`・`doctor`・`catalog`
- `sumi catalog --json` で部品・テーマ・プロファイルを、`sumi render --json` で出力サイズと紙面に収まるかを機械可読に取得できます
- 位置付きの共通診断（`--json` で機械可読）
- Claude Code 用の Skill（`npx skills add nishide-dev/sumi-diagram` で導入できます。PATH 上の `sumi` を使います）

## 互換性と既知の制約

- 出力は D2 v0.9.0 と同梱フォントに固定しており、同じ入力に対して決定的です。v0.9.0 以外の D2 を `SUMI_D2_PATH` で指定するとエラーになります。
- Windows 版はありません。
- macOS のバイナリは公証（notarization）されていません。ブラウザでダウンロードした場合は `xattr -dr com.apple.quarantine <展開したディレクトリ>` が必要なことがあります。
- npm には公開していません。
