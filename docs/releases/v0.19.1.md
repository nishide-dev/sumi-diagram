# Sumi v0.19.1

`sumi` テーマの図を白い背景で描くようにし、CLI と Skill を更新しやすくした版です。実装は milestone「[v0.19.1](https://github.com/nishide-dev/sumi-diagram/milestone/39)」です。

## `sumi` テーマの背景を白に

- **既定の背景は白**（[#595](https://github.com/nishide-dev/sumi-diagram/issues/595)）: `sumi` のキャンバスをクリーム色（`#f8f8ee`）から白（`#ffffff`）にしました。紙・PDF・スライドに貼っても色付きの箱になりません。背景から導く色（パレットの変種、cuboid の陰影、集合の重なり、淡色化、コントラストの lint）も白を基準にします。部品・平面・パネルの色は変わりません。
- **背景色を選べる `themeOverrides.canvas`**（#595）: `#RRGGBB` で図のキャンバスを上書きします。`canvas: "#f8f8ee"` で v0.19.0 までの見た目に戻せます。透過は従来どおり `figure.background: transparent` です。
- **`sumi-dark` は変わりません**。明るい文字と線のテーマで、暗い背景を前提にしています。
- サイトは `sumi` の図をこれまでどおりクリーム色の台に載せます。README の図の見た目も変わりません。

## 更新

- **`sumi update`**（[#597](https://github.com/nishide-dev/sumi-diagram/issues/597)）: 最新のリリースを取得し、`SHA256SUMS` で検証してから入れ替えます。`--check` は確認だけ（新しい版があれば終了コード 1）、`--version <版>` は版を指定します（古い版にも戻せます）。対象は install.sh で入れた配置だけで、それ以外は何も変えずにインストールの手順を表示します。
  - 今リンクが指している版は、切り替えの瞬間まで変更しません。途中で失敗・中断しても、今の版はそのまま動きます。
  - アーカイブの中身（パスの `..`、リンク、通常のファイル以外）を検査し、新しい `sumi --version` が期待の版を返すことを確かめてから切り替えます。同時に 2 つの更新は走らせません。
  - 古い版のディレクトリは、既知のリンク（`SUMI_BIN_DIR`、install.sh が記録した場所、`~/.local/bin`）がどれも指していないときだけ消します。
- **`sumi doctor` の更新通知**（#597）: 最新のリリースを 1 日 1 回まで確認し、新しい版があれば 1 行で知らせます。オフラインでは何も出しません。`render` などほかのコマンドは確認しません。CI、`SUMI_NO_UPDATE_CHECK=1`、`--no-update-check` では確認しません。
- **Skill の版の照合**（#597）: Skill は最初に `sumi doctor --skill-version <版>` を実行し、CLI と Skill の版が違えば古い側の更新方法（`sumi update` / `npx skills update sumi`）を示します。このオプションを知らない v0.19.0 以前の CLI では、install.sh での入れ直しを案内します。

v0.19.0 以前には `sumi update` がないため、今回の更新は install.sh で行ってください。次の版からは `sumi update` で更新できます。

```sh
curl -fsSL https://raw.githubusercontent.com/nishide-dev/sumi-diagram/main/install.sh | sh
npx skills update sumi
```

## 互換性

- Figure Schema に `figure.themeOverrides.canvas` が加わりました。既存のプロパティは変わりません。
- **出力が変わる図**: `sumi` テーマの図（背景が白になり、背景から導く色がわずかに白寄りになります）。Skill のベースレイアウト 30 個とギャラリーを再生成しました。`sumi` の SVG はメタデータに `canvas` を記録します。それ以外のテーマの図、作例、論文の再現図の出力は変わりません（版の表記を除く）。
- v0.19.0 以前に描いた `sumi` の SVG を PPTX に変換すると、スライドの背景は当時のクリーム色になります。
- install.sh は `SUMI_HOME/.sumi-install` に導入先を記録するようになりました。
- 固定版 D2 は v0.9.0、同梱フォント・Tabler Icons・Fluent Emoji Flat・Takumi は v0.19.0 と同じです。
- 設計の判断は、[docs/design/decisions](https://github.com/nishide-dev/sumi-diagram/tree/v0.19.1/docs/design/decisions) の `595-sumi-white-canvas.md`、`597-sumi-update.md` を参照してください。
- **既知の制限**: `sumi update` は macOS と Linux（x64・arm64）で、`tar` が必要です。既知の場所以外にある `sumi` のリンクは調べないため、古い版を残すことがあります。
