# Sumi v0.11.0

HTML/CSS で図の部品を書けるようにするリリースです。専用の `html` 部品を加え、その中身のはみ出し・文字の大きさ・欠字を検査し、出力が OS によらず同じであることを CI で確かめます。あわせて、図ごとに Theme を細かく調整する `themeOverrides` を加え、CLIP と EmbeddingGemma 2 の図を作例に加えました。計画は [#236](https://github.com/nishide-dev/sumi-diagram/issues/236)、実装は milestone「[v0.11.0 — HTML content](https://github.com/nishide-dev/sumi-diagram/milestone/22)」です。

## 新しい部品

- **`html`**（[#283](https://github.com/nishide-dev/sumi-diagram/issues/283)）: HTML/CSS の部分集合で書く部品。`props.html` に HTML を、`props.viewport`（例 `320x176`、CSS px）に描く範囲を書きます。大きさは `image` と同じく `width` / `height` で決めます。単独でも、group の中にも置けます。ブラウザなしで描き（Takumi、WASM）、SVG / PDF / 画像 PPTX に出せます。編集可能 PPTX には書き出せません（`pptx/unsupported-asset`）。文字は図形（パス）になるため、PDF では検索できません。
  - 使える要素は `div` / `span` / `p` / `b` / `i` / `br`、属性は `style` だけです。CSS は flex・grid・位置・大きさ・余白・色・枠線・角丸・フォント・`white-space` などの許可した性質と、性質ごとに決めた値の範囲だけを受け付けます。
  - **許可していないものは、黙って無視せず、YAML の行・列を指す error にします**（`asset/unsafe-html`、`asset/unsupported-css`）。URL・画像・`<style>`・スクリプト・グラデーション・影・`overflow` なども同じです。
  - Theme の色とフォントを CSS 変数（`--sumi-fg`、`--sumi-accent`、`--sumi-font`、`--sumi-mono` など、決まった一覧）で使えます。フォントは同梱のもの（Inter・BIZ UDGothic など）だけです。
  - 入力の大きさ（128KiB・512 要素・深さ 24）と viewport の大きさに上限があります。

## 新しい書き方

- **`figure.themeOverrides`**（[#300](https://github.com/nishide-dev/sumi-diagram/pull/300)、[#301](https://github.com/nishide-dev/sumi-diagram/pull/301)）: 選んだ Theme を、その図だけ調整します。どれも任意で、書かなければ Theme のままです。
  - `nodeCorners: square`: ノード・group・matrix / tokens のセル・凡例の枠の角を四角にします。
  - `edgeCorners: sharp`: structured の線の曲がり角と分岐を直角（T 字）にし、線の端と継ぎ目を角張らせます。`nodeCorners` とは独立で、角丸の箱に直角の線を合わせられます。auto（D2）の図の線の経路は D2 のままです。
  - `groupLabelWeight: regular | bold`: group の見出しの太さ。
  - `solidFills: { blue: '#3d9df5', … }`: `solid` の tone の塗りの色を置き換えます。文字は、白で 4.5:1 以上なら白のまま、足りなければ読める濃さまで暗くします。
  - `dashedGroupStroke: '#527da5'`: 破線の group の枠の色だけを変えます。
- **`waveform` の `props.frameStroke`**（#301）: 枠の線の色を、波形の色とは別に指定できます。

## 新しい診断

`html` の中身を、描いた結果を測って検査します（[#293](https://github.com/nishide-dev/sumi-diagram/issues/293)）。位置は `props.html` の中の要素を YAML の行・列で指します。

- **warning** `asset/html-overflow`（新規）: 要素や文字が viewport を 0.5 CSS px を超えてはみ出す。
- **error** `geometry/text-too-small`（既存）: CSS の文字の大きさに配置の縮尺と図の縮小を掛けた最終の大きさが、通常のラベルと同じ Profile の下限より小さい。
- **warning** `lint/missing-glyph`（既存）: 選んだ同梱フォントにない文字（Takumi 内蔵のフォントへの置き換えはカバーと見なしません）。
- **error** `asset/unsafe-html`・`asset/unsupported-css`（新規）: 上の許可していない HTML・CSS。
- `themeOverrides` の未知の項目・不正な値は、既存の `schema/unknown-field`・`schema/invalid-value` で位置を指します。

## 作例

- [`examples/clip/`](https://github.com/nishide-dev/sumi-diagram/tree/v0.11.0/examples/clip): CLIP（Radford et al. 2021）の Figure 1。`matrix`・`bracket`・`mono` と、`nodeCorners: square` / `edgeCorners: sharp`。
- [`examples/embedding-gemma/`](https://github.com/nishide-dev/sumi-diagram/tree/v0.11.0/examples/embedding-gemma): EmbeddingGemma 2 の Figure 1。文字カードとコード窓を `html` で、音声を `waveform` で、トークン列を `tokens` で描いています。
- README に 2 つの図を加えました。写真の部分は自作の合成画像です。

## 互換性

- Figure Schema は任意の追加だけです。CLI のコマンドは変わりません。
- **枠の中に文字のない `waveform` は、波形の中心を枠の高さの中央に置くようになりました**（#301）。v0.10.0 では、枠の中の文字のための場所を空けて高さの 35% に置いていたため、波形が上に寄っていました。枠の中に文字のある `waveform` は v0.10.0 と同じです。
- それ以外の図の SVG / PDF / PPTX / D2 は、v0.10.0 と同じです（版に関する metadata を除く）。
- **新しい依存**: `@takumi-rs/wasm` 2.19.0（MIT OR Apache-2.0）と `entities` 9.0.0（BSD-2-Clause）。配布物は約 4.1 MiB 大きくなります。Takumi が含む第三者のライセンス表記を配布物に同梱しました（`assets/licenses/takumi/`）。
- `html` の出力は、Ubuntu・macOS と配布バイナリで byte 単位で同じであることを CI で確かめています（[#294](https://github.com/nishide-dev/sumi-diagram/issues/294)）。
- 固定版 D2 は v0.9.0、同梱フォント・Tabler Icons・Fluent Emoji Flat は v0.10.0 と同じです。
- 既知の制限: 絶対配置の子の近くにある欠字の警告が、1 つ外側の要素を指すことがあります（警告は出ます。[#298](https://github.com/nishide-dev/sumi-diagram/issues/298)）。
- 設計の詳細は、[設計 §6.81〜§6.85](https://github.com/nishide-dev/sumi-diagram/blob/v0.11.0/docs/design/phase1.md)を参照してください。
