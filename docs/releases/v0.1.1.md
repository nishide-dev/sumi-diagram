# Sumi v0.1.1

v0.1.0 の不具合を修正したリリースです。図の出力（SVG）は v0.1.0 と同じです（メタデータの `sumi-version` だけが変わります）。

## 修正

- `sumi` の標準出力をパイプで渡した先のコマンドが先に終了した場合（例: `sumi catalog --json | head -1`）に、`EPIPE: broken pipe` のスタックトレースを表示していた問題を修正しました。読み手がいなくなった後も処理は最後まで続け（`render` の SVG や `fmt` の書き換えは完了します）、終了コードはコマンド本来の 0 / 1 / 2 を返します。`EPIPE` 以外の標準出力・標準エラーへの書き込み失敗（ディスクの空き不足など）は終了コード 2 とし、標準エラーに書き込める場合は 1 行のエラーを表示します（#49）。

## インストール

手順は v0.1.0 と同じです。`version=0.1.1` として、[v0.1.0 のリリースノート](v0.1.0.md) または README の「インストール（リリース版）」に従ってください。v0.1.0 から更新する場合は、展開したディレクトリを置き換えてください。

## 互換性と既知の制約

v0.1.0 から変更はありません（D2 v0.9.0 と同梱フォントに固定、Windows 版なし、macOS のバイナリは公証なし、npm 非公開）。
