# Sumi v0.4.0

論文に載せるブロック図・モデルアーキテクチャ図を描けるようにしたリリースです。Sumi 自身が配置と線を決める構造的配置（structured）を追加し、ラベル内の数式、同梱アイコン、ユーザー画像に対応しました。調査は [#86](https://github.com/nishide-dev/sumi-diagram/issues/86)（[調査メモ](https://github.com/nishide-dev/sumi-diagram/blob/v0.4.0/docs/research/86-paper-figures.md)）、実装は milestone「v0.4.0 — Structured layout (paper figures, stage A)」です。機能追加のため minor リリースとします。

## 構造的配置（structured）

```yaml
figure:
  id: encoder
  layout:
    arrange:            # これがあれば structured（engine: structured を書かなくてよい）
      stack: { direction: up, gap: 0, items: [mha, norm] }
```

- 図全体や group の中を、`stack`（縦）と `row`（横）の入れ子で並べます。`gap`（単位付き長さ）、`align`（start / center / end / stretch）、向きは箱ごとに指定します。
- `attach` は、要素を別の要素の横に添えます。図 A の「N×」や位置エンコーディングの記号が、この使い方です。
- 線は、Sumi の直交ルータが引きます。
  - `fromAnchor` / `toAnchor`（例 `south:0.15`）で、付く辺と位置を指定できます。
  - `junction` で分岐し、同じ出口の線は幹線を共有します。残差の迂回線も、この仕組みで引きます。
  - 角は丸めます（半径は最大 4pt。周囲の要素との間が狭いところでは小さくするか、丸めません）。SVG・PDF・画像方式 PPTX に反映されます。黒丸のある分岐点の合流と、編集可能 PPTX では角ばったままです。
- 経路が見つからない場合は `layout/no-route`、置き忘れは `layout/unplaced` など、配置の誤りは YAML の位置付きのエラーになります。
- **既定は従来の自動配置（D2/ELK）のままです。** structured になるのは、`figure.layout.arrange` を書いた図だけです。既存の YAML の描画結果は変わりません。structured 専用のフィールドを自動配置の図で使うと、`layout/structured-only` になります。
- structured の図は D2 を使わずに描画します。フォントは使う文字だけを SVG に埋め込みます。`--emit-d2` は使えません。

## 新しい部品・tone・color テーマ

- `operator`（plus / minus / times / dot / concat の記号を丸に描く）と、`junction`（分岐点）を追加しました。
  - 分岐点の黒丸を出さない場合は `variant: hidden` を使います。既定は黒丸ありで、合流と交差を見分けるためです。
  - 1 本だけの線を hidden の junction へ向けると、何もない先への矢印になります。
- node と group に `tone`（gray / red / orange / yellow / green / blue / purple / pink）を書けます。色の値はテーマが持ちます。
- 色つきの汎用テーマ `color` を追加しました。既存の minimal / academic / slides は、tone を 3 段階の灰色に割り当てます（同じ段階の tone は同じ見た目）。

## ラベル内の数式（structured のみ）

```yaml
label: '$\gamma_1,\beta_1$'
```

- `$...$` の中で、ギリシャ文字、`_` / `^`（1 段。両方を付けると縦に重ねず、書いた順に横に並べます）、記号・関数名のコマンド（`\times`、`\leq`、`\oplus`、`\log`、`\text{}` など）を使えます。`\frac` などの未対応の記法は `component/invalid-math` です。カンマの後に空白は入らないので、必要なら `\,` を書きます。
- 文字は実テキストとして出力するため、PDF で検索・抽出できます（上の例は `γ1,β1`。`\,` を書いた場合は、細い空白 U+2009 も含みます）。
- STIX Two Math / STIX Two Text Italic v2.13（OFL）を同梱しました。フォントの追加で、tarball は約 0.96MiB 増えます（darwin-arm64 での実測。アイコンの追加分は別に約 0.26MB）。
- 編集可能 PPTX（実験的）では、数式は上付き・下付きの属性を持つテキストになります。フォントは埋め込まないため、表示する環境に BIZ UD ゴシックと STIX Two が必要です。
- 自動配置の図では数式を描けません。同じ行で閉じた `$...$` の中にコマンド・`_`・`^` があるときだけ `component/unsupported-in-auto`（warning）を出し、ラベルは書いたとおりに表示します。`$x$` や v0.3 までの `$5` のようなラベルは、警告なしでそのまま表示されます。

## アイコンと画像

- `icon: tabler/<name>` で、Tabler Icons 3.49.0（MIT）を使えます。Brand を除く 4,808 個を同梱しています。名前は `sumi catalog --icons "<語>"` で探せます。
  - アイコンはラベルの代わりに描き、色は文字の色に合わせます。
  - ロゴ（商標）は同梱しません。
- `component: image` で、ユーザーの PNG / JPEG / SVG を埋め込めます。Sumi は画像を描画・加工しません。

  ```yaml
  - id: frame
    component: image
    variant: framed          # 枠を付ける（省略時は枠なし）
    props:
      src: assets/frame.png  # YAML からの相対パス
      width: 85pt            # width か height の少なくとも一方が必須（もう一方は縦横比から決まる。0.5pt 単位）
      fit: contain           # contain / cover / fill
      # sha256: <画像の実際の sha256（16進64文字）>   # 任意。ファイルの内容を固定する
  ```

  - `src` は YAML のディレクトリの外を指せません（URL・絶対パス・外に出るシンボリックリンクも不可）。ファイルの大きさと画素数には上限があります。前提は、図のディレクトリを他のプロセスが同時に書き換えないことです。Linux 以外では、その競合を完全には防げません（設計 §6.25）。
- SVG は許可リストで取り込みます。
  - スクリプト、イベント属性、外部参照、DTD、foreignObject などは、`asset/unsafe-svg` として位置付きのエラーになります。
  - 基本図形とパス以外（テキスト、グラデーション、`defs`、クリップ、マスク、フィルタなど）は、`asset/unsupported-svg` として取り込みません。複雑な SVG は、図形だけに変換してから使ってください。
- 両方の配置方式で使えます。アイコンか画像を使った図は、出力に `assets-sha256`（PDF / PPTX では `SumiAssetsSha256`）を記録します。同梱アイコンを使った図だけ、Tabler のライセンス表示も記録します。編集可能 PPTX では、アイコンと画像を `pptx/unsupported-asset` で拒否します。

## 互換性と検証

- Figure Schema は v1 のままで、追加はすべて任意フィールドと部品です。既存の図の SVG / PDF / PPTX は、metadata の `sumi-version` が `0.4.0` になる以外、変わりません。
- structured の SVG は、metadata の `backend` が `sumi-structured` で、`d2-sha256` を持ちません。PDF / PPTX の provenance からも、D2 の hash を省きます。
- 新しい診断を追加しました: stage `layout` の `layout/*`、`asset/*`、`component/invalid-math`、`component/unsupported-in-auto`、`theme/missing-tone`、`geometry/edge-through-node`（warning）、`pptx/unsupported-asset`。
- 配布物に `licenses/stix-two/`、`licenses/tabler-icons/` と NOTICE の項目を追加しました。
- 固定版 D2 は **v0.9.0**、BIZ UD Gothic は **1.051** のままです。
- 設計の詳細は、[設計 §6.19〜§6.26](https://github.com/nishide-dev/sumi-diagram/blob/v0.4.0/docs/design/phase1.md#619-88-の構造的配置のスキーマと検査) を参照してください。
