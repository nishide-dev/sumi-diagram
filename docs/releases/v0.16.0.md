# Sumi v0.16.0

論文の図をそのまま載せられる品質で描くための版です。集合の囲み、アイコンに添える特徴ベクトル、見本付きの凡例、配色パレット、線の太さ、流れの矢印などの部品を加えました。あわせて、密度と配色を診断する lint を足し、Skill に「見た目の方針を先に決める」「基準の図と並べて批評する」手順を入れています。基準として、TriCL と LLaDA の概要図の再現を例に加えました。計画は [#236](https://github.com/nishide-dev/sumi-diagram/issues/236)、実装は milestone「[v0.16.0 — Sets and visual language](https://github.com/nishide-dev/sumi-diagram/milestone/29)」です。

## 新しい部品と書き方

- **集合の囲み `sets`**（[#407](https://github.com/nishide-dev/sumi-diagram/issues/407)、[#430](https://github.com/nishide-dev/sumi-diagram/issues/430)）: 図のトップレベルの `sets:` に、ノードやグループを囲む円・楕円・凸包・角丸の四角を書きます。1 つのノードが複数の集合に入れるので、ベン図やハイパーグラフの hyperedge を描けます。
  - `shape: ellipse` に `angle: auto` を付けると、メンバーの並びに合わせて傾いた楕円を当てはめます。
  - 塗りは白に混ぜた不透明な淡い色です。重なった部分の色は計算して描くので、どの背景の上でも濁りません（[#440](https://github.com/nishide-dev/sumi-diagram/issues/440)）。
  - structured レイアウトで使えます。
- **ノードの添え物 `glyphs`**（[#408](https://github.com/nishide-dev/sumi-diagram/issues/408)）: 小さな特徴ベクトル（色付きのセルの列）、点、pill を、ノードの角や辺の 8 か所に添えます。`strength: solid` で濃い色のセルにできます。
- **アイコンの大きさと色**（[#424](https://github.com/nishide-dev/sumi-diagram/issues/424)、[#445](https://github.com/nishide-dev/sumi-diagram/issues/445)）:
  - `iconSize` で、アイコンを丸や箱で囲まずに大きく描けます。大きくしても線の太さは変わりません。
  - アイコンだけのノードは、`tone` の線の色で描かれます。
- **凡例の見本**（[#409](https://github.com/nishide-dev/sumi-diagram/issues/409)、[#446](https://github.com/nishide-dev/sumi-diagram/issues/446)）: 凡例の項目に、アイコン、添え物、集合の塗り、辺の種類を見本として置けます。
  - `flow: row` と `perRow` で横に並べ、`heading` で見出しを付けられます。
  - `headings: inline` を付けると、見出しのまとまりを同じ行に続けて並べます。まとまりの途中では改行しません。
- **流れの矢印**（[#426](https://github.com/nishide-dev/sumi-diagram/issues/426)）: 段階のパネルの間に置く部品として、`block-arrow`（➡）、`triangle-arrow`（▶）、`chevron` を加えました。
- **線の太さと種類**（[#427](https://github.com/nishide-dev/sumi-diagram/issues/427)）: `themeOverrides` で図全体の `lineWidth`・`frameWidth`・`arrowheadScale`・`cornerRadius` を指定でき、要素ごとにも上書きできます。辺・グループ・集合に `variant: dotted`（丸い点線）を使えます。

## 配色

- **配色パレット**（[#417](https://github.com/nishide-dev/sumi-diagram/issues/417)、[#423](https://github.com/nishide-dev/sumi-diagram/issues/423)、[#444](https://github.com/nishide-dev/sumi-diagram/issues/444)）: `themeOverrides.palette` で、8 つの組み込みパレット（`cool-blue`・`slate`・`coral`・`terracotta`・`sage`・`lavender`・`cyan-pink`・`seafoam`）から選べます。どのテーマにも使えます。
  - 色は [Color Hunt](https://colorhunt.co/palettes/popular) の人気パレットから値だけを採りました。
  - パレットの 4 色は、テーマの色の役割（パネル・塗り・強調・文字）に割り当てます。tone もパレットの明るさ・彩度に合わせて作るので、図全体の色がそろいます。
  - 暖色の濃い塗りが茶色に寄らないよう補正しています。
  - コントラスト、グレースケール、色覚の違いでの見分けやすさは、テストで確かめています。
- **paper テーマ**:
  - tone を、淡い塗りと調和した線の組に見直しました（[#434](https://github.com/nishide-dev/sumi-diagram/issues/434)）。
  - 既定のパネル（グループ）を、白地に 0.5pt の淡い灰色の枠にしました（[#440](https://github.com/nishide-dev/sumi-diagram/issues/440)）。灰色の面は、`variant: filled` や `groupFill` を指定したときだけになります。

## 診断（lint）

- **密度**（[#422](https://github.com/nishide-dev/sumi-diagram/issues/422)）: `geometry/sparse-figure` と `geometry/text-heavy-nodes`（info）。論文の図で、要素がまばらな図と、文字の多い箱を知らせます。
- **配色**（[#423](https://github.com/nishide-dev/sumi-diagram/issues/423)、[#440](https://github.com/nishide-dev/sumi-diagram/issues/440)）:
  - `geometry/color-harmony`（info）: 色相が多すぎる、明るさのばらつきが大きいなどの不調和を知らせます。
  - `geometry/muddy-color`（warning）: 実際に描かれる色を重ね合わせて計算し、白地のときより濁った色を知らせます。
  - `geometry/translucent-over-color`（warning）: 半透明の塗りが白以外の面に重なっているときに出ます。
  - `geometry/color-on-panel`（info）: 色付きのパネルに色付きの要素が多く乗っているときに出ます。
- **集合**（[#407](https://github.com/nishide-dev/sumi-diagram/issues/407)、[#420](https://github.com/nishide-dev/sumi-diagram/issues/420)）:
  - `geometry/set-contains-non-member`: メンバーでないノードが囲みに入っているときに出ます。
  - `geometry/set-label-collision`: 集合のラベルがほかの文字や線にぶつかっているときに出ます。
  - `geometry/set-outline-crosses-text`: 集合の輪郭が文字を横切っているときに出ます。
- **そのほか**:
  - `geometry/glyph-collision`: 添え物がほかの要素にぶつかっているときに出ます（[#408](https://github.com/nishide-dev/sumi-diagram/issues/408)）。
  - `lint/icon-enclosure`（info）: アイコンを大きく見せるためだけに丸や箱で囲んでいるときに出ます（[#424](https://github.com/nishide-dev/sumi-diagram/issues/424)）。
  - 論文の図の試行で見つかった問題の修正（[#411](https://github.com/nishide-dev/sumi-diagram/issues/411)）。辺のラベルの置き場所、幅いっぱいに伸ばした tokens からの線の起点、枠線の上を走る線の検出、`arrowhead-cramped` の誤検出、プレビューの出力先を直しました。

## Skill

- **見た目の方針を先に決める**（[#410](https://github.com/nishide-dev/sumi-diagram/issues/410)、[#440](https://github.com/nishide-dev/sumi-diagram/issues/440)）: 論文の図を書く前に、図に出てくるものの種類ごとに描き方（アイコン、特徴ベクトル、集合、矢印、番号付きの列）と色を表にします。
  - 守る方針: 文字と式は最小限にする。凡例は 1 か所にまとめる。背景は白にし、色は意味のあるものだけに少数使う。
- **基準の図と並べて批評する**（[#435](https://github.com/nishide-dev/sumi-diagram/issues/435)、[#447](https://github.com/nishide-dev/sumi-diagram/issues/447)）: `scripts/compare` で、描いた図と近い例を同じ幅で並べます。点検表に沿って批評し、直します。
  - 点検表: 密度と空き、大きさのそろい、見た目の統一、配色、文字の量、段階の流れ、主役。
  - 大きさや色のように測れる指摘は、YAML や `sumi` の出力で確かめてから対応します。
- **プレビュー**（[#411](https://github.com/nishide-dev/sumi-diagram/issues/411)）: `scripts/preview` は、PNG を SVG の隣に出し、`-o` で出力先を指定できます。

## 例

- **密度の基準**:
  - **TriCL**（[#420](https://github.com/nishide-dev/sumi-diagram/issues/420)、[`examples/tricl/`](https://github.com/nishide-dev/sumi-diagram/tree/v0.16.0/examples/tricl)）
  - **LLaDA**（[#421](https://github.com/nishide-dev/sumi-diagram/issues/421)、[`examples/llada/`](https://github.com/nishide-dev/sumi-diagram/tree/v0.16.0/examples/llada)）
  - どちらも論文の概要図の再現で、色を含めて元の図に合わせています。
- **再現図の色の固定**（[#441](https://github.com/nishide-dev/sumi-diagram/issues/441)）: 論文の図の再現（transformer・dit-block・clip・embedding-gemma・gcn・llama4-moe・tricl・llada）の色と線の太さを、元の図から取って YAML に書きました。テーマの既定値を変えても、これらの図は変わりません。テストでも、テーマの色や線の既定値を差し替えて描いたときに再現図が変わらないことを確かめています。

## 互換性

- Figure Schema への追加は任意のものだけです。CLI のコマンドは変わりません。
- **出力が変わる図**:
  - `paper` テーマで、tone や既定のパネルに頼っている図。tone の色が変わり、パネルは白地に淡い灰色の枠になります。灰色のパネルが必要なら、`variant: filled` か `themeOverrides.groupFill` を指定します。
  - 論文の再現図（transformer・dit-block・clip・embedding-gemma・gcn・llama4-moe）。元の図の色と線の太さに合わせました。
  - 集合（`sets`）を使う図は、重なった部分の色の計算方法が変わります。白地の上では、重なっていない部分の見た目は同じです。
  - ギャラリーの見本の多く。
- それ以外の既存の図の SVG / PDF / PPTX / D2 は、v0.15.2 と同じです（版に関する metadata を除く）。
- 固定版 D2 は v0.9.0、同梱フォント・Tabler Icons・Fluent Emoji Flat・Takumi は v0.15.2 と同じです。
- 設計の判断は、[docs/design/decisions](https://github.com/nishide-dev/sumi-diagram/tree/v0.16.0/docs/design/decisions) の各ファイル（#407〜#447）を参照してください。

## インストールと更新

```sh
curl -fsSL https://raw.githubusercontent.com/nishide-dev/sumi-diagram/main/install.sh | sh
```

版を固定するときは `SUMI_VERSION=0.16.0` を付けます（README の[インストール](https://github.com/nishide-dev/sumi-diagram/blob/v0.16.0/README.md#install)）。Skill は `npx skills add nishide-dev/sumi-diagram --skill sumi` で更新します。

公開準備は [#452](https://github.com/nishide-dev/sumi-diagram/issues/452) です。今後の計画は [#236](https://github.com/nishide-dev/sumi-diagram/issues/236) で管理します。
