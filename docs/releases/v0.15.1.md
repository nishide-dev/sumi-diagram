# Sumi v0.15.1

Meta の Llama 4 の発表記事の図の色合いで描ける組み込みテーマ `llama` と、開いた（塗らない）矢じりを加え、その Mixture of Experts の図を再現した例を追加しました。あわせて、分岐する線の描き方を 2 つ直しました。計画は [#236](https://github.com/nishide-dev/sumi-diagram/issues/236)、実装は milestone「[v0.15.1 — Llama theme](https://github.com/nishide-dev/sumi-diagram/milestone/27)」です。

## テーマ `llama`

- **組み込みテーマ `llama`**（[#386](https://github.com/nishide-dev/sumi-diagram/issues/386)）: [Llama 4 の発表記事](https://ai.meta.com/blog/llama-4-multimodal-intelligence/)の図の色合いです。`paper-single` と `paper-double` で使えます。フォントは `paper` と同じ Inter です。
  - variant が原図の要素に対応します: 既定は白地に灰色の枠（Expert）、`solid` は濃い青灰色に白い文字（Attention）、`emphasis` は青（Shared Expert）、`filled` は枠のない灰色（Router）、`muted` は枠のない淡い灰青（FFN）。グループの既定は枠のない淡いパネル、`muted` は白いパネルです。
  - 線と枠は 1pt、強調の線は 1.5pt、`zoom` の線は 0.5pt の細い破線です。8 つの tone はほかの図でも使えます。
- **矢じりの形**（#386）: テーマに `arrowhead: triangle | open` を加えました。`llama` は `open`（開いた山形）、ほかのテーマは従来どおり `triangle` です。
  - structured の図では、山形は矢じりのために確保している場所の中に収まり、先端は線の太さの分だけ箱から離れます。auto（D2）の図では先端は箱に接します。
  - SVG・PDF・picture PPTX で描き、editable PPTX では PowerPoint の開いた矢じり（`arrow`）になります。部品の定義でも `head: open` を使えます。
  - `sumi catalog --json` の各テーマに `arrowhead` を示します。

## 例

- **Llama 4 の Mixture of Experts**（[#387](https://github.com/nishide-dev/sumi-diagram/issues/387)、[`examples/llama4-moe/`](https://github.com/nishide-dev/sumi-diagram/tree/v0.15.1/examples/llama4-moe)）: Attention と FFN を交互に積んだ列、`zoom` の破線で拡大した MoE のパネル、Routed Experts と Shared Expert、⊕ を `llama` テーマで描きます（156.28mm × 107.77mm、縮小なし、診断なし）。原図の画像は使っていません。

## 線の描き方の修正

- **分岐の角**（[#385](https://github.com/nishide-dev/sumi-diagram/issues/385)）: hidden junction が、矢じりのための場所の少し手前にあると、幹がいったん横線より上に出てから戻り、小さな角とはみ出しができていました。junction を横線の高さに動かし、幹がまっすぐ横線に入るようにしました。
  - 動かすのは、配置の制約（`align`・`centerOn`・`place`）、ほかの要素との重なり、グループの境界、直線・曲線の辺に影響しないと確かめられたときだけです。
- **高さの違う相手への分岐**（[#390](https://github.com/nishide-dev/sumi-diagram/issues/390)）: 1 つの hidden junction から、同じ行に並ぶ高さの違う相手（Expert の箱の間の「···」など）に分かれる線が、別の高さの横線に分かれて段差と二重の線ができていました。全員が 1 本の横線を共有するようにしました（低い相手への矢印が長くなります）。
  - 間隔が狭く、矢じりの直線部分が短くなる場合や、別の行の相手の場合は、従来の経路のままです。

## 互換性

- Figure Schema とテーマの定義は任意の追加だけです。CLI のコマンドは変わりません。
- 出力が変わる図:
  - `examples/transformer`（と Skill の同じ例、`paper`・`academic` などのテーマのギャラリーの見本）: decoder の中段の分岐の幹（#385）。
  - hidden junction から同じ行の高さの違う相手に分かれる図（#390）。リポジトリの既存の図には該当がありません。
- それ以外の既存の図の SVG / PDF / PPTX / D2 は、v0.15.0 と同じです（版に関する metadata を除く）。
- 固定版 D2 は v0.9.0、同梱フォント・Tabler Icons・Fluent Emoji Flat・Takumi は v0.15.0 と同じです。
- 設計の判断は [docs/design/decisions](https://github.com/nishide-dev/sumi-diagram/tree/v0.15.1/docs/design/decisions) の各ファイル（#385、#386、#390）を参照してください。

## インストールと更新

```sh
curl -fsSL https://raw.githubusercontent.com/nishide-dev/sumi-diagram/main/install.sh | sh
```

版を固定するときは `SUMI_VERSION=0.15.1` を付けます（README の[インストール](https://github.com/nishide-dev/sumi-diagram/blob/v0.15.1/README.md#install)）。Skill は `npx skills add nishide-dev/sumi-diagram --skill sumi` で更新します。

公開準備は [#393](https://github.com/nishide-dev/sumi-diagram/issues/393) です。今後の計画は [#236](https://github.com/nishide-dev/sumi-diagram/issues/236) で管理します。
