# Sumi v0.17.1

v0.17.0 の見た目の細部を直す版です。集合の重なりを色の平均で不透明に塗るのを既定にし、waveform のラベルを枠の外へ出し、html カードの framed の角と `sumi` / `sumi-dark` の補助の文字色を直しました。README の仕組みの図も描き直しています。実装は milestone「[v0.17.1](https://github.com/nishide-dev/sumi-diagram/milestone/34)」です。

## 集合

- **重なりは色の平均**（[#492](https://github.com/nishide-dev/sumi-diagram/issues/492)、[#505](https://github.com/nishide-dev/sumi-diagram/issues/505)）: 塗りのある集合が重なる領域を、各色の知覚的な平均（OKLCH の明度・彩度の平均と色相の円平均）で不透明に塗ります。これまでの積による重ね塗りは、重なりが暗く濁り、半透明を重ねたように見えていました。
  - `figure.setOverlap` で図全体の既定を、`sets[].overlap` で集合ごとに `mix`（既定）か `multiply`（従来の積）を選べます。指定の異なる集合が交差する領域は `multiply` を優先します。
  - 3 つ以上の集合の重なりも、参加するすべての色の平均です。SVG・PDF・PPTX（画像・編集可能）と幾何 lint は同じ色を使います。
  - 重なりの領域が 1024 を超えると `layout/set-overlap-budget`（warning）が出ます。
  - 角丸の `rect` の集合は、重なりの領域も角丸に沿うようになりました。

## コンポーネント

- **waveform のラベルは枠の外**（[#491](https://github.com/nishide-dev/sumi-diagram/issues/491)）: `label` を枠の下の中央にキャプションとして置きます。枠の中は信号だけになり、自動サイズの枠は 80×48pt です（従来はラベルの分だけ縦長でした）。structured では整列と接続の基準は枠のままで、線はキャプションを避けます。
- **emphasis の waveform の信号**（#491）: 信号が塗りと同じ色で見えなかったのを、塗りの上で読める文字色で描くようにしました。

## HTML カード

- **framed の角**（[#490](https://github.com/nishide-dev/sumi-diagram/issues/490)）: framed の枠を、カードのルート要素の位置・大きさ・角丸に合わせます。角丸のカードの外側に四角い枠が出ていたのを直しました。
- **`--sumi-muted`**（[#496](https://github.com/nishide-dev/sumi-diagram/issues/496)）: `sumi` / `sumi-dark` でテーマの補助の文字色（`#4e566b` / `#acbac4`）になります。`sumi-dark` で `#666666` に落ちて読めなかったのを直しました。

## README と Web サイト

- **仕組みの図**（[#493](https://github.com/nishide-dev/sumi-diagram/issues/493)）: Sumi Skill の手順で描き直しました。エージェント（Claude Code・Codex のアイコン）、`.sumi.yaml` と JSON の診断のカード、Sumi CLI の範囲（catalog → compile → layout → render → geometry lint）を示します。`sumi` / `sumi-dark` の色で、背景は透明です。README では列の幅いっぱいに、Web サイトでは本文の幅（46rem）までで表示します（[#503](https://github.com/nishide-dev/sumi-diagram/issues/503)）。
- Web サイトの favicon をメンテナーの GitHub のアイコンにしました。

## 互換性

- Figure Schema への追加は任意のもの（`figure.setOverlap`、`sets[].overlap`）だけです。
- **出力が変わる図**:
  - 塗りのある集合が重なる図。重なりの色が変わります。従来の色は `figure.setOverlap: multiply` で戻せます。
  - ラベル付きの waveform。ラベルが枠の外に出て、枠が小さくなります。emphasis の waveform は信号が見えるようになります。
  - framed の html カードと、`sumi` / `sumi-dark` で `--sumi-muted` を使う html カード。
- コミット済みの作例と論文の再現図は変わりません（版の表記を除く）。
- 固定版 D2 は v0.9.0、同梱フォント・Tabler Icons・Fluent Emoji Flat・Takumi は v0.17.0 と同じです。
