# Sumi v0.3.1

v0.3.0 の不具合を修正したリリースです。

## 修正

- カスタム輪郭の部品（`trapezoid` / `stack`）に入るエッジが、レイアウトの都合でわずかに傾いている場合に、`svg/outline-edge-miss` の warning が出て、輪郭への延長も行われない問題を修正しました（#82）。
  - ひし形・楕円・円とカスタム輪郭の部品を直線のエッジでつなぐと、ELK はほぼ垂直・水平（実測で最大約 1.3°）の経路を引きます。v0.3.0 は軸に厳密に平行な端点だけを延長していたため、単純な縦並びの図でも warning になり、台形の斜めの辺に入るエッジでは輪郭との間に隙間（実測で約 6〜8pt）が残っていました。
  - 端点が実際に入る辺の法線から 5° 以内なら、エッジの進行方向に沿って輪郭まで延長します。延長が不要な端点（輪郭と配置用の矩形が一致する辺）では warning を出しません。射線が輪郭に当たらない場合や傾きが大きい場合は、従来どおり warning になります。

## 出力への影響

- カスタム輪郭の部品に、わずかに傾いたエッジが斜めの辺から入る図では、エッジの端点の位置が変わります（隙間がなくなります）。これ以外の図の SVG・PDF・PPTX は、メタデータのバージョン表記を除いて v0.3.0 と同じです。

## インストールと更新

READMEの[インストール手順](../../README.md#インストールリリース版)で `version=0.3.1` を指定してください。旧版からは展開ディレクトリを丸ごと置き換え、`sumi --version` と `sumi doctor` を確認してください。

## 互換性と既知の制約

v0.3.0 から変更はありません（[v0.3.0 のリリースノート](v0.3.0.md)を参照）。
