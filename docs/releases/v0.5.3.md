# Sumi v0.5.3

論文図の段階 C（[#167](https://github.com/nishide-dev/sumi-diagram/issues/167)、[計画](https://github.com/nishide-dev/sumi-diagram/blob/v0.5.3/docs/research/167-stage-c.md)）の前に、Transformer・DiT などの図を描いて見つかった structured の不具合を直したパッチリリースです。Figure Schema の書き方は追加していません。実装は milestone「[v0.5.3 — Stage C prerequisite fixes](https://github.com/nishide-dev/sumi-diagram/milestone/15)」です。

## 不具合の修正

- **ほぼ揃った端の辺が、送り元を一周する問題を直しました**（[#169](https://github.com/nishide-dev/sumi-diagram/issues/169)）。
  - 向かい合う 2 つの端が 1 unit 未満ずれていると、まっすぐ引けるはずの辺が送り元をぐるりと回ることがありました。たとえば、`align: stretch` で広げた箱と、その上の中央揃えの ⊕ は、座標の丸めで 0.001 unit ずれることがありました。4 桁に丸めた anchor でも起きていました。
  - 向かい合う端のずれが 1pt（2 unit）以下なら、片方の端を辺に沿って動かし、まっすぐな線にします。ほかの辺と共有していない端だけを動かします。**`fromAnchor` / `toAnchor` で書いた端も、この範囲で動くことがあります**。
  - ずれがそれより大きく、箱の間が狭い場合は、短い S 字で引けるようにしました（途中の列がほかの箱や線で塞がれていれば、回り道が残ることがあります）。
  - どちらの端も動かせない場合（ほかの辺と共有している、移動先が辺の範囲外や別の端の位置になる）は、新しい warning `layout/unaligned-ends` で知らせます（下記）。
- **辺のラベルの背景を、その下に塗られている色にしました**（[#170](https://github.com/nishide-dev/sumi-diagram/issues/170)）。
  - structured の辺のラベルの背景は常に白で、灰色や tone の塗りのある group の上では白い四角になっていました。描く順に group の塗りを重ねた色（透明な group は飛ばし、なければ背景の白）を使います。編集可能 PPTX も同じ色です。
- **group の中で横から入る矢じりの前に、余白を取るようにしました**（[#171](https://github.com/nishide-dev/sumi-diagram/issues/171)）。
  - 線の太い Theme（`minimal`・`color`）では、同じ group の中で横から入る辺（Transformer の残差など）が、group の枠から 0.35mm のところを走っていました。矢じりの長さが Theme の線の太さで変わり、group の余白に足りなかったためです。どの Theme でも、足りない側だけ group の余白を広げて配置し直します（最大 3 回）。
- **中を塗らない矢じりの内側を、その下の塗りにしました**（[#192](https://github.com/nishide-dev/sumi-diagram/issues/192)）。
  - #170 と同じ規則です。組み込みの Theme の矢じりはすべて塗りつぶしなので、今の出力は変わりません。編集可能 PPTX の矢じり（線の端の形）は内側の色を持てないため、従来どおりです。

## 診断の追加と改善

- **`layout/unaligned-ends`（warning）**: structured の図で、向かい合う端が 0 を超え 1pt 以下ずれたまま、どちらの端も動かせずに揃えられない辺を報告します（#169）。細い段差・細い S 字・一周のどれになったかを示します。hint は、両方の端に同じ位置を書く、片方の端に専用の位置を与える、という直し方を示します。
- `layout/align-search-limit` のメッセージに示す配置計算の上限の数は、#171 の配置し直しと上限を分け合うため、その回に残った上限になりました。

## 互換性

- Figure Schema と CLI は変わりません。上の新しい診断コードを追加しました。既存のコードと severity は変わりません。
- auto（D2/ELK）の図の SVG / PDF / 画像方式 PPTX は、版に関する metadata（`sumi-version` など）を除いて変わりません。
- structured の図は、次の場合に出力が変わります。
  - 塗りのある group の中に、ラベルのある辺がある（#170）。同梱の作例では `examples/dit-block` の α・γ のラベルの背景が、白から panel の灰色になりました。`academic` の既定の group は透明なので、その中のラベルは白のままです。
  - 同じ group の中で横から矢じりが入り、矢じりの前の長さと間隔に group の余白が足りない（#171）。足りない側の余白が数 unit 広がります。線の太い `minimal`・`color` で起きやすく、`academic` でも、端から枠まで 14 unit 未満なら広がります。同梱の作例とギャラリーの見本は、それぞれの Theme では変わりません。Theme を変えて描くと、幅が紙の上限を超えることがあります（研究用の #135 の seq2seq 図を `color` で描くと 88.02mm で、`geometry/exceeds-page-width` の error）。
  - 向かい合う端が 1pt 以下ずれている（#169）。段差がまっすぐな線になり、`fromAnchor` / `toAnchor` の端が最大 1pt 動くことがあります。同梱の作例とギャラリーの見本は変わりません。
- **辺の `fill` の意味が変わりました**（#170）。structured の図では、辺のスタイルの `fill` はラベルの背景を描くかどうか（`transparent` なら描かない）だけを決め、色は使いません。組み込みの Theme はどれも白なので、見た目は変わりません。
- **編集可能 PPTX**（#170）: ラベルの背景は、SVG でそのラベルの直前に描いた四角の色を使います。auto（D2）の図でも、組み込みの Theme では従来どおり白です。
- 固定版 D2 は v0.9.0、同梱フォントは BIZ UD Gothic 1.051 と STIX Two 2.13、Tabler Icons は 3.49.0 のままです。
- 設計の詳細は、[設計 §6.40〜§6.43](https://github.com/nishide-dev/sumi-diagram/blob/v0.5.3/docs/design/phase1.md#640-169-のほぼ揃った端で一周しない) を参照してください。
