# Sumi v0.6.0

論文図の段階 C です。Transformer（Vaswani et al. 2017, Fig. 1）・DiT（Peebles & Xie 2023, Fig. 3）・H3-World 系の概要図のような論文図を、論文にそのまま載せられる品質で作り込むための機能を足しました。計画は [#167](https://github.com/nishide-dev/sumi-diagram/issues/167)（[調査](https://github.com/nishide-dev/sumi-diagram/blob/v0.6.0/docs/research/167-stage-c.md)）、実装は milestone「[v0.6.0 — Paper figures stage C](https://github.com/nishide-dev/sumi-diagram/milestone/16)」です。

3 図を新しい書き方で描き直した記録は [research/185-acceptance](https://github.com/nishide-dev/sumi-diagram/blob/v0.6.0/research/185-acceptance/README.md) にあります（`theme: paper`。Transformer は 0 error・0 warning・0 info、DiT と H3-World は縮小で添字が 5pt を下回る info 1 件だけ）。

## 新しい書き方

すべて Figure v1 への任意のフィールド・値・部品・Theme の追加です。特に書かない限り structured の図だけで使えます（auto の図では `layout/structured-only`）。

### 見た目（Theme と variant）

- **Theme `paper`**（[#173](https://github.com/nishide-dev/sumi-diagram/issues/173)）: 論文の図の見た目。角丸（箱 2pt・group 6pt）、パステルの tone、黒 1pt の枠、0.5pt の辺と 4pt の小さい矢じり、欧文は Inter。文字は node 8pt・group の見出し 9pt・辺 7pt。`paper-single` / `paper-double` 向け。
- **欧文のサンセリフ Inter 4.1 を同梱**（[#172](https://github.com/nishide-dev/sumi-diagram/issues/172)）: フォントセット `sumi/inter-biz-ud-gothic`（欧文は Inter、日本語は BIZ UDPGothic）。`paper` が使います。既存の Theme のフォントは変わりません。auto の図は従来どおり BIZ UDPGothic です。
- **枠のない箱とパネル**（[#174](https://github.com/nishide-dev/sumi-diagram/issues/174)）: node の `variant: filled`（塗りだけ）、container の `variant: plain`（枠も塗りもない）・`filled`（塗りだけ）・`dashed`（破線の枠）。全 Theme で定義し、auto の図でも使えます。
- **パネル全体を淡くする**（[#175](https://github.com/nishide-dev/sumi-diagram/issues/175)）: `groups[].dim: true`。group と中のすべて（文字・線・矢じり・塗り・キャプション・凡例・トークン列のセル、両端が中にある辺）を、Theme の dim の色に変えます。配置は変わりません。auto の図でも使えます。
- **色の枠線と色の辺**（[#177](https://github.com/nishide-dev/sumi-diagram/issues/177)）: node の `variant: outlined`（白地に tone の色の枠と文字）、`edges[].tone`（線・矢じり・ラベルの文字の色）。Theme に `toneLines.<tone>` を足しました。auto の図でも使えます。

### 部品と配置

- **拡大の引き出し線**（[#176](https://github.com/nishide-dev/sumi-diagram/issues/176)）: `component: zoom` の辺。元の要素と拡大先の対応する角を、2 本の斜めの破線で結びます。
- **送り元の真上（真横）で入る端**（[#179](https://github.com/nishide-dev/sumi-diagram/issues/179)）: `toAnchor: straight` / `fromAnchor: straight`。相手の中心を自分の辺に射影した位置で入り、線がまっすぐになります。射影が辺に乗らない場合は `layout/straight-off-side`（warning）で、既定の端で描きます。
- **ラベルの回転**（[#178](https://github.com/nishide-dev/sumi-diagram/issues/178)）: `nodes[].labelRotation: 90 | -90`。PDF でも文字として抽出できます。
- **小さい 2 行目**（[#184](https://github.com/nishide-dev/sumi-diagram/issues/184)）: `nodes[].sublabel`。ラベルの 7/8 の大きさで、ラベルの下に描きます。
- **セルの並び**（[#181](https://github.com/nishide-dev/sumi-diagram/issues/181)）: `component: tokens`。トークン列やキーの並びを 1 つの node で書き、辺の端に `<node>.<cell>` でセルを指定できます。セルごとに tone・variant を変えられます。
- **行列**（[#180](https://github.com/nishide-dev/sumi-diagram/issues/180)）: `component: matrix`。行と列の見出し（数式可）、`classes` による塗り分けと斜線、行は `"o..oo."` のような 1 文字ずつの文字列でも書けます。凡例の項目 `{ class: <matrix>.<class> }` で、行列と同じ見本を描きます。

### 大きさと密度

- **段の幅に縮める**（[#183](https://github.com/nishide-dev/sumi-diagram/issues/183)）: `figure.fit: scale`。Profile の幅を超える図を、配置を変えずに縮めて描きます（拡大はしません）。縮めた後の文字は Profile の `typography.minScaledFontSize`（`paper-*` は 5pt）以上かを検査します。数式の添字は info（`geometry/script-too-small`）で知らせます。auto の図でも使えます。
- **間隔を詰める**（[#182](https://github.com/nishide-dev/sumi-diagram/issues/182)）: `figure.layout.density: compact`。既定の間隔・group の余白・箱の上下の余白を詰めます（`paper-*` では間隔 4mm → 2.5mm など）。値は Profile の `layout.compact` にあります。

## 新しい診断

- **error**: `schema/reserved-key`（`__proto__` というキー。下記）、`component/label-rotation-unsupported`、`component/sublabel-unsupported`、`component/sublabel-without-label`、`ref/unknown-cell`、`ref/tokens-reference`、`ref/unknown-class`、`layout/attached-tokens`、`pptx/unsupported-size`（縮小で 1pt 未満の文字になる編集可能 PPTX）
- **warning**: `layout/straight-off-side`、`component/anchor-on-zoom`、`component/label-rotation-without-label`、`geometry/zoom-crosses-node`、`theme/undimmed-image`、`theme/missing-dim`、`lint/unused-matrix-class`
- **info**: `geometry/script-too-small`
- `geometry/text-too-small` と幾何 lint の近接の規則（#156）は、`fit: scale` で縮めた図では印刷の大きさで判定します。

## 不具合の修正

- **PDF・画像方式 PPTX で、数式の直後の空白が消えることがある問題を直しました**（#172）。`a$_\text{ b}$` のようなラベルで、usvg が `<tspan>` の先頭の空白を落としていました。この形のラベルでは、既定のフォントセットでも SVG のバイト列が変わります。
- **macOS の CI で重いテストが時間切れになる問題を直しました**（[#206](https://github.com/nishide-dev/sumi-diagram/issues/206)）。テストだけの変更です。

## 互換性

- Figure Schema は任意の追加だけです。CLI のコマンドは変わりません。
- **新しい書き方を使わない図の SVG / PDF / PPTX / D2 は、v0.5.3 と同じです**（版に関する metadata を除く）。各 PR で、リポジトリの全 `*.sumi.yaml` を書かれた Theme と組み込みの Theme で描き、出力の sha256 が変わらないことを確かめています。
- 例外として、出力や診断が変わる場合があります。
  - **`__proto__` というキーを拒否します**（#180）。Figure では `schema/reserved-key`（error）、Theme の定義では `theme/reserved-key`、lint の設定ではエラーで止まります。以前は、このキーは黙って捨てられていました。
  - **独自の Profile の `layout.compact`**（#182）: compact の値が通常の値より大きいと `profile/invalid-value` です。`layout.compact` を書かない Profile は、`paper` の既定値を通常の値で頭打ちにした値になります。
  - 診断の文面が変わったものがあります: `geometry/exceeds-page-width` の hint（`figure.fit: scale` を案内）、`layout/invalid-anchor` の message と hint（`straight`）、未知の部品の hint（`zoom`・`tokens`・`matrix` を列挙）、`lint/unused-legend-entry` の hint（tone）。code と severity は変わりません。
  - ギャラリーの slides の見本のうち、variant が 4 つ以上の部品は `presentation-16x9` で描くようになりました（#174）。既存の variant の配置も変わります。
  - `sumi catalog` の Theme に `toneLines`、Profile に `minScaledFontSize` と `layout.compact`、部品に `routing` が加わりました。
- **配布物**: Inter（Regular・Bold、OFL）を同梱し、tarball が約 0.4MB 大きくなりました（`bin/sumi` の大きさは変わりません）。ライセンスは `licenses/inter/OFL.txt`。
- 固定版 D2 は v0.9.0、BIZ UD Gothic 1.051、STIX Two 2.13、Tabler Icons 3.49.0 のままです。
- 設計の詳細は [設計 §6.44〜§6.56](https://github.com/nishide-dev/sumi-diagram/blob/v0.6.0/docs/design/phase1.md#644-172-の欧文のサンセリフフォントセットの-latin--latinbold) を参照してください。Skill の [論文図の作り方](https://github.com/nishide-dev/sumi-diagram/blob/v0.6.0/skills/sumi/references/layout-tips.md) に、原図の見た目と書き方の対応をまとめました。
