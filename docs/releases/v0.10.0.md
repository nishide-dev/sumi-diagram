# Sumi v0.10.0

論文図の再現性を上げるリリースです。括弧・波形の新しい部品、等幅のラベル、matrix のセルの文字、YAML に直接書く安全な SVG を加え、離れた bowtie のラベルと伸縮の配分を見直しました。計画は [#236](https://github.com/nishide-dev/sumi-diagram/issues/236)、実装は milestone「[v0.10.0 — Figure fidelity](https://github.com/nishide-dev/sumi-diagram/milestone/21)」です。

## 新しい部品

- **`bracket`**（[#281](https://github.com/nishide-dev/sumi-diagram/issues/281)）: 要素の列や行をまとめる括弧。`props.form: square | curly`（角括弧・波括弧）、`props.points: east | west | north | south`（開く向き。辺はこの側の中央、波括弧では先端から出入りします）。group・matrix・tokens 全体の側に `attach` すると、その辺の長さに合わせて伸びます（`width` / `height` を書けばそちらが優先）。ラベルは持ちません。structured の図だけで使えます。
- **`waveform`**（[#278](https://github.com/nishide-dev/sumi-diagram/issues/278)）: サンプル値から波形を描く部品。`props.samples`（2〜2,048 個、-1〜1）と `props.mode: bars | line`（上下対称の縦線、または符号を保った折れ線）。乱数を使わず、同じ値からは同じ図になります。structured と auto の両方、SVG / PDF / 画像 PPTX / 編集可能 PPTX（枠と波形を 1 つのグループの図形として）に出せます。

## 新しい書き方

- **YAML に直接書く SVG**（[#277](https://github.com/nishide-dev/sumi-diagram/issues/277)）: `image` の `props.svg: |` に SVG を書けます（`props.src` と同時には書けません）。ファイルの画像と同じ安全な取り込み（許可した要素と属性だけを書き直す。外部参照・スクリプト・イベント・`foreignObject` は拒否）を通り、SVG / PDF / 画像 PPTX に出せます。文字は図形（パス）で書いてください（`<text>` は使えません）。編集可能 PPTX には書き出せません（`pptx/unsupported-asset`）。
- **等幅のラベル**（[#279](https://github.com/nishide-dev/sumi-diagram/issues/279)）: ノードの `mono: true` で、ラベルと 2 行目を Theme の等幅フォント（同梱の BIZ UDGothic）で描きます。`mono: false` は variant の等幅を外します。tokens では全セルの既定になり、セルごとに上書きできます。数式は従来どおり STIX で、`\textcolor` の色付きの範囲もそのまま使えます。
- **matrix のセルの文字と省略**（[#280](https://github.com/nishide-dev/sumi-diagram/issues/280)）: list 形式の行で、セルを `{ class, text }`（文字・数式を書く）や `{ ellipsis: "…" | "⋮" | "⋱" }` にできます。`ellipsisRows` / `ellipsisColumns`（1 から数える）で行・列全体を省略にできます。省略のセルは大きさを保ち、記号だけを描きます。`flush: true` は matrix の枠の余白をなくし、隣の行・列と接して並べられます。
- **tokens 全体を辺の端点に**（#281）: tokens の ID を辺の端・`attach` の対象・align の項目に書くと、列全体（余白のない枠）を指します。
- **伸縮の配分 `grow`**（[#270](https://github.com/nishide-dev/sumi-diagram/issues/270)）: `justify: stretch` の余りを、要素ごとの重み `grow`（0 より大きく 1,000 以下、既定 1）で分けます。大きさは 0.5pt 単位で配ります。bowtie（離れた形を含む）と trapezoid も主軸の方向に伸びるようになりました。

## 改善と修正

- **離れた bowtie（`props.gap`）のラベルを中央に戻しました**（[#269](https://github.com/nishide-dev/sumi-diagram/issues/269)）。v0.9.0 では左の台形の中に置き、全体を横に広げていましたが、原図に合わせて 2 枚の台形と間隔の中央に置きます。白地に対して読みにくい色の文字（`solid` の白い文字など、コントラスト 4.5:1 未満）は、塗られた左の台形の中に置きます。輪郭線と文字の重なりの検査は、線を描く場合だけに行います。
- **CI のテストがときどき時間切れで落ちる問題を直しました**（[#289](https://github.com/nishide-dev/sumi-diagram/issues/289)）。全テストの既定の時間制限を 60 秒にしました（`bun run test`）。D2 が時間切れで止められて SVG を出さなかった場合の `backend/empty-output` に、外からの中断の可能性を示す hint を加えました。

## 新しい診断

- **error**: `component/grow-unsupported`（展開される部品 tokens・matrix・legend に `grow` を書いた）、`asset/invalid-image`（画像の `src` と `svg` がどちらもない、または両方ある）。
- matrix のセル（未知の class、文字と省略の同時指定、範囲外の省略の行・列など）と waveform のサンプル・SVG の取り込みの誤りは、書いた位置を指す error になります。
- `ref/tokens-reference` はなくなりました（tokens 全体を端点にできるようになったため）。

## 互換性

- Figure Schema は任意の追加だけです。CLI のコマンドは変わりません。
- **離れた bowtie（`props.gap`）を使う図は、大きさとラベルの位置が変わります**（#269。v0.9.0 の左寄せより幅が小さくなります）。
- **`justify: stretch` の列・行に bowtie・trapezoid を含む図は、それらが伸びるようになります**（#270）。
- 上の 2 種類以外の図の SVG / PDF / PPTX / D2 は、v0.9.0 と同じです（版に関する metadata を除く）。
- 固定版 D2 は v0.9.0、同梱フォント・Tabler Icons・Fluent Emoji Flat は v0.9.0 と同じです。新しい依存はありません。
- HTML/CSS の部分集合で箱の中身を書く方式は調査を終え（`research/277-html-subset/`）、次の版で扱います（[#283](https://github.com/nishide-dev/sumi-diagram/issues/283)）。
- 設計の詳細は、[設計 §6.74〜§6.80](https://github.com/nishide-dev/sumi-diagram/blob/v0.10.0/docs/design/phase1.md#674-269-の-split-bowtie-の中央ラベルへの復帰) を参照してください。
