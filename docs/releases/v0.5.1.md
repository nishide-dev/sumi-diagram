# Sumi v0.5.1

v0.5.0 の既知の不具合 [#143](https://github.com/nishide-dev/sumi-diagram/issues/143) を直したパッチリリースです。新しい機能や書き方は追加していません。実装は milestone「[v0.5.1 — Parallel edge fix](https://github.com/nishide-dev/sumi-diagram/milestone/13)」です。

## 不具合の修正

- **structured の図で、平行な辺が 1 本の線に重なる問題を直しました**（[#143](https://github.com/nishide-dev/sumi-diagram/issues/143)）。
  - 同じ 2 要素を同じ向きに結ぶ辺（例: `a → b` を 2 本）は、要素の辺の別々の位置から出入りします。ところが、同じ口を入りと出の両方に使う辺があると、入りと出を分けるために出る側の端を動かします（v0.4.1 の [#113](https://github.com/nishide-dev/sumi-diagram/issues/113)）。その動かした先が、もう 1 本の平行な辺の端と同じ点になることがありました。同じ向きの端は合流として扱うため、2 本が同じ経路の 1 本の線になり、辺が 2 本あることが図から読めませんでした。v0.4.1 から起きていました。
  - 動かす先が平行な辺の端に重なる場合は、その辺の空いた位置へ動かすようにしました。相手側の端も、平行な辺の端に重なる位置へは動かしません（その場合、線は曲がります）。`fromAnchor` / `toAnchor` を書いた端は、従来どおり動かしません。
  - 別の要素へ向かう辺との合流（fan-out・fan-in）は、従来どおりです。
  - v0.5.0 のリリースノートで案内した回避策（2 本に別々の anchor を書く）は、不要になります。書いたままでも問題ありません。

## 互換性

- Figure Schema、CLI、診断のコードと severity は変わりません。
- auto（D2/ELK）の図の SVG / PDF / PPTX は、版に関する metadata（`sumi-version` など）を除いて変わりません。
- structured の図は、入りと出の分離で端が平行な辺の端に重なっていた図だけ、経路が変わります。分離の途中で一時的に重なっていた図も、端の動き方が変わるので結果が変わることがあります。同梱の作例・ギャラリー・fixture、#109 と #135 の図では、版の表記を除いてバイト単位で同じことを確かめています。
- 箱どうしが重なる配置や、隙間なく接した箱では、線を引けない辺の `layout/no-route` のメッセージが変わることがあります。これらの辺は v0.5.0 でも引けていませんでした。
- 経路探索の時間は変わりません（合成図での測定の差は、ぶれの範囲）。
- 固定版 D2 は v0.9.0、同梱フォントは BIZ UD Gothic 1.051 と STIX Two 2.13、Tabler Icons は 3.49.0 のままです。
- 設計の詳細は、[設計 §6.35](https://github.com/nishide-dev/sumi-diagram/blob/v0.5.1/docs/design/phase1.md#635-143-の入りと出の分割で平行な辺を潰さない) を参照してください。
