# Sumi v0.18.1

v0.18.0 の Skill で描き直した再計測（[#538](https://github.com/nishide-dev/sumi-diagram/issues/538)）で見つかった課題を直す版です。集合の正確な大きさと箱の幅をそろえる指定、置き場所の lint、凡例の文字倍率、編集可能 PPTX の中抜き矢じりと破線、矢印の経路、Skill の不足などを直しました。実装は milestone「[v0.18.1](https://github.com/nishide-dev/sumi-diagram/milestone/36)」です。

## 構造化レイアウト

- **集合の正確な大きさ**（[#545](https://github.com/nishide-dev/sumi-diagram/issues/545)）: `circle` / `ellipse` / `rect` の集合に `width` / `height`。中心を保ったまま外形がその大きさになります。メンバーが入らないときは外形を切らず、`layout/set-size-too-small`（warning）を出します。同じ軸の `minWidth` / `minHeight` と併記すると `ref/set-size-conflict`（error）です。
- **箱の幅をそろえる**（#545）: ノードに `matchWidth: <name>`。同じ名前の箱は、置かれた場所によらず最も広い箱の幅になります。grid / stack の `align: stretch` で幅が揃わなくなるときは `layout/match-width-unmet`（warning）で知らせます。
- **まっすぐ降ろすアンカー `straight:span`**（#545）: 複数列にまたがる箱から、重なった区間の中央でまっすぐ降ろします。端数のアンカーを書く必要がなくなりました。
- **交差軸の整列**（#545）: stack の item を `x` で、row の item を `y` でそろえる指定が、主軸の空きで解けないときは交差軸の空きも使って解きます。これまでの `layout/unsatisfied-align` の一部が出なくなります。grid の複数列にまたがるグループの中身をそろえる式は `structured.md` に書きました。
- **曲線の自己ループの場所**（[#544](https://github.com/nishide-dev/sumi-diagram/issues/544) の一部）: `route: curve` の自己ループとそのラベルが配置の場所を取るようにしました。隣の要素や枠に重ならなくなります。

## 矢印の経路

- **枠に寄る幹と同じ側の線**（[#512](https://github.com/nishide-dev/sumi-diagram/issues/512) の一部）: 外の 1 つの箱からグループ内の複数の箱へ入るファンアウトの幹が、枠から離れるようにグループの余白を広げます。同じ側どうしを結ぶ入れ子のスキップ接続（`fromAnchor` / `toAnchor: east` など）は、重ならないよう別の通り道に分けます。

## 描画

- **数式の添字**（[#547](https://github.com/nishide-dev/sumi-diagram/issues/547)）: `figure.target.minFontSize` のある図では、添字の大きさを最小の文字サイズまで引き上げます（基準の文字を超えません）。
- **高い円柱**（#547）: 高さ 140 unit を超える円柱（文字の倍率が大きい図など）の蓋を、高さに合わせて深くします。
- **3 つ以上の集合の重なりの色**（#547）: 重なりの色が、どの単独の集合の色とも見分けられるよう、明度を少しずらします。2 つの重なりは従来どおり単純平均です。
- **凡例の文字倍率**（[#543](https://github.com/nishide-dev/sumi-diagram/issues/543)）: `themeOverrides.textScale` を使った図で、凡例の見本（線・箱・集合）と間隔も同じ倍率で大きくなります。
- **等幅の太字**（[#495](https://github.com/nishide-dev/sumi-diagram/issues/495)）: `html` の等幅フォントの太字で、i と j の点が軸に潰れなくなりました。
- **編集可能 PPTX**（[#485](https://github.com/nishide-dev/sumi-diagram/issues/485) の一部）: 塗らない triangle / diamond / circle の矢じりを SVG と同じ中抜きの形で描きます。ラベルの下で分かれる破線は、SVG と同じ模様の位相で続きます。

## Lint

- **置き場所の lint**（[#546](https://github.com/nishide-dev/sumi-diagram/issues/546) の一部）: すべて info です。
  - `geometry/token-column-drift`: トークンの行が列からずれる。
  - `geometry/edge-label-hugging`: 線のラベルが線から 1pt 未満。
  - `geometry/edge-label-on-corner`: 線のラベルが箱の角にかかる。
  - `geometry/arrowhead-cramped` を曲がりのない線にも広げました。
- **色付きパネル**（[#548](https://github.com/nishide-dev/sumi-diagram/issues/548)）: `geometry/color-on-panel` が、`sumi` テーマの青・紫・ピンクのパネルでも、緑や赤と同じように出るようにしました。

## Sumi Skill

- **Skill の不足**（[#549](https://github.com/nishide-dev/sumi-diagram/issues/549)）:
  - 下絵の語彙に、グループの `labelAt: above-*` と `props.padding` を加えました。
  - ノードに `height` などを直接書いたときは「`props` の下に書く」ヒントを出します。
  - matrix のセルの `text: ~` は、セルの位置と直し方を示します。
  - `scripts/preview` の `-o` を入力の後ろにも置けます。
- **サイトの凡例**（[#550](https://github.com/nishide-dev/sumi-diagram/issues/550)）: サイトの Options の「Legends」を外し、凡例の見本の種類は `sumi/legend` の部品の見本で示すようにしました。ギャラリーの `legend-samples` ページは部品の見本にまとめました。

## 互換性

- Figure Schema への追加はすべて任意です（集合の `width` / `height`、ノードの `matchWidth`、アンカー `straight:span`）。新しい診断は warning 2（`layout/set-size-too-small`、`layout/match-width-unmet`）、error 1（`ref/set-size-conflict`）と、上の lint の info です。
- **出力が変わる図**:
  - structured の図で、曲線の自己ループがある図。
  - 外の箱からグループ内の複数の箱へのファンアウト。
  - 同じ側どうしの入れ子のスキップ接続。
  - `minFontSize` があり、添字が最小値より小さかった数式。
  - 高さ 140 unit を超える円柱。
  - 3 つ以上の集合の重なり。
  - `textScale` を使った図の凡例。
  - 等幅の太字。
  - 編集可能 PPTX の中抜き矢じりと、ラベルの下を通る破線。
  - Skill のレイアウトでは `three-panel-flow`、`encoder-decoder`、`pipeline-branch-merge`、`venn-three` が変わりました。
- これまで `layout/unsatisfied-align` だった、stack の item を `x` で、row の item を `y` で動かす図は、警告が出ずに整列します。
- コミット済みの作例と論文の再現図の出力は変わりません（版の表記を除く）。`examples/dit-block` では `geometry/edge-label-hugging` の info が 1 件増え、期待する診断に記録しました。
- 固定版 D2 は v0.9.0、同梱フォント・Tabler Icons・Fluent Emoji Flat・Takumi は v0.17.1 と同じです。
- 設計の判断は、[docs/design/decisions](https://github.com/nishide-dev/sumi-diagram/tree/v0.18.1/docs/design/decisions) の各ファイル（#485、#495、#512、#543〜#550）を参照してください。
- 残りの課題は milestone「[v0.18.2](https://github.com/nishide-dev/sumi-diagram/milestone/37)」で扱います。
  - 隣り合う箱の間の幹（#512）。
  - `labelAt: above-*` の見出しの隙間（#544、再現せず）。

  - 編集可能 PPTX の `arrow` の矢じりと点線の位相（#485）。
