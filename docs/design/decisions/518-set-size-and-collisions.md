# 518: 集合の大きさ、輪郭を横切るノードの lint、ラベルの扱い

## 背景

#509 の分類の図（run 8）で、集合に関する 5 つの不便が記録された。8B は、楕円を広げるために見えない `junction` をメンバーに足し、幅をそろえた箱が隣の楕円にはみ出しても lint が黙っていた。

## 決定

### 1. 集合のラベルは配置の場所を取らない（lint で検出する）

予約しない。#407 で「集合は配置後にメンバーから決まる」ため arrange に空間を持たせない、と決めた前提（`place` の剛体の契約、メンバーの相対位置が集合の大きさで動く問題）は変わらない。8A の衝突は、既存の `geometry/set-label-collision`（他のラベル、ノード、エッジ、他の集合の輪郭との重なり）が検出している。追加で、ラベルの位置を決める `labelAt` と、下の `minWidth` / `minHeight` で輪郭をそろえれば、ラベルの高さもそろう。

### 2. lint `geometry/set-outline-crosses-node`（warning）

メンバーではないノードの図形が、集合の輪郭に一部だけかかる場合を報告する。判定はノードの外接矩形ではなく描かれる形（円、ひし形などの輪郭）に対して行い、ノードを縮めないので細いノードも見逃さない。1 つのノードは、被覆（中心が内側、または形の 25% 以上が内側）・横断（形の一部が輪郭の 1 unit より深く内側。ノードの形と輪郭の凸領域の厳密な交差判定で、輪郭を 1 unit 内側へ寄せた領域との重なりを、多角形の切り取りと分離軸、楕円は単位円への変換で調べる。標本点ではないので、1000 × 2 のような細長いノードが標本の間で見落とされない）・無関係のどれか 1 つに分類され、2 つの lint が同じノードを二重に報告することも見落とすこともない。被覆のノードは従来どおり `geometry/set-contains-non-member` が見るので、二重に報告しない。メンバー（メンバーのグループの子孫を含む）と接続点は対象外。集合ごとに 1 件で、横切られたノードを related に示す。

### 3. `minWidth` / `minHeight`

集合に追加する任意の長さ。`circle` / `ellipse` / `rect` の輪郭の最小の大きさ（外接矩形の幅・高さ）で、メンバーに合わせた輪郭が小さいときだけ、その**中心を保ったまま**大きくする（メンバーは輪郭の内側に残る）。`circle` は 2 つのうち大きい方の半径の円のまま。傾けた楕円（`angle`）は楕円自身の軸（`rx` が第 1 軸）に対して効く。`hull` はメンバーに沿う形で大きさを持たないため、`ref/set-min-size-needs-fixed-shape`（error）で拒否する（`angle` を楕円以外に付けた場合の `ref/set-angle-needs-ellipse` と同じ扱い）。長さは部品の `width` と同じ `SizeLength`（#515）で、0.5pt の倍数に丸め、正の値のみ（0 は拒否）。`18mm` は箱でも集合の最小でも同じ大きさになる。`padding` はこれまでどおり。縦横比（`aspect`）は、`minWidth` と `minHeight` の組み合わせで表せるので足さない。

採らなかった案: 中心の指定。輪郭の中心はメンバーに合わせた輪郭の中心のままで、複数の集合をそろえるにはメンバーを対称に置く。中心を作者が決めるには座標系が要り（`place` 以外の配置には無い）、見えないノードを足す回避と変わらなくなるため。

### 4. ラベルの副題は足さない

集合のラベルは 1 つの書式（`SetStyle` の文字）で、描画（SVG・PDF・picture PPTX・editable PPTX の自由図形とテキストボックス）、再計測（lint）、配置（`setLabelCenter`）のすべてが 1 つのテキストの箱を前提にしている。2 段にするには、これらすべてに 2 つ目の書式の箱を通す必要があり、`sublabel` を持つノードのように見える図の部品が 1 つ増える。今回の目的（輪郭のはみ出しと大きさ）から外れ、効果も 8B の見た目の差に限られるので見送る。需要が増えたら、`sublabel`（小さい文字、tone の薄い色）を #407 のラベルと同じ箱に積む形で別の Issue にする。

### 5. 凡例の `node` サンプルの `cornerRadius`

凡例の `node` サンプルが、ノードと同じ `cornerRadius`（0.5pt の倍数、10pt まで）を受け付け、サンプルの箱に渡す。角丸のノードと凡例の見た目がそろう。`edge` と `set` のサンプルは変えない。

## 互換性

追加の任意のフィールドと lint 1 件のみ。`minWidth` / `minHeight` のない集合の輪郭と、既存の出力は変わらない（ピン留めした再現と `gallery:check` で確認）。新しい lint は既存の図で新しい警告を出し得る。

## 検証

`tests/fixtures/figures/sets/method-taxonomy.sumi.yaml`: #509 の 8B を、見えない `junction` なし、`minWidth: 58mm` / `minHeight: 48mm` と角丸の凡例サンプルで描き直した。4 つの楕円の大きさがそろい、`lint --geometry` は 0 件。ヘッドレス Chrome で描画して目視した。
