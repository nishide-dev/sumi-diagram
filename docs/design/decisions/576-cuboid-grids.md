# #576 cuboid の格子・部分ブロック・受容野の線（設計 #574 の段階 B）

- **背景**: 3D 畳み込みやテンソルの図（conv3d）には、立体の格子、カーネルや出力セルの部分ブロック、そこから次の体積へ引く四隅の線が要る。見た目は `research/574-3d-components/`（conv3d の節、`variants-rf-sumi.png` の案 A）で決まっている。段階 A の `cuboid`（#575）の上に足す。
- **決定**:
  - **格子** `props.cells: [nx, ny, nz]`: 見える 3 面（前・上・側）を `nx × ny × nz` のセルに分ける細線。太さは枠の 0.5 倍、色は枠の色をキャンバスへ 45% 混ぜる（研究の決定）。renderer の契約に `OutlineLayer.grid`（線）と `more`（同じ属性で描く追加の開いた線。格子の多数の線を 1 つの path / freeform にまとめる）を足した。`cells` を書かない cuboid の出力は変わらない（レイヤーは従来の 6 つのまま）。
  - **部分ブロック** `props.highlight: [{name, tone, at: [x, y, z], size: [nx, ny, nz]}]`（`cells` が要る）: セルの範囲を、自分の面（上・側は tone の fill から導く陰影）・格子・内側の辺・枠を持つ小さな立体として、体積の上に描く。`at` は左・上・手前からのセル番号、`size` はセル数（既定は 1 セル）。tone は必須（色の既定値を持たない）。色は常に `tinted`（淡い fill に tone の枠）で、枠は節点の枠の太さ。奥（z が大きい）のブロックを先に、同じ奥行きでは左から右・下から上の順に描く。範囲外・重複した名前・`cells` なしは `component/invalid-prop`（`props.highlight[i].at` などに位置を付ける）。ブロックの色は IR の render params（`blocks`、JSON）に確定してから renderer へ渡す（params はスカラーだけの契約のため）。renderer は `OutlineDrawing.parts`（名前 → 外接形・シルエット・3 つの面と隠れた左の面の四隅）を返す。
  - **参照** `<node>.<name>`: `tokens` の `<node>.<cell>` と同じ綴りで、辺の端にだけ使える。tokens の展開と同じ段階で、cuboid の `highlight` の名前なら受け入れ、IR の端は cuboid のノードのままで `fromPart` / `toPart` に名前を持つ。未知の名前・別のノードのブロックは `ref/unknown-cell`。
  - **受容野** `zoom` の端にブロックを使える: 両端がブロックで向かい合う（右または左）とき、4 本の線を引く（案 A: 始点ブロックの出力側の面（右なら側面）の四隅 → 終点ブロックの入力側の面（左の隠れた面）の四隅。前上・奥上・奥下・前下の順に対応）。ブロックと普通の箱のあいだ、上下に離れたものは、ブロックの外接形の角で従来の 2 本。線は始点の体積の上、終点の体積の下に描く（SVG では終点のノードの直前）。研究の決定どおり、終点の体積がセルの背面へ届く線の端を隠す。
  - **PDF・編集可能 PPTX**: PDF は SVG 経由。PPTX は cuboid の外形（シルエット）をマークし（格子か部分ブロックがあるときだけ `class="sumi-solid-outline"`）、それより前の path（面・格子・内側の辺）は文字の下、後の path（ブロックの面・格子・枠）は上の別々の freeform にする。zoom の線は従来どおり。
- **採らなかった案**:
  - ブロックを実ノードに展開して配置する（tokens のセルのように）: 親の中の位置は親の配置が決まるまで分からず、エンジンに「親の内側」という配置を足すことになる。ノードの内側に描くほうが小さく、レイアウト・lint・PPTX に新しい経路が要らない。
  - 部分ブロックを普通の（直交ルーティングや `route: straight` / `curve` の）辺の端にする: ルーターの端は要素の箱と外形を前提にしており、ブロックのポートと障害物の扱いをルーターに足す必要がある。段階 B は `zoom` の端だけにし、普通の辺の端は診断（`layout/part-needs-direct-route`）で止める。
- **互換性**: 既存の図・作例・ギャラリー・golden は変わらない（`gallery:check`、PDF・PPTX の golden が一致）。追加は `conv3d` のベースレイアウト（SVG・PNG・`previews.json`）と、catalog の説明の文面（`sumi/cuboid`・`zoom`）のみ。
- **未実装・今後**: ブロックのポートを使う普通の辺（直交ルーティング・直線・曲線）。上下に離れたブロックの受容野（上面・下面の線）。ブロックごとに親と異なる格子。
