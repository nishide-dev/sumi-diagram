# #473 テーマのキャンバス色

## 背景と決定

テーマの `canvas` は不透明な地の色で、省略時は白とする。3 桁の色は 6 桁に正規化する。structured の背景とラベルの背景サンプリングに加え、auto の D2 SVG の背景矩形もこの色にする。PDF と画像 PPTX は SVG の背景を受け継ぎ、両 PPTX のスライドマスターも同じ色を使う。HTML の `--sumi-bg` はテーマの地を表す。

描画色の合成はキャンバスから始め、tone の地上の文字コントラストと bowtie の文字配置もキャンバスを基準にする。既存テーマのキャンバスは白であり、白の D2 出力を加工しない。

## 白の用途ごとの判断と残課題

- `style.ts` の白は部品とエッジの既定の塗りであり、キャンバスではない。
- `resolve.ts` の solid の白文字・スタックの白い区切り・塗りのフォールバックは部品の塗りに対する色として残す。地上の tone 文字の比較はキャンバスを使う。
- `node-variants.ts` の solid の白文字と区切りは部品上の色として残す。ページのコントラストと warm tone の背景はキャンバスを使う。ただし warm tone の探索は暗いキャンバスに最適化されていない。
- `palette-tones.ts` の白文字は明色地の solid 塗り上の文字として残す。パレット由来の線のページ上の可読性は白に加えてキャンバスでも検査する（下記「パレット」）。
- set の不透明な塗りは明色地では従来通り白への混色、暗色地ではキャンバスへの混色とする。暗色地の重なりは各色の地からの差分を 0.8 倍して加算し、SVG、編集可能 PPTX、lint で同じ色にする。白地の乗算と既存出力は維持する。
- `color-composition.ts` の地との比較はキャンバスを使う。既定の説明やパネルの推奨文には白い紙向けの表現が残る。

## 途中経過

テーマに地色を持たせ、描画とコントラスト計算に渡す。`sumi` はクリーム色の地、`sumi-dark` は紺色の地を使う。既存テーマの既定値は白のままとする。暗い地では solid の明るい塗りに暗い文字を使い、黄色の明色地向け導出は適用しない。

dim の塗りは白ではなくキャンバスへ混ぜる。白いキャンバスでは従来と同じ計算になり、暗色地でも背景に近づく。文字と線の dim はキャンバスとのコントラストが通常より低いことを検査する。ギャラリーを再生成し、dim の両テーマを PDF から PNG に変換して目視した。

## パレット

パレットはテーマのキャンバスごとに導出する（`getPalette(id, canvas)`）。分岐はテーマ ID ではなくキャンバスの OKLCH 明度（L < 0.6 を暗色地とする `isDarkCanvas`）で行う。白では従来の導出そのもので、`BUILTIN_PALETTES` とカタログは白地の値のままとする。

- 明色地（`sumi` のクリーム）: 導出は白地と同じで、コントラストの基準を白からキャンバスに広げる。ink はキャンバスに 9:1、muted はキャンバスとパネルに 4.5:1、accent と strong は白文字の塗りとして白に 4.5:1 に加えてキャンバスにも 4.5:1、tone の線は白・キャンバス・パネルに 4.5:1 とする。muted のグループの塗りはパネルとキャンバスの中間。パネルはパレット自身の色のまま。
- 暗色地（`sumi-dark`）: パレットの暗色版を作る。キャンバスはテーマのまま、パネルはキャンバスより L で 0.05 明るくパレットのパネルの色相に寄せ、tint はキャンバスより 0.12 明るく tint の色相とする（ink が 4.5:1 で読めなければ暗くする）。ink はパレットの最も淡い色をキャンバスに 9:1・パネルに 4.5:1 まで白へ寄せたもの、muted は ink をキャンバスへ寄せられるだけ寄せたもの。accent は色相を保ち、読めなければ明るくし、キャンバスとの差が 6.5:1 を超える淡い色（sage）は ink と区別できないため彩度 0.08 以上で読める限り暗くする。strong は accent をさらに明るくし、キャンバス・パネル・tint に 4.5:1 とする。solid と emphasis の塗りの文字はキャンバス色。tone は色相を保ち、塗りは tint より少し暗い位置から ink が 4.5:1 で読めるまで暗くし、線は L 0.8 を起点にキャンバス・パネル・自身の塗りに 4.5:1 となるまで動かす。線は文字にも使うため 3:1 ではなく 4.5:1 を満たす。
- 色の対応付け（`colorMap`）では、白とキャンバスを置き換えない。グループの塗りは明度によらずパネル、暗色地の emphasis の色は彩度によらず accent、その他の淡色・灰色は明色地ではキャンバスに対する相対輝度、暗色地ではキャンバスとのコントラストでパネル・tint・muted に振り分ける。`sumi` は muted の文字と gray の線が同色のため、gray tone の塗りと線、および outlined の枠と文字は役割（tint・strong）を明示して割り当てる。
- 暗色地の tinted ノードの文字は明色地と同じく枠（tone の線）の色とした。`sumi-dark` のチャット吹き出しは白ではなくパネル色とし、黄の文字色は彩度を 0.09 に上げた。

## 互換性と検証

既存テーマではキャンバスが白のため、ギャラリーの再描画は一致した。暗いテスト用テーマで両エンジンと PPTX を検査し、CLI の PDF を PNG に変換して目視した。

パレットの変更では、変更前後でギャラリーの全サンプル（部品・tone・dim・glyph・set・stroke・legend・palette）と `examples/` の全図を、既存 6 テーマ × パレットなしと 8 パレットの計 2214 通りで描画し、SVG の sha256 がすべて一致した。ギャラリーと golden の差分は `sumi-dark` の出力に限られる。パレットのサンプル図を `sumi` と `sumi-dark` の全 8 パレットで PDF から PNG に変換して目視した。
