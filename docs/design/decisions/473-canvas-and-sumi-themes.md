# #473 テーマのキャンバス色

## 背景

描画と色計算が白い背景を前提としているため、暗い地のテーマを正しく表現できない。

## 決定（途中）

テーマ定義に `canvas` を追加し、不透明な色または色トークンとして検証する。省略時は `#ffffff` とする。structured SVG の地と、エッジラベル・中空矢印の背景サンプリングには解決済みの値を使う。既存テーマは省略するため、これらの出力は従来どおり白を使う。
