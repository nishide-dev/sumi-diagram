# #455 パレットの黄色と濁りの検出

## 背景

パレットの tint の明度を黄色にも使うと、黄土色やカーキに見える。従来の濁り検出は白の上の色との相対比較なので、不透明なカーキを検出できなかった。

## 決定

黄色の塗りは OKLCH L 0.93 以上から探索し、線は paper の黄土色に近い色相 92 度から、白とパネル双方に対して 4.5:1 を満たす最も明るい色を探索する。追補の暖色調整は [設計記録](455-warm-fills.md) を参照。灰色との距離と文字のコントラストは従来どおり検査する。

`geometry/muddy-color` は不透明な塗りも含め、L 0.69 以上 0.86 未満、C 0.045 以上 0.105 未満、h 78〜115 度を黄〜橙のカーキとして警告する。通常の淡い黄色、鮮やかな色と無彩色は除く。既存の example と gallery に新たな警告はない。

パレット図では tone の列をパイプラインの直下に置き、右の凡例と並べる。8 パレットすべてで dead-space の info が消えた。

## 互換性

パレット由来の黄色を使う図の色が変わる。ピン留めされた example の色は変わらない。全パレットの比較図は配置と黄色が変わる。再描画の比較では、対象外の図の生成物は一致した。ただし構造化図には D2 出力がなく、無効 fixture や一部テーマで経路を解決できない図は描画できない。
