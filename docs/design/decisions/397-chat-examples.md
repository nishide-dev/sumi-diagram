# #397 会話の作例を一段組の図として収める

## 背景

`bubble`（#395）と `chat` 配置（#396）の実用例として、和文の予定相談と英文の
ユーザー・LLM 対話を examples とギャラリーへ追加する。コンポーネント単体では
見えにくい連投、注記、avatar の再利用、本文の折り返しを示す。

## 決定

- 両図は `paper-single`、列幅80mm、拡縮なし。本文8pt・注記7ptを保つ。
  出力寸法は chat が83.96 × 59.09mm、llm-dialogue が83.96 × 61.56mm。
- `chat` は参照の会話部分の「今日」と5発言、時刻・既読を再現する。
  話者は汎用の friend / me、avatar は円内の A。受信は白、送信はテーマの green / filled（淡い緑。左右の話者を色で見分けられるようにする）。
  サービス名・ブランド色・写真・端末枠・ヘッダー・入力欄は加えない。
  同一話者の連投は #396 の契約どおり avatar としっぽを省き、本文端を揃える。
- `llm-dialogue` はクレヨンの個数を求める自作の例示対話。実際のモデル出力や評価結果ではない。
  User / Assistant の注記と、同梱の `tabler/user` / `tabler/robot` を円内に置く。
  回答は短い4行の計算過程と、条件を変えた追質問への2行の回答。
  数式は短い `$...$` に限定し、`|-` で改行して演算と結論を読み取りやすくする。
- LLM 対話を paper / academic / llama で PDF 描画して比較した。
  academic はグレースケール印刷に向くが、本文の折り返しが増えて縦長になる。
  paper は Inter が読みやすい一方、黒枠が強い。Inter と淡い配色を保ち、
  slate の輪郭で主張を抑えた llama を採用する。和文の作例にも同じテーマを用いる。
- 説明文、例一覧の件数・info 表、Skill の chat 参照を更新する。
  既存の自動列挙による SVG/PDF テストへ入り、例一覧テストでも両 YAML の存在を固定する。
  新しい診断の許容や、部品・配置実装の変更は不要だった。

## 検証と互換性

- 両図は geometry を含む lint が error / warning / info とも0件。
- CLI のベクター PDF を `pdftoppm -png` で画像にし、しっぽ、円内の文字・アイコン、
  和文と英文・数式の改行、注記の位置を目視した。和文は参照の会話領域と同じ幅で並べて比較した。
  英文の最後の回答は計算と結論の2行に分け、短い語句だけが折り返される状態を避けた。
- 生成物は `bun run gallery` と文書化された PDF/PPTX/assets の golden 更新コマンドのみで更新する。
- 変更前の全106図を自テーマ＋6組み込みテーマの742条件で描画し、変更後と比較する。
  SVG / PDF / picture PPTX と、auto の D2 ソースの SHA-256、失敗時の診断コードを記録する。
  research/ と private figures は除外する。
