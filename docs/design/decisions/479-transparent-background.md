# #479 透明なキャンバス

## 背景と決定

図をスライドや Web の背景に重ねるため、`figure.background` に `canvas`（既定）と `transparent` を追加し、`render --background` で上書きできるようにする。透明時は SVG の最外周の矩形のみを省き、PDF はその SVG を変換し、PPTX のマスター背景は noFill とする。SVG のメタデータには透明時のみ `background="transparent"` を記録し、省略時は canvas と解釈する。

ノードの塗り、エッジラベルなどの下地、パネル、集合の色は変えない。HTML の `--sumi-bg`、コントラスト計算、トーン導出と lint もテーマの地を想定する。別の色の背景に置くとラベルの下地が見えることがあるが、線を切る方式は採らない。

## 互換性

既定の描画はメタデータを含め従来どおりとする。透明化は明示した場合だけであり、実際の配置先の背景色を知らないため新たな lint は加えない。

既存図を自身のテーマと全組み込みテーマで比較した 990 ケースでは、描画成功 689 ケースの SVG・PDF・画像 PPTX・D2 の SHA-256 に差はなく、残り 301 ケースの失敗診断コードも一致した。research/ と非公開の図は除外した。
