# #456 描画された破線と集合のフットプリント

## 背景

構造化レイアウトでは丸い角の直線部分と曲線部分を別々の SVG サブパスとして描画するため、それぞれで破線が再開する。論理経路の長さの合計では模様が見えると誤判定する。また矢じりの種類によって線の終点は異なる。

## 決定

`geometry/dash-hidden` は構造化描画の検査情報にある描画済みサブパスごとの長さで判定する。独立した曲線は一つのサブパスとして標本の長さを合算する。描画情報がない場合は描画器と共有する矢じりの形ごとの切り詰め量を使う。D2 は従来の近似を維持する。

`enclose: footprint` の契約は、円、回転楕円、凸包、角丸矩形の実際の輪郭に対し四方向の glyph の矩形を検査し、ラベル、非メンバー診断、PDF と PPTX への出力も検証する。

## 互換性

SVG やスキーマは変わらない。破線の警告は描画状態に応じて増減する。LLaDA の既存の警告数は変わらない。research/ と private figures は個別の確認から除外した。
