# #492 集合の交差領域の計算量を制限する

## 背景

深い交差を全列挙すると、同じ輪郭の 18 集合でも 262,125 領域が生じ、描画と幾何 lint の負荷が指数的に増える。

## 決定

同じ多角形輪郭を持つ集合を先にまとめ、全参加色と `multiply` 指定を維持する。異なる輪郭の交差は浅い組合せから段階的に求め、面積が閾値未満なら枝を打ち切る。共通の領域列挙を SVG、PDF、編集可能 PPTX、幾何 lint で使う。

領域は最大 1024 個とし、超過時はそこで打ち切り、計算済みの領域を浅い順に描く。`layout/set-overlap-budget` 警告は対象の塗り付き集合の ID を列挙する。上限に達した次数は部分的になり得て、深い交差では一部の参加色が反映されない。図を分割するか重なりを減らせば回避できる。

## 互換性と代替案

上限に達しない図では混色の結果は同じ。同一輪郭は中間の重ね塗りを省き、最終色を維持する。無制限の全列挙は実用的でないため採らない。上限時の近似は警告で明示する。
