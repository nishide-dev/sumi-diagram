# #369 route: straight が隣のノード・セルをかすめるときの診断

## 背景

`route: straight`（#349）は障害物を避けない一本の線である。`geometry/edge-through-node` は、線が端点以外のノード（tokens のセルを含む）の輪郭の内側へ許容 1 unit（0.5pt）を超えて入ったときだけ報告していた。そのため、円や隣のセルを深さ 1 unit 未満でかすめる線、輪郭のすぐ外を通って線と輪郭の線が接する線は無言だった。

再現: 円を 3 列の grid に隙間 0.5mm で並べ、a から f へ直線を引くと、線は b と e の内側 0.5 unit を通る。隙間 1mm では輪郭の外 0.7 unit を通り、線幅（1）と輪郭の線幅（2）が接して見えるのに診断が出ない。tokens を 2 段に重ね（段の間隔 4mm、セル間隔 2mm）、左上のセルから右下のセルへ引くと、同じ段の B と下段の Y の角をかすめる。端点自身のセルは従来から対象外で、端点以外のセルは既に検査されていた。

## 決定

- `route: straight` の辺に限り、`geometry/edge-through-node` が、辺と他ノードの輪郭の線幅の半分ずつの合計（辺 0.5 + ノード 1 = 1.5 unit）以内まで線が近づく場合も位置つき warning で報告する。内側へ 1 unit を超えて入る場合は従来どおり "passes through the shape"、それ未満の接触は "touches the outline" と文言を分ける。rule id は増やさない。
- ヒントは、端点に側面のアンカー（`fromAnchor` / `toAnchor`）を使う、ノードや端点を動かす、`route: straight` をやめる、のいずれかを示す。自動で避ける経路は作らない。
- 端点のノード・セルは従来どおり対象外。直角経路の辺・auto の辺・zoom 辺は変更しない。

## 採らなかった案

- 全辺の許容を負にする案: 直角ルーターは輪郭から一定の余白を保つため差は出ないが、D2/ELK の経路で誤検出が増えうる。
- 新しい rule を足す案: 同じ原因（障害物を避けない線）で、同じ対処を示すため、既存 rule の文言で足りる。

## 互換性
