# #491 waveform の波形色とラベル配置

## 背景

emphasis の塗りと信号の色が同じで、信号が見えなかった。ラベル付き waveform では枠内の下部にラベルを置くため、信号の領域も上に寄る。

## 現状と残作業

emphasis の信号には variant の文字色を使い、全組み込みテーマと variant の塗りとのコントラストを検査する。ラベルの枠外配置は未実装であり、両レイアウトエンジンで失敗する回帰テストを追加した。

枠外ラベルには、描画枠とラベルを含むレイアウト領域を区別し、サイズ計算、ポート、SVG 検査、幾何 lint、編集可能 PPTX を一貫させる必要がある。現在の outline 契約では safeArea を描画本体の内部に置くため、単にラベルを枠外へ動かすだけではこの契約を破る。

EmbeddingGemma の waveform 自体にラベルはなく、別の label ノードを南側に attach している。既存の原図再現を保つための内側配置 prop は不要である。
