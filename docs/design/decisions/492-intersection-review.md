# #492 多重交差と混色の濁り判定

## 背景と決定

[集合の重なり色の設計](492-set-overlap-mix.md)に対するレビューで、4 個までの交差しか描かない制限と、`mix` の濁り判定を全面的に省略する問題が見つかった。

共通の交差列挙は次数を制限せず、全参加色と `multiply` の指定を SVG・編集可能 PPTX・幾何 lint で共有する。交差しない枝は早期に除外するが、すべてが重なる場合は組合せ数が指数的に増える。固定上限では参加色が欠けるため採用しない。

`mix` は入力色との意図的な差ではなく、混色後の塗りを基準に、最終色の濁りと上に重なる半透明塗りの影響を検査する。`multiply` の既存の彩度差判定は維持する。

## 互換性

5 個以上が重なる領域の色と、混色領域の濁りの診断が変わり得る。スキーマは変わらない。既存ギャラリーの生成物は変化しない。
