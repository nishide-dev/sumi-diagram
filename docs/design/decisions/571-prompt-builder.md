# #571 プロンプトビルダーの出力を Skill に合わせる

サイトのプロンプトビルダー（`site/prompt.ts`、#469 / #471）が出すプロンプトを、Sumi Skill（`skills/sumi/SKILL.md`）と `sumi catalog` の profile / テーマの値に合わせる。

## 背景

4 つの設定のプロンプトをビルダーで作り、Sonnet のエージェントに Skill で図を作らせた。設定は次の 4 つ。

- README のシステム構成図（`sumi`）
- 論文 1 段の日本語 RAG パイプライン（`paper`）
- スライドのフローチャート（`sumi`）
- 全幅のパネル概要図（`paper`、tone 3 つ、高さ 60mm）

どの図も lint は通ったが、プロンプトに次の問題があった。

- README を `paper-double` に割り当てていた。Skill と catalog は README に `screen-doc` を使う（200 × 150mm、最小 10pt、7-9pt のテーマは `textScaleFor.screen-doc` = 1.5）。結果は 125 × 217mm の縦長で、文字も小さかった。
- スライドでは、選んだテーマを `slides` に置き換えていた。`slides` は tone を灰色の濃淡で描くので、`sumi` を選んでも色が消えた。Skill は 7-9pt のテーマに `textScale: 2` を使う。
- 配置先が幅しか書いておらず、高さの上限がなかった。スライドでは高さが先に効いた。
- 「曖昧な点は質問」とだけあり、答えが得られないときにどうするかを書いていなかった。参考資料がないときも「参考資料とメモから」と書いていた。
- tone を付ける先（ノードかグループか）が書かれていなかった。灰色のテーマでは tone が色にならないことも伝えていなかった。
- 仕上げは「SVG を見る」だけで、Skill の PNG プレビュー、内容のチェック、ベースレイアウトに触れていなかった。
- 文法の誤りがあった（"Make a overview in panels"、"RAG システム の内容を表す"）。

## 決定

- README の配置は `screen-doc`（200 × 150mm）にする。`screen-doc` と `presentation-16x9` では、`figure.themeOverrides.textScale` を catalog にあるテーマの `textScaleFor.<profile>` にするよう書く。`slides` は書かない（スライドの文字の大きさをもともと持つ）。この 2 つの配置では横長の形を勧める。
- スライドでもテーマを変えない。
- 配置先には幅と高さの上限を両方書く。高さの指定が profile の上限以上のときは、その指定を書かない（profile の上限が効く）。論文で高さの指定がないときは、内容に必要な分の高さにし、縦に長い流れは折り返すよう書く。最初の再評価では、RAG が 87 × 209mm まで縦に伸びたため、この行を足した。
- 事実と見せ方を分ける。要素・接続・ラベル・数値はメモ（と参考資料）からだけ取る。配置・グループ・ラベルの短縮は任せる。矢印は接続なので、メモ（と参考資料）が順につながる手順として書いている段階だけを結び、それ以外で結んだ矢印は仮定として報告させる（Skill の「関係は事実」に合わせる）。
- 曖昧な点は一度だけ質問させる。答えが得られなければ最も素直な解釈で進め、仮定を報告させる。参考資料がないときは「メモ」とだけ書く。
- おまかせのレイアウトは、Skill の layouts から最も近いものを選んで名前を報告させる（合うものがなければそう書き、最も近い作例を挙げる）。auto がページに入らなければ structured で折り返す。
- tone は、その種類のノードとグループすべてに付けさせる。それ以外はテーマの既定の色のままにする。`minimal` / `academic` / `slides` でパレットがないときは、tone が灰色の濃淡になることを書く。
- 仕上げでは、エラーはすべて直し、警告は直すか残す理由を報告させる。`scripts/preview` の PNG で内容（要素・ラベル・矢印の向き）、重なり、遠回りを確かめさせる。報告には、ベースレイアウト・大きさ・残った診断・仮定を含めさせる。

## 採らなかった案

- 「書かれていないものは足さない」だけにする: 2 回目の評価で、全幅のパネル概要図からパネル間の矢印が消えた。見せ方の自由を書き、矢印を接続として扱う形にした。
- 段階を順に並べたら矢印を自由に足してよいとする: 順に並んでいるだけでは直接の流れを意味しない。関係を作ることになるため、仮定として報告させる形にした。
- スライドで `slides` に置き換え続ける: 選んだテーマの色が消える。`textScale` で文字の大きさは満たせる。

## 互換性

- 変わるのはサイトのプロンプトの文面と、README の配置の表示（180mm → 200mm）だけ。CLI・スキーマ・作例・ギャラリーの出力は変わらない。
- 評価（変更後、Sonnet、各設定 1 回。lint はいずれも 0/0/0）:
  - README: 193 × 91mm、`textScale` 1.5。
  - RAG: 78 × 114mm。
  - スライド: `sumi` のまま `textScale` 2、337 × 179mm。
  - パネル: 171 × 51mm、パネル間の矢印あり。
