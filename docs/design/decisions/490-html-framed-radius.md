# #490 HTML の枠の角丸

## 背景

`sumi/html` の framed は HTML の描画後に画像用の枠を重ねていたため、ルートのカードの角丸と枠が一致しなかった。

## 決定

ルート要素の CSS 宣言から角ごとの半径を解決し、ビューポートから配置サイズへの変換を適用して枠を描く。px、pt、em、% と個別の楕円半径を扱い、半径の合計が辺を超える場合は CSS と同様に縮小する。角丸の枠を描く場合は下側のプレースホルダーの枠を隠す。半径がなければ角は四角とする。画像自体の枠は変更しない。

## 互換性

角丸の framed HTML の SVG と、それを元にした PDF / PPTX が変化する。自動レイアウトではプレースホルダーの枠を隠すため D2 も変化する。その他の出力は各組み込みテーマと図の既定テーマで比較する。
