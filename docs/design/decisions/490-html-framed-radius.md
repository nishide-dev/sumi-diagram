# #490 HTML の枠の角丸

## 背景

`sumi/html` の framed は HTML の描画後に画像用の枠を重ねていたため、ルートのカードの角丸と枠が一致しなかった。

## 決定

ルート要素の CSS 宣言から角ごとの半径を解決し、計測したルートの位置と寸法に、fit に応じた拡大率と中央寄せのオフセットを適用して枠を描く。画像の表示領域からはみ出す枠は同じ領域でクリップする。px、pt、em、% と個別の楕円半径を扱い、半径の合計が辺を超える場合は CSS と同様に縮小する。下側のプレースホルダーは枠だけを隠し、透明な HTML の背後に tone の塗りを残す。半径がなければ角は四角とする。画像自体の枠は変更しない。

## 互換性

framed HTML の SVG と、それを元にした PDF / PPTX が変化する。自動レイアウトではプレースホルダーの枠を隠すため D2 も変化する。スキーマは変わらない。
