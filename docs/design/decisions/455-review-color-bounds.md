# #455 濁り判定と暖色探索の境界

## 背景

色相 72〜78 度の隙間で tan が漏れ、低明度や高彩度の olive も検出されなかった。また、明るい tint に近い黄色は、色域変換後の彩度を初期候補で確認せず白に近づくことがあった。

## 決定

橙から黄緑に向かって濁り判定の明度下限を 0.70 から 0.55、彩度上限を 0.065 から 0.135 に連続的に変える。淡い黄色の既存の判定も維持する。これは経験的な警告であり、色名の厳密な分類ではない。

黄色とオレンジは明度下限を守りつつ明暗両方向に探索し、色域変換後に彩度 0.045 以上かつ文字コントラスト 4.5:1 以上の候補を選ぶ。tint との距離 9 以上も優先するが、両立できない場合は条件を満たす候補のうち tint から最も離れた色を採る。任意の入力ではすべての条件を満たす候補が存在する保証はない。

## 互換性

組み込みパレットの色は変わらない。既存の対象図 109 件を既定と全組み込みテーマで SVG / PDF / PPTX / D2 の SHA-256 で比較し、描画できた 525 ケースに差分はない。無効 fixture や経路未解決など 238 ケースは描画できず、構造化図に D2 はない。research/ と private figures は除外した。
