# ギャラリーの物語に沿った作例 (#456)

## Legend samples

文書と属性の対照学習を題材に、正例を実線、負例を破線の双方向矢印で示し、関連する文書とタイトルを集合で囲む。凡例は実際に現れるアイコン、特徴ベクトル、関係だけを Nodes・Features・Relations に分ける。モノクロテーマでも対の種類を区別できるよう線種を併用する。ベクトルはアイコンの上に置き、矢印の接点から離す。サイズだけを示す無関係なデータベースは除いた。

## 集合と glyph

集合の `enclose: footprint` はメンバーの glyph を含めてから余白を加える。既定の `body` は従来どおり glyph を含めない。常に glyph を含めると既存の楕円が拡大して非メンバーに重なるため、明示的な選択とした。

## Node glyphs と Stroke options

二つのエンコーダの生特徴、埋め込み、結合をベクトルの強さ・色・向きで表し、学習可能と固定の状態を点とピルで区別する。知識蒸留の図では主経路と補助入力の線幅・矢じり、破線の教師信号、点線の推論経路と枠、異なる枠の角を対応する凡例とともに示す。単に機能を列挙する代わりに、それぞれの記号に意味を与える。slides は大きい文字と凡例を収めるため presentation-16x9 を使う。

ギャラリーの glyphs と strokes の各 6 テーマの SVG および説明が変わる。コンパイラや既存 YAML の意味は変更しない。両図を PDF 経由の PNG で全テーマ確認した。

## 破線の可視性

矢じりの間に線種の約2周期が入らない場合、`geometry/dash-hidden` を警告する。凡例の破線・点線サンプルは矢じり2個と2周期を収める長さまで伸ばし、推論経路は間隔を広げる。既存の凡例の寸法と出力は変わりうる。線幅の要素指定は絶対値であり、slides の通常線は 2pt、主経路の 1.5pt はそれより細い。テーマの意味は変更しない。

LLaDA の再現図では原図の短い破線の remask 矢印に対する4件の警告を期待値として残す。警告を消すため線幅を変えると原図への忠実さを損なうため、YAML と SVG/PDF は main と同一に保つ。ギャラリーは該当する4辺の同一コードのみ許容し、他の警告やエラーは引き続き拒否する。
