# #517 整列・配置・グループ見出しを予測しやすくする

- **背景**: #509 の 6 回の実行で、構造化配置の整列が思いどおりにならなかった。8 項目を最小の再現にして、不具合・診断不足・機能不足・仕様どおり（文書不足）に分けた。
- **決定（項目別）**:
  1. `align` で動く側と不揃いの隙間: **仕様どおり、文書化**。候補は「先頭の前に空き」「末尾の後に空き」の 2 つで、残差、キャンバス面積、先着の順に選ぶ。動く側は囲む箱の `align` で決まり、空きは 1 つの gap に入るので隙間が不揃いになる。`structured.md` に規則と回避法（単独の箱に包む、箱の `align` を選ぶ）を書いた。
  2. grid のセルの `align` と 1 行 tokens の単一セル: grid のセルは従来どおり strut を取らず、`layout/unsatisfied-align` の hint と文書で説明済み（変更なし）。1 行の tokens のセルを `align` に入れると行が黙って割れる件は、**診断** `layout/align-splits-tokens`（warning）を追加した。挙動は変えない（#305 で単一行の tokens は従来どおりとした）。
  3. `place` の `at`: 葉ノードは常に本体の中心で、グループと全体名を使う tokens の枠だけ、付属ノードの場所を含む枠の中心になる（1B の原因）。**既定は変えず**、item ごとの `origin: body`（既定 `footprint`）を追加した。既定を変えると既存の図が黙って動く。
  4. `centerOn` の空白: **仕様どおり**（対称に確保する）。5mm 超かつ箱の 1/4 以上の空白に **info** `layout/center-on-void` を出し、代替（`centerOn` をやめて `align`）を文書化した。
  5. `straight` が効かない: #531 の自動 straight は変えない。`layout/straight-off-side` は既にあり、狭い端の中心が外でも辺が重なる場合に、重なりの中央に合わせる両端の anchor（例 `south:0.126` / `north:0.937`）を hint に出す。ルーターの端の決め方は変えていない。
  6. グループの見出し: `labelAt: above-left | above | above-right`（枠の外、上に置く。枠内に行を取らない。structured のみ）と、グループの `props.padding`（余白の置き換え。正の 0.5pt 単位、structured のみ）を追加した。見出しの場所は、バッジと同じく外側の張り出しとして親の配置に入る。
  7. grid の `align` がグリッド全体で 1 つ: grid のセルに `align`（`{item, span, align}`）を追加した。列幅は grid の `align` で決まり、上書きは列の中での位置だけを変える。
  8. 空のセル: tokens に `{blank: true, id?, width?, height?}` を追加した。大きさを確保し、何も描かず、位置参照に数える。`''` は空の枠を描くので別物で、空の `label` セルは従来どおり `component/missing-label`。
- **採らなかった案**: 見出しを枠線にまたがせる（枠線を切る不透明な地が必要で、透明な背景と合わない）。`place` の既定を本体の中心に変える（既存の図が動く）。`straight` の位置を重なりの中央に自動で寄せる（経路の変更が既存の図とピン留めの再現に及ぶ）。`centerOn` を非対称にする（箱の中心がノードの中心という契約を壊す）。`padding: 0`（枠を持たない囲みは `plain` や tokens の枠がある）。
- **互換性**: 追加はすべて任意の項目で、既存の図の出力は変わらない（gallery・ピン留めの再現ハッシュは不変）。新しい診断は warning 1 つ（`layout/align-splits-tokens`、黙って割れていた図にだけ）と info 1 つ。
