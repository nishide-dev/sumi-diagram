# #454 グリフ付きノードの本体を基準に揃える

## 背景

グリフやバッジはノードの外側に領域を予約する。従来の中央揃えはこの予約領域を含む矩形を基準にしていたため、グリフ付きアイコンと箱の本体の中心がずれ、水平な接続が折れ曲がっていた。grid では予約矩形そのものが本体として渡され、本体の寸法も大きくなっていた。

## 決定

row と stack の中央揃えでは、交差軸の本体の中心を揃える。本体の中心から予約矩形の両端までの大きい方を両側に確保し、グリフの領域を侵さない。grid でも同様に行の高さと中央揃えの列幅を確保し、配置後に予約矩形から本体矩形を取り出す。開始・終了揃えも本体端を基準とし、各トラックに最大のはみ出しを非対称に予約する。stretch と入れ子の arrange は引き続きその矩形を基準とする。

直線の経路が接続元のグリフを横切る場合、経路に段差は加えず、既存の `geometry/glyph-collision` で警告する。`at` / `dx` / `dy` または接続位置の変更を案内する。

## 採らなかった案

予約矩形だけを中央揃えする方法は本体のずれが残る。グリフの予約を無視すると隣接要素との重なりを防げない。中心に対称な余白は片側に余分な空間ができるが、既存の矩形ベースの配置を保ちながら衝突を避けられる。

## 互換性

スキーマは変わらない。グリフを含む中央揃えの配置と接続経路は変化する。全テーマ・全形式の描画比較では、対象外の research/ と非公開図を除き、YAML の変更は `tests/fixtures/figures/density/sparse-small-elements.sumi.yaml` のみ。ギャラリーの glyphs と legend-samples も本体と矢印が揃う。
