# #434 `paper` テーマの tone を調和した配色（案 B）にする

## 背景

`paper` の tone は、淡い塗り（明度 0.90〜0.95・彩度 0.03〜0.06）と鮮やかな線（明度 0.5・彩度 0.12〜0.17）の組で、青・緑・灰色などを並べると濁って見えるという評価があった（2026-11-08）。[#423](423-tone-harmony.md) で現行と 3 案（A: LLaDA 風、B: 淡い塗り＋調和した線、C: slate 由来）を比べ、ユーザーが案 B を選んだ（2026-11-09）。

## 決定

`paper` の `tokens.tone`（塗り）と `tokens.ink`（線。`outlined` の枠と文字、辺の線・矢じり・ラベル、`solid` の塗り）を案 B の値にする。`tones` と `toneLines` は両トークンを参照するので、変更は 2 つのトークン表だけで済む。`dim` は塗りを白へ寄せる計算なので、値の書き換えは要らない（コメントの青の例だけ更新した）。

| tone | 塗り（旧 → 新） | 線（旧 → 新） |
| --- | --- | --- |
| gray | `#dcdee6` → `#dee1e8` | `#6b6e78` → `#656970` |
| red | `#f6dcdb` → `#f9c7bb` | `#c0392b` → `#8b3c34`（案 B は `#703226`） |
| orange | `#f9e0bc` → `#fcdbb7` | `#bd5410` → `#8a4b00`（案 B は `#71480a`） |
| yellow | `#f1f4c6` → `#f8efbf` | `#857500` → `#866c02` |
| green | `#d0e6cd` → `#c6edcd` | `#3f7d3a` → `#417a50` |
| blue | `#cddff6` → `#d1e7ff` | `#2f62b0` → `#31608e` |
| purple | `#dfdcef` → `#d8cdf8` | `#7240a8` → `#524177` |
| pink | `#f6d8e5` → `#ffdcf1` | `#b8336a` → `#7c4569` |

検証は [`paper-tones.test.ts`](../../../src/core/theme/paper-tones.test.ts) で `paper` 自身の tone に対して行う（パレット導出の試験と同じ基準）。

- 文字のコントラスト 4.5:1: 黒の文字と各塗り、各線と白（`solid` の白い文字・`outlined` の文字・辺）、各線と薄い灰色のパネル。
- グレースケール: 線は塗りより L\* で 20 以上暗く、どの線も L\* 55 未満。
- 色覚（protanopia・deuteranopia・tritanopia）: 線と自分の塗りの CIE76 が 20 以上、tone どうしの線・塗りの差が 2.5 以上。
- tone どうしの CIE76: 塗りは 10.7（旧 7.3）、線は 20.4（旧 20.7）。試験の下限は塗り 10、線 20。

#423 の表は塗りの最小差を 14.4 としていたが、実測の最小は gray と blue の 10.7 だった（旧 7.3 からは改善）。下限は実測に合わせた。

## 採らなかった案

- 案 A（LLaDA 風）・案 C（slate 由来）: ユーザーが案 B を選んだ。
- `paper` だけパレットを既定にする案: `palette` を指定しない図の見た目は tone 表が決めるべきで、既存の `palette` の導出（#417）を変えない。

## 互換性

`paper` テーマで tone（`tone`・`outlined`・`solid`・`tinted`・辺の `tone`・凡例・set・`dim`）を使う図の出力が変わる。tone を使わない部分（黒の枠・文字・灰色のパネル・`muted`）は変わらない。

全 `*.sumi.yaml`（`research/` と非公開の図を除く）を、図自身のテーマと組み込み 6 テーマで描き、SVG と D2 の sha256 を前後で比べた。変わったのは `paper` の出力だけで、他の 5 テーマと、`themeOverrides` で色を明示した図（`gcn`・`tricl`）は 1 バイトも変わらない。D2 が変わったのは `images-auto`（`paper`）のみ。

見た目で気づいた点: yellow の塗りが旧（`#f1f4c6`、明るい淡黄）よりくすんだオリーブ寄り（`#f8efbf`）になり、Transformer の Add & Norm が重く見える。purple の塗りは旧より青紫が強くなる。どちらも案 B の選定の結果で、tone の側では直さない。
