# 515: 大きさの props は 0.5pt に丸める

## 決定

`SizeLength`（`width` / `height` / `tailSize` / `maxWidth` / `offset` / 矢印の長さ・太さ / 画像・表のセル幅など、部品 props の大きさ）は、0.5pt（D2 の 1 unit）の倍数でない値を拒否せず、最も近い 0.5pt に丸める（.5 は上へ）。誤差は、0.25pt 以上の入力では最大 0.25pt。0.25pt 未満の正の値（例: 0.1pt）は 0 になって大きさが消えないよう 0.5pt に切り上げるため、この範囲では誤差が 0.25pt を超える。

## 理由

大きさは配置の値で、0.25pt の誤差は見えない。mm で書いたエージェントが毎回 pt に換算し直していた（#509、18mm → 51pt など）。

## 範囲外

線の太さ・角の丸み・文字サイズなど見た目の値は、これまでどおり `exactD2Units` で厳密に扱い、丸めない（`src/core/theme/style.ts`）。

## 診断

丸めは通知しない。誤差が小さく（0.25pt 以上の入力で最大 0.25pt）、毎回の info は mm を多用する図でノイズになるため。
