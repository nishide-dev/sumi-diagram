# 475: README からサイトの Home を生成する

## 決定

英語と日本語の README をビルド時に Bun の Markdown パーサーで変換し、相対リンクを GitHub に、画像をサイト内のコピーに解決する。サイト自身へのリンクはハッシュルートに変換する。ダーク用 picture はサイトの表示設定と OS 設定に従う画像に変換する。README の構成を固定せず、コードブロックのコピー操作はブラウザー側で付ける。

## 信頼境界

HTML はリポジトリにコミットされた README を信頼して生成し、サニタイザーとしての利用や外部から渡された Markdown の処理は想定しない。ブラウザーへの挿入時に二重エスケープせず、スクリプト要素とイベント属性などを除去する。README の変更はサイトの HTML の変更としてレビューする。
