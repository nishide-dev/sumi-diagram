# #455 暖色の塗りの色相と明度

## 背景

黄色は彩度の下限 0.06 と色相の引き寄せの上限 8 度が重なり、寒色系の複数パレットで同じ 108 度の黄緑色になった。淡いパレットのオレンジや暗いパレットの赤も、低彩度・低明度のため濁って見えた。

## 決定

黄色の色相を最大 98 度、オレンジを最大 60 度に制限する。オレンジの彩度は 0.075 以上、彩度の低いパレットでは明度 0.84 以上から探索する。特に暗い tint の赤は 0.79 以上から探索する。sRGB 色域への収縮と、文字の 4.5:1、灰色との距離、色覚多様性の検査は維持する。全 8 パレットの PDF から生成した PNG を目視し、塗りと線を確認した。

濁り lint は既存の黄土色に加え、低彩度の中明度オレンジと、黄緑に偏った限定的な明るい黄色を検出する。既存 example の淡いピーチや黄色を誤検出しないよう、明度と色相の範囲を限定する。

## 互換性

パレット由来の暖色を使う図は色が変わる。全図の各テーマで SVG・PDF・PPTX・D2 を比較し、描画できた既存図の差分はなかった。自動生成パレットギャラリーのうち coral を除く 7 枚は色が変わる。無効 fixture や一部テーマで経路を解決できない図など、描画失敗もある。research/ と private figures は除外した。
