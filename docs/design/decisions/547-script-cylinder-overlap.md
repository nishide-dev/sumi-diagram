# #547 添字の下限・高い円柱の蓋・3 つ以上の重なりの色

#538 の再計測で見つかった 3 件。

## 数式の添字（下限）

- **背景**: 添字は基準の 0.7 倍（8pt なら 5.6pt）で、`figure.target.minFontSize: 7pt` を満たせるのは基準を 10pt にしたときだけだった。基準そのものは 7pt 以上を満たしているのに `geometry/script-below-target` が出た。
- **決定**: 構造化レイアウトの文字の測定（`measureText()`）で、添字の大きさを `min(基準, max(基準 × 0.7, minFontSize))` にする（`scriptGeometry()` の `floor`、`TextMeasurer.scriptMinUnits`）。`minFontSize` のない図、添字が最小値をすでに満たす図は変わらない。基線のずらしは基準の大きさから決めるので変えない。lint は SVG から添字の大きさを読むので、引き上げた大きさで判定する。
- **残るもの**: 基準が最小値未満のとき、および `fit: scale` で縮めた図（最小値は印刷後の大きさだが、測定は縮小前）では `script-below-target` が出る。ヒントは「最終的な大きさで、基準を最小値以上（縮めた図は縮小後の添字が基準の 0.7 倍になるので、最小値 ÷ 0.7 以上）にする」に変えた。引き上げは構造化レイアウトだけに働く（数式のラベルは構造化にしかない）。添字の判定は、アクセントの記号（#129）を除き、基準と同じ大きさの添字も基線のずれで添字と見なす。
- **採らなかった案**: 添字の比率を一律に上げる案（`minFontSize` のない図の SVG がすべて変わる）。添字を検査から外す案（#356 の判断に反する）。

## 円柱の蓋の深さ（高い円柱）

- **背景**: 蓋は高さ 100 unit 以上で D2 の 24 unit に固定だった（#516）。`textScale` や `text: large` で文字が大きくなると円柱は高く広くなるが、蓋は 24 unit のままなので、蓋が相対的に浅い缶のような太い形になった（`textScale: 2` の 140×199 unit で、蓋の楕円の縦横比は 1 倍のときの 0.48 から 0.24 になる）。
- **決定**: `cylinderArc(height)` を 140 unit を超える高さで深くする。超えた分の 1/6 を足し、D2 の 2 倍（48 unit）を上限にする。100〜140 unit は従来の 24 unit で、通常の大きさの円柱は変わらない。胴体の高さ（高さ − 3 × 深さ）は引き続き高さに対して単調に増える。構造化レイアウトの寸法は、胴体が内容の高さ（パディング込み）を確保する最小の高さ（`cylinderMinHeight()`）にする。D2 経路は `composeCylinders()` の対象を「蓋が 24 unit でない円柱」に広げ、描き直す。蓋が D2 より深い円柱では、D2 が自分の輪郭や外接矩形に置いた辺の端点が新しい輪郭の外に浮くので、最後の線分を延長して新しい輪郭に載せる（内側に入った端点は従来どおり戻す）。蓋が浅い円柱の外側の端点は、従来どおり動かさない。
- **限界**: D2 は高さを自分の 24 unit の蓋で決めるので、auto の高い円柱は胴体が D2 の想定より低くなる（1 行のラベルでは収まる）。D2 が辺の端点を側面の蓋の曲線の位置に置いた場合は、`composeCylinders()` の既存の補正で新しい輪郭へ戻す。
- **ここで再現できたこと**: 「太く見える」は文字の倍率で蓋の比率が変わることとして再現した。線の太さの倍率による見た目は別の話で、変えていない。

## 3 つ以上の重なりの色

- **背景**: #505 の平均では、3 色のうち 1 色が他の 2 色の中間にあるとき、平均がその色とほぼ同じになる（`sumi` テーマの blue・green・purple で ΔE76 が 0.4）。中央が集合 C だけに見えた。
- **決定**: `mixTints()` は 3 色以上のとき、平均が参加するどの色とも CIE76 の ΔE で 5（`MIN_OVERLAP_DELTA_E`）以上離れるまで、OKLCH の明度を 0.005 ずつ、キャンバスから遠ざかる向き（明るい地では暗く、暗い地では明るく）に動かす。動かす量は 0.08 まで。色相と彩度は平均のまま。キャンバスから遠ざかる向きで満たせなければ逆向きも試す。2 色の重なりは従来どおり単純平均（#505）で、動かさない。`sumi` テーマの 8 つの tone の 3 つ組すべてで ΔE が 5 以上になることを確かめた。
- **保証の限界**: ΔE ≥ 5 は 0.08 の範囲で満たせるときの努力目標である。色域の端（黒や白の色など）で両向きとも満たせなければ、最も近い色から最も離れた候補を返す（例外にはしない）。同一の色の 3 つ組は、どちらかの向きで分離できる。
- **互換性**: 3 つ以上の重なりで、平均が既存の色に近い図の色が変わる。`multiply` の重なりは変わらない。SVG・PDF・PPTX と幾何 lint は同じ `mixTints()` を使う。
