# #459 塗りのある図形の枠線の判定

## 背景と決定

背景と区別できる塗りは、それ自体で図形の輪郭を示す。枠線が薄くても輪郭の視認性不足とは限らない。ノードの各輪郭標本で、合成した塗りと背景のコントラストが 1.3:1 以上なら枠線の判定から除く。透明または背景と近い塗りは従来どおり 3:1 を要求する。outlined はページ色で塗られる枠のため例外として枠線を検査する。エッジは従来どおり背景と比較する。

## 互換性と残課題

描画は変わらず、一部の塗り付きノードの警告が減る。一方、既存の例やギャラリーには 3:1 未満のエッジや背景と近い塗りがあり、エッジ判定を変更せずに警告をゼロにはできない。警告ゼロと従来のエッジ判定を両立させるには別途方針が必要である。
