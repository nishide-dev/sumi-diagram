# #444 暖色の tone の solid・線を茶色・オリーブにしない

## 背景

論文の図の 4 回目の試行（2026-11-09）で、`cool-blue`・`seafoam`・パレットなしのいずれでも、solid の orange（強調に使った ⊕）が茶色に見えた。原因は [#423](423-tone-harmony.md) の導出にある。線は「パレットの strong の明度（tone ごとの差を足す）」に置き、白い文字が 4.5:1 になるまで暗くする。暗い橙は茶色、暗い黄はオリーブ（暗い黄緑）に見える。

変更前の線（OKLCH）は、orange が明度 0.43〜0.49・彩度 0.09〜0.12・色相 54〜69°、yellow が明度 0.50〜0.53・彩度 0.09〜0.11・色相 92〜108°だった。`paper` の線は orange `#8a4b00`、yellow `#866c02`。

## 決定

solid の塗りは線の色そのもの（白い文字を載せる）なので、**白い文字 4.5:1 を保ったまま**、暖色の線を「4.5:1 が通る最も明るい色」に置き、彩度を保ち、色相を赤寄りにする。

### パレットから導く線（`src/core/theme/palette-tones.ts`）

orange と yellow だけを次のようにする（ほかの tone は変えない）。

- **明度**: strong の明度を使わず、明度 0.75 から下げて、白とパネルの上で 4.5:1 になる最初の色にする（最も明るい色）。
- **彩度**: `WARM_LINE_CHROMA`（orange 0.17、yellow 0.125）。通常の線の範囲（0.09〜0.14）より高い。色域に入らないときは `fromOklch` が彩度を落とす。
- **色相**: `WARM_HUE_LEAN`（orange −18°、yellow −16°）だけ赤へ寄せ、`WARM_HUE_LIMIT`（orange 40°、yellow 82°）を上限にする。パレットの色相への引き寄せ（最大 8°）で暖色側に寄ったパレットでも、橙は 40°を、黄は 82°を超えない。

結果の線は、orange が明度 0.52〜0.55・彩度 0.16〜0.17・色相 36〜40°（`#b5360e`〜`#bf4211` 付近）、yellow が明度 0.51〜0.53・彩度 0.10〜0.11・色相 76〜83°。

### `paper` テーマ（`builtin.ts`）

orange `#8a4b00` → `#b83b07`、yellow `#866c02` → `#876200`。塗りは変えない。

### 黄色の限界

白い文字が 4.5:1 になる黄は、明度が 0.52 付近より明るくできず、その明度では色域で彩度が 0.11 程度までしか出ない。黄の solid は「金色・からし色」までで、明るい黄色にはならない。黄を明るく保つには、solid に濃い文字を使えるようにする（tone ごとの文字色。塗り＝線という現在の構造を変える）必要があり、この issue の範囲外とした。outlined・tinted の黄は従来どおり。

### 検証

- `palette-tones.test.ts`: 8 パレットで orange の線は彩度 0.13 以上・色相 50°未満・明度 0.5 以上、yellow の線は色相 90°未満・彩度 0.10 以上（茶色・オリーブの検知。変更前は orange が彩度 0.09〜0.12 で失敗する）。`paper` の同じ検査。
- 既存の検査（コントラスト 4.5:1、グレースケール、色覚、tone どうしの色差、gray tone との色差）はすべて通る。次の基準だけ、暖色の線の意図に合わせて緩めた: 線の色相の許容（orange・yellow は 28°）、red と orange の線の色相の間隔（25° → 12°。明度・彩度で区別される）、線の彩度の上限（暖色は `WARM_LINE_CHROMA`）。
- 比較画像: `.sumi/preview/warm-tones-before.png`、`warm-tones-after.png`（8 パレットと `paper` の solid 7 色）。

## 採らなかった案

- **白い文字の代わりに濃い文字を使う solid**: 黄色を明るく保てるが、solid の文字色は塗り＝線から決まる構造で、tone ごとの文字色・凡例・set などへ波及する。上記のとおり範囲外。
- **明度を下げすぎない（コントラストを緩める）**: 白い文字 4.5:1 を保つ方針（#423）に反する。
- **暖色の色相を大きく赤へ回す**: orange が red と同じに見える。上限を 40°にした。

## 互換性

`palette` を指定した図の orange・yellow の線（solid・outlined・辺・set の輪郭）と、`paper` テーマで orange・yellow を使う図が変わる。ほかの tone、`palette` を書かない他のテーマ、`themeOverrides` で色を明示した図は変わらない。論文の再現図は固定した色なので変わらない（`pinned-reproductions` の試験）。
