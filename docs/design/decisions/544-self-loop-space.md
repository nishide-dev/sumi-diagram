# #544 曲線の自己ループの場所と、枠の上の見出しの余白

- **背景**: #539 のレイアウトを描く中で、`labelAt: above-left` の見出しと中身の間に約 13mm の隙間が出ること、`route: curve` の自己ループが配置の場所を取らず隣や枠に当たることが記録された（#538 のレポート）。
- **決定（自己ループ）**: 構造化エンジンが、ノードの付属の場所（バッジ、キャプションと同じ張り出し）に、曲線の自己ループの外接矩形とラベルの箱を含める。ルーターと同じ関数（`selfLoopAnchors`、`selfLoopPoints`、`curveLabel`、`loopLabelEdge`）で本体の辺のアンカーから描くので、描画と確保する場所が食い違わない。ノードの本体の大きさと `place` の `at`（葉は本体の中心）は変わらず、隣の要素、枠の内側の余白、キャンバスだけが膨らみに合わせて広がる。円や菱形は外接矩形の辺から描くため、輪郭へ射影するルーターの実際のループより少し大きく見積もる（隣との間隔が足りないより安全側）。
- **決定（見出し）**: 仕様どおり、変更なし。`above-*` の見出しは枠の内側に行を取らず、枠の上端から最初の中身までの余白は見出しなしのグループと同じ（paper-double / sumi で 16 単位 = 約 2.8mm。単独、入れ子、`place`、行の中で確認し、テストで固定）。見出しは枠の外の張り出し（見出しの高さ 約 22 単位 + 余白の半分 8 単位 = 約 30 単位、約 5.3mm）として親の配置に入り、見出しと枠の間は 8 単位（約 1.4mm）。入れ子では子の見出しが親の枠の余白の中に入るので、親の枠の上端から子の枠までは 余白 + 張り出し = 約 46 単位（約 8mm）になる。この外側の場所を内側の隙間と見間違えた可能性が高く、13mm の隙間は再現しなかった。
- **互換性**: 自己ループのない図は変わらない。ピン留めの再現と gallery の例は変わらず、Skill の基本レイアウトでは `three-panel-flow`（東側のループがパネルの外へはみ出していた）だけが少し広がった。
