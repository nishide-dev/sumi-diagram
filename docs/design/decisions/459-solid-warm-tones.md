# #459 solid の暖色を線色から分離する

## 背景と決定

黄色を文字と同じ暗さの線や solid に使うと黄土色になる。有彩色の tone から OKLCH で色を導き、黄色の線は白地とパネルの両方で 3:1 以上、文字はテーマの ink、solid は明るい黄色にする。橙は赤寄りの solid に白文字を使い、llama と color の線も赤寄りにする。無彩色テーマは元の灰色を維持する。

レビュー対応: 色相と彩度を維持し、OKLCH の L を 0.665 から 0.001 刻みで下げ、量子化後の色が白と通常パネル・組み込み filled パネル（パレット指定時はパレットの panel ロール）に 3:1 を満たす最初の金色を選ぶ。パレットの filled が tint ロールに変わるテーマでは、その濃い塗りは対象外とする。これにも 3:1 を求めると黄土色となり muddy-color に抵触するためである。明示的な色の上書きは対象外。

明示的な tone の line または solidFills の上書きは優先する。muddy-color は塗りに加え線と文字も検査する。

レビュー対応: tone を持つ emphasis は塗りと文字が 4.5:1 未満のときテーマの ink を使い、必要ならさらに暗くする。solid の優先順位は `solidFills`、tone の `line`、組み込み solid の順で、`fill` のみの指定は solid に影響しない。文字のコントラストは 4.5:1 以上とする。glyph と凡例も同じ解決済み solid 色を使う。黄土色の検出は色相に応じた連続的な明度境界を使い、75° の断絶を避ける。

## 互換性

solid の黄色・橙、対応する凡例と glyph は出力が変わる。色を固定した再現図は pinned reproductions テストで確認する。SVG・PDF・PPTX と D2 の比較では research/ と非公開の図を除外した。
