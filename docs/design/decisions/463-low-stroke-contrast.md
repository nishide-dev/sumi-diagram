# #463 線の背景コントラスト（geometry/low-stroke-contrast）

## 背景

#459 で組み込みの線は白と既定のパネルに対して 3:1 を保証したが、パレットを当てた llama の filled パネルなど濃い塗りの上では、線が背景に溶けうる（cool-blue で 2.13:1）。#459 の試作は、塗りのある図形の装飾的な枠（LLaDA のトークンのセル、DiT の円）や、原図どおりの淡い線を大量に警告したため取り下げた。

## 決定

- 測る対象
  - エッジの線（実際に描かれた経路）。
  - 輪郭だけで形を示すノードの枠。ノードの塗りと、その中心の下に描かれている色との差が 1.2:1 未満のものだけを対象にし、塗りで形がわかるノードの枠は装飾として測らない。中心の下で判定するので、同じ色のセルが隣り合うトークン列の境界を誤検出しない。
- 測らないもの
  - グループの枠（テーマが決める構造の線）。
  - operator と junction（記号で読む）、zoom の案内線（意図して淡い）。
  - `dim` の中の要素（意図して淡い）。
- 背景は、線に沿って 4 単位ごとに、その位置に実際に描かれた合成色（テーマの地、グループ、set、重なり）を取る。テーマの地の色（#473）を使い、白を仮定しない。
- 基準と重大度
  - エッジ: 3:1 未満で info（WCAG の非テキストのコントラスト）、1.5:1 未満で warning（ほぼ見えず、関係が読めない）。
  - ノードの枠: 2:1 未満で info のみ。中身は読めるので、テーマの控えめな枠（llama の 2.73:1 など）は対象外にする。
  - 各重大度の閾値を下回る長さを別々に合計し、それぞれ 10 単位以上の場合にのみその重大度で報告する。
- 矢じりは線と同じ色で描くので、線の判定で代表させる。

## 検出結果（導入時）

- examples（各自のテーマ）: `gcn` の淡いエッジ ×2（2.51:1）だけ。原図どおりなので、図は変えず `examples/README.md` に期待値として記録した。
- ギャラリーの `themes` ページ: Transformer の sumi-dark テーマで 28 件の info。先頭の `enc-mha` の枠（1.03:1）を含み、パネル上の枠や線が背景に近くなる箇所の検出。`examples` ページ: GCN のエッジ 2 件。その他のギャラリーページは 0 件。
- それ以外の見本（全テーマ・全パレット）は検出なし。warning はどこにも出ない。

## 互換性

lint の診断の追加のみで、描画結果は変わらない。ギャラリーの Markdown には info が加わる。

背景の合成は他の色検査と同じ描画スタックを共有し、要素と線分の範囲で候補を絞る。透明なノードも描画順を持ち、直前までの塗りを背景とする。短い 16 進色も正規化して測定する。`embedding-gemma` の `sumi lint --geometry` の実測は変更前 0.364 秒、変更後 0.367 秒（描画を含む wall time、各 1 回）だった。
