# #463 線の背景コントラスト（作業途中）

## 背景と方針

矢印と輪郭だけで形を示す図形は、実際の背景と区別できる必要がある。描画順に塗りを合成し、線と背景のコントラストを測る。3:1 未満は info、1.5:1 未満は warning とし、明示したルール重大度はこの既定値を上書きする。塗りと背景の差が 1.2:1 以上の装飾枠は対象外とする。

## 未解決

試作は境界上の隣接する塗りを背景と誤認し、再現図のセルや operator を warning にする。境界の内外のサンプリングと描画順を修正し、矢印先端を測る必要がある。全作例の検出結果・互換性の確認も未完了。現状の試作は完成した設計ではない。
