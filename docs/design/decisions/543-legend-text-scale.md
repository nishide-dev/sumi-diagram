# 543: 凡例の見本を textScale に従わせる

## 背景

凡例の見本（線・箱・集合）の大きさと間隔は、テーマの `sumi/label` の文字サイズと見本の線のスタイルから決まる。展開処理（`expandLegends`）は組み込みテーマをそのまま引いており、`themeOverrides.textScale`（#514）を掛けた後のテーマを見ていなかった。そのため `textScale: 2` では文字と線だけが 2 倍になり、見本の長さ・箱・間隔は元の大きさのままだった（#538）。

## 決定

`expandLegends` が使うテーマを `figureTheme(テーマ, figure.themeOverrides)` に通す。

- 見本の寸法（`LEGEND_EM` を文字サイズに掛けたもの）は、倍率を掛けた文字サイズから出る。見本・箱・見本と文字の間・行間は倍率に比例する。
- 破線の見本の線の長さは、倍率を掛けた線の太さと矢じりから出す。破線の周期は線の太さに比例するので、見本の線は倍率 1 と同じ個数の周期を持つ。

倍率が省略または 1 の図は `figureTheme` がテーマ自身を返すので、出力は変わらない（テストで固定）。`LEGEND_EM` の値は変えない。
