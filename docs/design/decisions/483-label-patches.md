# #483 エッジラベルの下地

## 背景

透明なキャンバス上に描く図で、エッジラベルの下地や中抜き矢じりの内部にテーマのキャンバス色が残ると、配置先の背景色を隠してしまう。

## 決定（structured）

structured のエッジラベルには下地矩形を描かない。ルーターはラベルを線の脇に置き、他の線との交差は引き続き幾何 lint が報告する。中抜き矢じりは塗りなしとし、線は従来どおり矢じりの根元で止める。

下地を明示的に復元するスキーマは追加しない。下地が必要な場面を評価してから別途検討する。

## auto と編集可能 PPTX

auto の D2 出力では、マスク付きエッジのテキスト直前の矩形を除き、線のマスクは維持する。編集可能 PPTX の freeform は共有マスク内の全矩形と各線を交差させて線を分割し、始点と終点の矢じりをそれぞれ外側の線分に残す。曲線は交点付近のみ細分化する。glued は通常のキャンバスでは接続を維持し、マスク付きラベルにキャンバス色の下地を付ける。透明背景では下地を使わず、そのエッジを freeform に分割するため接続は維持されない。PDF と画像 PPTX のマスクは decision-flow で目視確認した。

透明背景ではキャンバス色を塗る代替案は目立つため採用しない。編集可能 PPTX の中抜き矢じりの形と分割線の破線の連続性は #485 で扱う。D2 の中抜き矢じりは未対応である。全図・全テーマの互換性比較は未完了である。
