# #483 エッジラベルの下地

## 背景

透明なキャンバス上に描く図で、エッジラベルの下地や中抜き矢じりの内部にテーマのキャンバス色が残ると、配置先の背景色を隠してしまう。

## 決定（structured）

structured のエッジラベルには下地矩形を描かない。ルーターはラベルを線の脇に置き、他の線との交差は引き続き幾何 lint が報告する。中抜き矢じりは塗りなしとし、線は従来どおり矢じりの根元で止める。

下地を明示的に復元するスキーマは追加しない。下地が必要な場面を評価してから別途検討する。

## auto と編集可能 PPTX

auto の D2 出力では、マスク付きエッジのテキスト直前の矩形を除き、線のマスクは維持する。編集可能 PPTX の freeform は共有マスク内の全矩形と各線を交差させて線を分割し、始点と終点の矢じりをそれぞれ外側の線分に残す。曲線は交点付近のみ細分化する。glued は通常のキャンバスでは接続を維持し、マスク付きラベルにキャンバス色の下地を付ける。透明背景では下地を使わず、経路がマスクの矩形（ラベルの隙間）の下を通るエッジだけを freeform に分割し、そのエッジの接続は維持されない。D2 はラベルのマスクを全エッジで共有するため、矩形の下を通らないエッジは glued のまま接続を保つ。PDF と画像 PPTX のマスクは decision-flow で目視確認した。

透明背景ではキャンバス色を塗る代替案は目立つため採用しない。編集可能 PPTX の中抜き矢じりの形と分割線の破線の連続性は #485 で扱う。全図・全テーマの互換性比較は未完了である。

## auto の中抜き矢じり

D2 は塗らない矢じり（`style.filled: false` の triangle、diamond、circle、box、cross）を、内部をキャンバス色（`fill="#FFFFFF"` と class `fill-N7`）で塗った marker として描き、矢じりの下の線を隠す。透明背景やキャンバスが白でないテーマではこれが下地として見える。

`composeHollowArrowheads()`（`src/render/hollow-arrowheads.ts`）が D2 の SVG を後処理する。

- その端は marker のコピーを参照する。コピーは図形の fill を `none` にし、`fill-*` の class を除く。D2 は同じ見た目の marker を辺の間で共有するため、元の marker は書き換えない（#386 の開いた矢じりと同じ）。
- 線は矢じりの外形を出る点で切る。marker の幾何は D2 の定義から求める。`orient="auto"` では marker の x 軸がその端の経路の向き、(`refX`, `refY`) が経路の端に一致し、1 単位は `min(markerWidth / viewBox 幅, markerHeight / viewBox 高さ)`（`markerUnits="strokeWidth"` ならさらに線幅倍）である。外形（polygon と circle、線の中心）をこの対応で利用者座標へ写し、端から経路を辿って外形を出る点を求める（標本化と二分法、曲線は de Casteljau で分割）。三角形と box は底辺、diamond は後ろの頂点、circle は手前の円周で止まる。D2 の `.connection` は丸い線端なので、さらに線幅の半分だけ戻し、線端が外形の線の中心で終わるようにする。
- 矢じりの位置は変えない。コピーの参照点を線の新しい端の marker 座標へ移す。曲線上や手前の線分で切ると新しい端の向きが変わるため、そのときは `orient` を元の向きの角度に固定する。始点を切った破線は `stroke-dashoffset` で位相を保つ。
- 両端の矢じりが接するか重なり、間に線が残らない辺は、経路を残して矢じりを置き、線の `stroke` を `none` にする。
- cross は腕が線幅より細く内部がないため fill だけを除き、線は切らない。

編集可能 PPTX は線の端に PowerPoint 自身の矢じりを置くため、切った線ではなく D2 の経路を使う。切った経路には元の `d` を `data-sumi-route` に、線を隠した経路には元の `stroke` を `data-sumi-route-stroke` に残し、編集可能 PPTX は読み込む前に `untrimmedRoutes()` でそれらを戻す。現状の編集可能 PPTX は塗らないネイティブ矢じりを拒否する（#485）が、塗った矢じりとして渡した場合も線の端は D2 の経路の端と一致する。

この処理は inspection と幾何 lint の後（`composeOpenArrowheads()` の直後）に行う。lint は従来どおり D2 の経路（先端まで）を見る。`finalizeSvg()` で行うと inspection の経路が変わり、`composeOutlines()` などの後続の端の補正とも干渉するためである。

通常のキャンバス上の見た目は変わらない。カスタムの辺部品で各形の中抜き矢じりを両端に持つ auto の図を academic と llama で描き、origin/main と比べた PDF（200 dpi）の差は `magick compare -metric AE` で 8.3 と 6.2（アンチエイリアスのみ）である。透明背景を色付きの紙に重ねると、矢じりの内部に紙の色が見え、線は矢じりの中に入らない。画像 PPTX も同じ SVG を埋め込む。組み込みの辺部品とテーマには塗らない矢じりがないため、ギャラリーと golden は変わらない。
